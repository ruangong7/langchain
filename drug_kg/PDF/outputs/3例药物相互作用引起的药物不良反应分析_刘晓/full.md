摘要:目的 分析 3 例药物相互作用引起的药物不良反应 方法 汇总整理2010 ～ 2014 年我院上报的药物不良反应 1003 例，从中筛选出因药物相互作用导致的药物不良反应病例，并对其进行分析和再评价。 结果 共有 3 例因药物相互作用引起的药物不良反应。 1 例为环孢素与伏立康唑联用，导致环孢素血药浓度升高，出现肢体抖动; 1 例为螺内酯与地高辛联用，导致地高辛中毒; 1 例为华法林与莫西沙星、阿奇霉素联用，导致血尿。 结论 在评估患者病情确实需要联合用药对患者进行治疗时，应同时分析是否存在不良的药物相互作用，权衡利弊，为患者制定更加合理的药物治疗方案。

Abstract: Objective To analyze 3 cases of adverse drug reactions caused by drug interactions. Methods We selected the adverse drug reactions induced by drug interactions from the summary of 1003 cases of adverse drug reactions reported in our hospital during 2010 － 2014，and analyzed and evaluated the cases one by one. Results There were 3 cases of the adverse drug reactions due to drug interactions in the all 1003 cases of adverse drug reactions. One case was a patient given voriconazole combined with cyclosporine leading to the cyclosporine plasma concentration increased and the patient was limb － shaking. One case was a patient given spironolactone combined with digoxin leading to digoxin poisoning; One case was a patient given warfarin combined moxifloxacin and azithromycin causing hematuria. Conclusion In the assessment of the patients who really need combination therapy，the doctor should also analyze the existence of adverse drug interactions and weigh the pros and cons to make more reasonable drug regimens for the patients.

Key words: drug interaction; adverse drug reaction; combined medication; rational drug use

药物间的相互作用可影响药物代谢，进而导致药物原有药理作用的叠加、降低，还可引起药物不良反应( ADR) 的增加或降低。 合理的药物相互作用可以增加药物的有效性，减少 ADR 的发生; 反之，不合理的药物相互作用则可以降低药物的有效性，增加 ADR 的发生。住院患者中，每日用药 1 ～ 5 种、6 ～ 10 种、11 ～ 15 种的潜在药物相互作用发生率分别为 12. 1% ，29. 0% ，44. 8% ，实际 ADR 发生率分别为3. 5%，10. 0%，28. 0%［1］。 每年因药物相互作用的致死率，占住院患者致死原因的第 4 ～ 6 位。 因此，合理地联合应用药物，避免不良的药物相互作用是联合用药中不容忽视的问题。 本文通过汇总整理我院2010 ～ 2014 年上报的 1003 例 ADR，从中筛选出 3 例因药物相互作用引起的 ADR，对其进行分析和再评价，为临床避免不合理的药物联合应用提供参考。

## 1 环孢素联合伏立康唑致环孢素血药浓度升高

患者1，男，52 岁，因“肾病综合征、肾小球微小病变( 光镜) 、慢性肾病 1 期”入院治疗。 初始予以醋酸泼尼松片50 mg qd po，入院第3 天醋酸泼尼松片调整为 40 mg qd po，入院第 6 天加用环孢素 $5 0 ~ \mathrm { m g } ~ b i d ~ p o$ 。入院第10 天，查环孢素血药浓度为 $1 0 3 . 6 ~ \mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ 。同时，G 试验示: D － 葡聚糖 $> 1 0 0 0 \mathrm { \ p g \ } \bullet \mathrm { \ m L } ^ { - 1 } ; \mathrm { G M }$ 试验( － ) ; X 线片示双肺渗出。 考虑为真菌感染，加用伏立康唑胶囊 $2 0 0 \ : \mathrm { ~ m g } \ : \ : b i d \ : p o$ ，此时患者血钾为 3. 65$\mathrm { m m o l } \cdot \mathrm { ~ L ~ } ^ { - 1 }$ 。 入 院 第 17 天 患 者 血 钾 为 5. 50$\mathrm { m m o l } \cdot \mathrm { L } ^ { - 1 }$ ，并出现肢体抖动，复查环孢素血药浓度为$3 6 1 . 8 ~ \mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ ，较前明显升高，遂停用环孢素。 第18 天复查血钾为 $6 . 2 9 \mathrm { \ m m o l } \cdot { \mathrm { L } } ^ { - 1 }$ ，予以口服聚磺苯乙烯钠散、补液、糖 + 胰岛素静脉点滴排钾。 第 19 天复查血钾为 $4 . 6 2 \ \mathrm { m m o l } \cdot \mathrm { L } ^ { - 1 }$ ，恢复正常范围。 入院第20 天复查环孢素血药浓度为 $5 1 . 3 ~ \mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ ，随着患者环孢素血药浓度的下降，患者肢体抖动症状逐渐改善 。

分 析 其 原 因: 环 孢 素 是 细 胞 色 素 P450 3A4( CYP3A4) 底物，而伏立康唑是 CYP3A4 抑制药。 伏立康唑的说明书中明确指出，在病情稳定的肾移植患者中，伏立康唑可使环孢素的 Cmax和 AUC 至少分别增高13%和 70% 。 因此，对于已经接受环孢素治疗的患者开始应用伏立康唑时，建议其环孢素的剂量减半，并严密监测环孢素的血药浓度; 同时，停用伏立康唑后仍需严密监测环孢素的浓度，如有需要，可增大环孢素的剂量。 丁雄芳等［2］曾报道了 2 例恶性血液病合并真菌感染的患者，环孢素与伏立康唑联用导致环孢素血药浓度升高，引起高血钾症。 曲彩红等［3］报道1 例异基因外周造血干细胞移植术后患者服用环孢素治疗，因肺部真菌感染加用伏立康唑后，导致环孢素血药浓度升高，继而诱发癫痫样发作。 本例患者因肾病综合征用环孢素治疗，因肺部真菌感染加用伏立康唑，11 d 后出现血钾升高、肢体抖动，且环孢素血药浓度较前明显升高。 停用环孢素，随着患者环孢素血药浓度的降低，患者血钾恢复正常范围，肢体抖动症状逐渐改善。 故考虑患者血钾升高及肢体抖动是由于环孢素与伏立康唑联用使环孢素血药浓度升高

所致 。

## 2 螺内酯联合地高辛致地高辛中毒

患者2，男，72 岁，4 年前诊断为 “扩张型心肌病、左心室附壁血栓、心律失常”，开始服用地高辛 0. 125mg bid，未监测血药浓度; 同时服用阿司匹林 100 mgqd 、 雷米普利 1. 25 mg qd 、 氯沙坦钾 25 mg qd 、 螺内酯$2 0 { \mathrm { ~ m g ~ } } q d ,$ 呋塞米 20 mg qd 。 近 1 个月，患者出现喘憋伴双下肢水肿、恶心、厌食、饮水呛咳、视物发黄，体重减轻约15 kg。 偶有发作性黑曚，晕倒，呼之不应，持续3 ～ 5 s 后自行恢复。 目前患者地高辛服用剂量为0. 125 mg qd 。 入 院 查 地 高 辛 血 药 浓 度 ﹥ 4. 0$\mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ 。考虑为地高辛中毒，停用地高辛，予以补液等对症治疗，复查地高辛血药浓度 $1 . 2 ~ \mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ ，患者病情明显好转，无喘憋、恶心、厌食等。

分析其原因: 本例患者地高辛血药浓度曾﹥ 4. 0$\mathrm { n g } \cdot \mathrm { m L } ^ { - 1 }$ ，远高于参考值上限，很可能与患者的合并用药相关。 文献表明［4］，地高辛与螺内酯联用时，螺内酯可抑制肾小管对地高辛的分泌，从而减少地高辛的清除，导致地高辛血药浓度增加 2 ～ 3 倍。 地高辛与螺内酯联用时，地高辛用量应减半，并进行血药浓度监测; 地高辛与呋塞米联用时，由于在低血钾状态下，心脏摄取地高辛的量增加，心肌对地高辛敏感性增强，因此常规剂量的地高辛也易发生中毒，导致患者心律失常。 因此，应注意调整地高辛的剂量及补充钾盐，监测地高辛血药浓度及血钾水平。 此外，氯沙坦与螺内酯联用会增加发生严重高钾血症的风险。因此，在应用此类相互作用较多，治疗窗窄、毒性较大的药物时，应更加严格监测用药安全。

## 3 华法林联合莫西沙星和阿奇霉素致血尿

患者3，女，71 岁，因 “肺栓塞”服用华法林治疗，剂量调整范围在 $1 . 5 \sim 4 . 5 ~ \mathrm { m g } ~ q d \mathfrak { c }$ 服用8 个月时，因“肺部感染”，加用莫西沙星 0. 4 g qd 及阿奇霉素0. 5 g qd，此时华法林剂量为 1. 5 mg qd 。 7 d 后，出现血尿。 立即停用华法林，2 d 后好转。

分析其原因: 阿奇霉素与莫西沙星与华法林合用时，可导致华法林的抗凝效果增强。 华法林是维生素K 的结构类似物，通过抑制维生素 K 环氧化物还原酶而发挥药理作用［5］，而阿奇霉素作为广谱抗生素，可杀灭肠道内产生维生素 K 的肠道菌群，导致体内维生素 K 摄入量减少，从而使华法林的抗凝效果增强。 除上述因药物相互作用导致其中某种药物血药浓度升高、或联合用药导致药理作用增强引起的 ADR 外，联用可能诱发相同 ADR 的药物时也应特别注意。

如目前，发现很多药物如氟喹诺酮类、阿奇霉素、特非那定、阿司咪唑、西沙必利、匹莫齐特、奎尼丁等，可引起QT 间期延长，进而诱发尖端扭转型室性心动过速，如有需要联合使用这些药物时，应严格监测患者心电图及生命体征，在老年患者等特殊人群中尽量避免联用。

4 讨论

通过对上述3 例 ADR 的分析发现，药物相互作用导致的ADR 是联合用药时不容忽视的问题。 此时，药师在与医师共同评估患者的病情是否确实需要联合用药治疗的同时，还应充分分析联合用药之间的可能发生的相互作用。 如存在可能发生的不良相互作用，应权衡利弊，为患者确定更加合理的药物治疗方案。
