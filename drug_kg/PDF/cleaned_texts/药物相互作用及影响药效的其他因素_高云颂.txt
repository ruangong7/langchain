药物相互作用，是影响药效的重要因素之一。从临床意义来讲，药物相互作用有有益的一面，也有有害的一面。探讨药物相互作用，就是为了充分发挥联合用药时有益的作用，扼制有害的作用，以达到合理的联合用药。影响药物效应的因素还有年龄、性别、精神、疾病及个体差异等。 因此，在临床用药过程中，应全面考虑药物效应问题，以使用药安全有效。
1.1.4 对药物排泄的影响药物通过肾脏排出时，有的经肾小管滤过而排出，有的则由肾小管分泌而排出。无论哪种形式排出，联合用药时，易排泄者可因竞争而使较不易排泄者滞留，使其增效或增强毒性反应。如丙磺舒可减少头孢菌素类的排泄而增效，也可减少甲氨蝶呤的排泄而加剧其毒性反应。 两种酸性或碱性药物同用，可出现竞争性抑制，使其中一种药物排泄减少，因而易出现药物蓄积而改变药效。
1 药物相互作用及其影响
1.1 药动学的相互作用一种药物因与其他药物联用而在吸收、分布、代谢、排泄等过程中受到影响，致使体内药量增减而使药效增强或减弱，即药动学的相互作用。
1.2 药效学的相互作用
1.2.1 生理性拮抗与协同服用催眠镇静药后大量饮酒会加重中枢神经抑制作用；反之，喝茶或咖啡能减轻中枢神经抑制作用。 抗凝血药华法林与抗血小板药阿司匹林合用，其抗凝作用增强，可引起出血。
1.1.1 对药物吸收的影响应用抗酸药，如 -受体阻滞剂、质子泵抑制剂及碱性制酸药，可明显提高胃中$\mathrm { p H }$ ，这样可减少在酸性环境中易被吸收药物的吸收量。胃肠动力药如西沙必利可增强胃肠蠕动，减少某些药物的吸收，尤其对有固定吸收部位的药物，如维生素等影响更明显。 抗胆碱药可抑制胃肠蠕动，使某些药物增加吸收而增强疗效。 多价金属离子可与四环素络合而影响其吸收。
1.2.2 受体的协同与拮抗 β-受体阻滞剂与肾上腺素合用，可导致严重高血压危象；许多抗组胺药如酚噻嗪类及三环抗抑郁药，都有抗 -胆碱作用，若与阿托品类药物合用，可引起精神错乱、记忆紊乱等不良反应。
1.2.3 干扰神经递质的转运三环类抗抑郁药可抑制儿茶酚胺的再摄取，增加肾上腺素及其拟似药如酪胺） 的升压反应，而抑制可乐定和甲基多巴的中枢神经降压作用。
1.1.2 对药物分布的影响在此只讲竞争血浆蛋白的问题。对血浆蛋白亲和力强的药物，可置换亲和力弱的药物，而使后者游离型药物增多，药效增强。 竞争血浆蛋白可引起药物分布容积、 $\cdot ^ { \mathrm { t 1 } / 2 }$ 、清除速率等一系列改变，其结果是药物效应和某些不良反应均发生改变。例如，氯贝丁酯、阿司匹林、吲哚美辛、依他尼酸等与降糖药、口服抗凝药合用，可使后者游离型血药浓度升高，药效增强，甚至出现低血糖或出血倾向，应引起注意。
为充分发挥药物相互作用的有益之处，避免不良作用，临床用药品种应尽量精简，除有一定的临床指征外，优先考虑单品种用药。 联合用药时，要有明确的临床指征，更要清楚地了解药物之间在药理、药效及理化特性等方面的相互关系，以达理想的治疗效果。
2 影响药效的其他因素
1.1.3 对药物代谢的影响主要有酶抑作用和酶促作用。药物在体内的代谢多由酶催化，主要是肝微粒体代谢酶，也称药酶。 药酶受抑或受促，可导致其他药物体内代谢的改变，进而引起药效的增强或减弱。
2.1 年龄小儿（ 特别是新生儿和早产儿） 机体各种生理功能，包括自身调节功能尚未完善，药物清除率低，对药物一般比较敏感。 例如，新生儿的肾功能只有成人的 ％，庆大霉素的 $\mathbf { t } ^ { 1 / 2 }$ 可达 ，是成人的倍。 新生儿肝脏葡萄糖醛酸结合能力尚不强，应用氯霉素可导致灰婴综合征。但是，中枢神经兴奋药对多动性儿童常有镇静作用，可使儿童过多的活动减少，使其注意力集中，因而能治疗多动症。老年人血浆蛋白结合率低，水溶性药物分布容积较小，脂溶性药物分布容积较大，肝肾功能减退，故药物清除率下降， $\mathbf { t } ^ { 1 / 2 }$ 延长。 例如，在肝脏灭活的地西泮，其 $\mathbf { t } ^ { 1 / 2 }$ 可延长倍，达到。 老年人对许多药物敏感，例如中枢神经兴奋药可导致老人精神错乱，抗 -胆碱药可导致尿潴留、大便秘结，诱发青光眼等。
具有酶抑作用的药物可增强其他药物的效应，常用的如胺碘酮、地尔硫 、维拉帕米、普萘洛尔、美托洛尔、红霉素、氯霉素、环丙沙星、甲氧苄啶、甲硝唑、酮康唑等，在联合用药时应谨慎。
具有酶促作用的药物可加速其他药物的代谢而降低效应，但对某些前体药物则可加速其转化而使药效增强。常用药物有苯巴比妥、苯妥英钠、格鲁米特、卡马西平、利福平等。

2.2 性别男性对乙酰氨基酚（ 扑热息痛） 及阿司匹林的清除率分别高于女性40％～60％；女性在月经期对泻药、刺激性较强的药和能引起子宫收缩的药比较敏感；在妊娠期，多数药物能通过胎盘进入胎儿体内；在分娩期，药物可在新生儿体内滞留；在哺乳期则可通过乳汁被乳儿吸收而引起药物反应。
2.7 时间因素许多药物效应与应用时间有关。中枢神经系统药物、心血管药物、内分泌药物、抗肿瘤药、抗生素、平喘药等，均有昼夜节律变化。例如，肾上腺皮质激素，体内浓度在早晨时左右最高，以后逐渐下降，至时最低。 临床上根据这一规律，改为每天早时给足全日量，明显提高了疗效，不良反应也有所减轻。药物在体内的毒性也与时间有关，经动物实验证明：药物在时左右毒性最高，而在晨时毒性最低。 机体对药物的吸收也与时间有关， 例服用茶碱治疗哮喘，结果早晨服药的血药浓度明显高于晚间服药。
2.3 个体差异有些个体对药物特别敏感，所需剂量远低于常用量，称为高敏性；而另一些个体对药物则不敏感，用药量须大于正常量才能发挥效应，称为低敏性或耐受性。耐受性有先天耐受性和后天耐受性之分。若按耐受性的机制，又可分为药效耐受性和代谢耐受性。由于受体数目减少，使药物反应降低所致者为药效耐受性；由于肝药酶活性被诱导增强所致者为代谢耐受性。高敏性和耐受性对药效及不良反应有重大影响，在药物临床应用中，应重视这一因素。
2.8 某些药物因素不少药物可以产生生理依赖性成瘾 ，如可待因、吗啡、哌替啶等。即使是常用的药物如阿司匹林也可产生心理依赖性习惯性 。 有些药物虽不成瘾，但往往耐受性加大，须加大剂量才能发挥效用，如硝酸甘油制剂，长期持续使用往往疗效降低，甚至失效，须停用一段时间才能恢复作用，所以，目前临床上主张间歇用药。 长期应用 β-受体阻滞剂可引起细胞的受体数量增加，突然停用可使去甲肾上腺素与过多的受体结合，引起病情加重，发生反跳，甚至导致心肌梗死。所以，应该逐渐减量，然后停用，才能保证治疗效果。
2.4 精神因素病人的心理活动变化对药物的疗效常发生影响。 临床上常用安慰剂对照实验法以排除其对药物效应的影响及评价药物疗效的可靠程度。 安慰剂并不具药理活性如含乳糖或淀粉的片剂，含盐水的注射剂等 ，外观上则与具有药理活性的药物完全相同。安慰剂在新药临床研究的双盲对照中极其重要，可以排除假阳性疗效和假阳性不良反应。 安慰剂对任何病人都可能取得阳性效果，因此，医生可用安慰剂治疗某些非器质性疾病，但不能单用安慰剂作出真病或假病心理性疾病的诊断。
