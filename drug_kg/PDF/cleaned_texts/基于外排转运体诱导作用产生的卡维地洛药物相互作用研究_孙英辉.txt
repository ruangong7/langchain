In clinical combined administration，corresponding adjustment of drug dosage should be considered.卡维地洛是一种血管扩张性非心脏选择性 β 受体阻滞药，对脂质代谢也有良好影响［］。 临床上常与他汀类药物联合使用治疗高血压合并血脂异常类疾病。 研究发现，卡维地洛与瑞舒伐他汀联用时，比格犬体内瑞舒伐他汀的血浆暴露量显著降低，这可能与外排转运体相关［］。 外排转运体在肠上皮细胞和肝、肾小管细胞高表达，可调节药物的吸收、分布、排泄、药效和毒性［ ］，研究卡维地洛基于外排转运体介导的药物相互作用机制对患者的药效和安全性尤为重要。 本研究以细胞模型和大鼠为研究对象，考察卡维地洛对外排转运体蛋白表达和转运功能的影响，以探讨卡维地洛是否会通过调控外排转运体导致药物相互作用，为其在临床的合理用药提供理论依据。

外排转运体在体内分布广泛，在口服药物吸收途径中有很高的参与度［］，因此其表达水平的变化对研究药物间的相互作用十分重要， 细胞是体外诱导抑制转运体研究的有效工具［ ］。 本研究应用细胞结合大鼠体内药代动力学发现了卡维地洛是 $\mathrm { P - \mathrm { g p } }$ 和的诱导药，能显著上调 $\mathrm { P } - \mathrm { g p }$ 和蛋白表达水平和转运活性。 当其与上述转运体的其他底物类和抑制剂药联用时会发生相互作用，继而影响上述药物的血药浓度乃至药效。 本研究提出并证实，卡维地洛作为 $\mathrm { P } - \mathrm { g p }$ 和的诱导药在与其对应底物合并用药时的潜在风险和机制。 提示卡维地洛在临床上联合用药时有必要考虑这种相互作用，并考虑对用药剂量作出相应调整。 但具体剂量调整情况还需临床研究进行验证。
非索非那定是一种选择性组胺受体拮抗药，广泛用于鼻炎和慢性荨麻疹的治疗，同时也是 $\mathrm { P } - \mathrm { g p }$ 的典型底物。 本研究发现卡维地洛能够增强 $\mathrm { \mathrm { ~ P ~ - ~ } g p }$ 的外排活性，当非索非那定与卡维地洛联用时导致非索非那定的 $C _ { \mathrm { m a x } } \setminus t _ { \mathrm { m a x } }$ 和 $\mathrm { A U C } _ { 0 - 2 4 \mathrm { ~ h ~ } }$ 均发生显著性降低，提示临床中当高血压合并荨麻疹或鼻炎患者同时应用卡维地洛和非索非那定时可观察二者合用时的药效以保证抗过敏疗效或者采用替代疗法更换为其他抗过敏药物。
此外， $\mathrm { \Delta \mathrm { J } - \mathrm { g p } }$ 和酶在许多组织中具有高底物重叠率且都受和受体的调控［ ］，当 $\mathrm { P - \mathrm { g p } }$ 和酶活性受到抑制或诱导时将会发生二者共同介导的药物相互作用［ ］。 因此，当卡维地洛与上述药物联用时应注意 $\mathrm { P - \mathrm { g p } }$ 和的表达和活性变化，并可能需要相应调整临床给药剂量; 这为临床用药的管理策略提供了新的见解，揭示了转运体介导的药物相互作用的临床意义，为临床合理用药提供了有效参考。
