1 资料与方法
1. 1 数据来源
本研究数据来源于 FDA 公众健康项目( openF-DA) 数据库［15］，其 ADEs 原始数据由 FAERS 导入［16］。 FAERS 收集发生在美国境内外用药相关的自发性安全报告及上市后临床研究报告，其所有ADEs 数据采用国际医学用语词典( medical dictiona-ry for drug regulatory activities，MedDRA) 的首选术语( preferred terms，PT) 编码 。
2 月18 日，国家卫生健康委员会发布 《新型冠状病毒肺炎诊疗方案( 试行第六版) 》，建议试用磷酸氯喹用于抗病毒治疗［2］。 氯喹为 4-氨基喹啉类抗疟药。 近些年来，多项研究证实氯喹是一种潜力广阔的广谱抗病毒药物，能够有效抑制 SARS-CoV［3-4］、 人类免疫缺陷病毒 ( HIV) ［5］、 流感病毒［6］、 登革热病毒［7］ 和基孔肯雅病毒［8］ 等感染 。近日 《CELL RESEARCH》 期刊报道，氯喹和瑞德西韦在细胞水平上能够有效抑制 COVID-19 感染。研究发现，氯喹有效浓度 ( $\operatorname { E C } _ { 9 0 } { \big ) }$ 为 6. 9 μmol ·L－ 1 ，提示可以使用氯喹常规剂量治疗 COVID-19 ［9］。 氯喹对 COVID-19 等病毒的抑制机制可能为: 提高 pH 值以抑制病毒侵入细胞的过程，以及改变病毒包膜糖基化以阻断病毒在细胞内复制［10］ 。
1.2 数据处理
本研究采用 ResearchAE 分析工具提取数据，该分析站点通过对接应用程序接口( API) 直接提取OpenFDA 数据库中结构化的 ADEs 报告信息［17］，选择药品 ADEs 模块，限定时间为 “2004 /01 /01 ” 至“2020 /02 /22 / ” ，限定目标药物通用名 ( GenericName) 为 “CHLOROQUINE”得到目标药物氯喹为首要怀疑药物的 ADEs 报告。 提取报告数排名前 250位的 ADEs 报告，计算评价 ADEs 与氯喹的相关性。为提高信号检测结果的可靠性，本研究不纳入药物适应证相关的报告数据。
但是氯喹的不良反应不容忽视，其会导致头晕、头痛、胃肠不适和皮肤瘙痒等不良反应，且对皮肤、视网膜、心脏和神经系统等有剂量依赖性毒副作用［11］，高剂量使用可能导致急性致死［12］ 。 《新型冠状病毒肺炎诊疗方案( 试行第七版) 》进一步调整磷酸氯喹的用法用量［13］。 因此，亟须深入挖掘和掌握氯喹相关不良反应，在 COVID-19 治疗过程中有效避免氯喹相关药害事件并保证患者安全。
1. 3 信号检测方法
比值失衡测量法是国际上常用的 ADEs 信号挖掘方法，分为频数法和贝叶斯法两大类［18］。 前者包括报告比值比法( ROR) 、比例报告比值比法( PRR) 、综合标准法( MHRA) ，后者有贝叶斯可信区间递进神经网络法( BCPNN) 与相对比值法等［19-20］。 本研究采用 ROR、BCPNN 两种方法进行信号检测［21-22］，当两种算法均呈阳性，则判断为可疑信号。 信号检测标准见表1，比值失衡测量法算法原理见表2。
自发呈报系统是目前世界上监测药物不良反应( adverse drug reaction，ADR) 和发现 ADR 信号的最基本方法。 通过有效分析手段，我们不仅能够及时发现氯喹的 ADR 信号、挖掘出潜在不良反应，而且有效预防和避免氯喹相关药害事件［14］。 本实验通过数据挖掘( data mining) 技术对美国食品药品监督管理局( Food and Drug Administration，FDA) 自发呈报系统———FDA 不良事件报告系统( FDA adverse e-vent reporting system，FAERS) 中氯喹上市后的不良事件( adverse events，ADEs) 报告进行信号提取 、 计算和分析，得到已知高危安全性信号和潜在高危安全性信号，为临床安全使用氯喹提供数据参考。

3 讨论
3. 2 心脏毒性和低钾血症
目前，ADEs 信号检测常用的信号挖掘方法中频数法计算简单且灵敏度高，但在报告数量较少时容易产生假阳性信号。 贝叶斯法稳定性好，但是计算复杂，信号检出时间相对滞后［25］。 结合不同的信号挖掘方法能够提高 ADRs 信号检测的灵敏度和特异度，并降低假阳性率［26］。 因此，本研究同时使用了 ROR 法和 BCPNN 法，以提高信号检测结果的可靠性 。
氯喹的安全窗口较窄，服用过量会导致中毒。其致死剂量为 $3 0 \sim 5 0 ~ \mathrm { m g ~ ^ { \bullet } ~ k g ^ { \mathrm { ~ - 1 ~ } [ 2 7 ] } }$ ］，而成人致死剂量为 2 ～ 4 g ［12］。 氯喹中毒临床表现为嗜睡、 视觉障碍、心脏毒性和低钾血症。 过量服用1 ～ 3 h 后会导致心脏骤停。 氯喹对心肌毒性的机制类似于奎尼丁，产生负性肌力作用，抑制自发性舒张期去极化，导致传导减慢、有效不应期延长、QT 节段和 QRS 间隔延长等，并导致心排出量及脑循环血量减少，而产生昏厥及抽搐［28］。 上述报道与本研究中氯喹心脏器官 ADEs 结果一致。
3. 1 ADEs 概况
在氯喹为首要怀疑药物的 557 份 ADEs 报告中，前20 位 ADEs 信号有发热、呕吐、恶心、呼吸困难、头痛、肺炎、无力、完全性房室传导阻滞、疲劳、头晕、心脏骤停及低钾血症等，建议临床医务工作者对表 4 中的不良反应给予重点监测。 本研究利用ROR 和 BCPNN 两种方法检测和分析 FAERS 中氯喹不良反应信号后发现: ①与氯喹说明书警示内容一致的 ADEs 信号包括: 胃肠系统疾病( 呕吐) ，眼器官疾病( 失明、眼花) ，皮肤及皮下组织类疾病( 脱发) ，神经系统疾病( 自杀死亡、意识丧失、躁狂、企图自杀、昏迷、困倦及惊厥) 等。 此外，说明书虽提及氯喹偶可引起窦房结的抑制，导致心律失常、休克，严重时可发生阿-斯综合征，但是未详细阐述氯喹相关的心脏器官不良反应。 本研究分析结果显示，氯喹与完全性房室传导阻滞、心室纤维性颤动、心脏毒性、心室肥大、心电图 QRS 波群延长、心电图QT 延长、心源性休克、心跳呼吸停止和限制性心肌病等心脏器官不良反应相关。 ②氯喹说明书尚未收录的 ADEs 信号有: 全身性疾病及给药部位各种反应( 发热、无力、缺氧、苍白和多器官衰竭) ，代谢及营养类疾病( 低钾血症) ，呼吸系统、胸及纵隔疾病( 胸腔积液) ，血管与淋巴管类疾病( 低血压、高铁血红蛋白血症) ，各种肌肉骨骼及结缔组织疾病( 肌无力) ，肾脏及泌尿系统疾病( 急性肾衰竭) 。 本研究重点针对严重的 ADEs 及药品说明书未收录的ADEs 进行分析。
本研究分析结果显示，低钾血症( ROR = 4. 18，IC-2SD =1. 51) 与氯喹相关但是尚未在氯喹药品说明书中收录。 低钾血症发生基机制为氯喹致使细胞外的钾向细胞内转移，其严重程度与毒性密切相关［29］。 因此，在使用氯喹的过程中，医务人员应密切监护 COVID-19 患者的心率、心律、血压、血氧饱和度、电解质、心电图和心脏彩超等指标，并密切关注联合用药。
3. 3 肾毒性
长期服用氯喹会导致肾脏功能紊乱和组织异常［30］。 本研究分析结果中，急性肾衰竭 ( ROR =3. 08，IC-2SD = 0. 30) 尚未在氯喹药品说明书中收录。 Abdulkadir 等［31］发现氯喹和乙醇联合使用可能通过结构损伤和功能紊乱而引起肾脏损伤。 与对照组相比，联合给药组的近端肾小管直径增加( P =0. 142 6) ，上皮肥大( $P = 0 . 2 5 3 \ 0 )$ ，尿路萎缩( P =0. 000 01) ，且尿量显著减少( $P = 0 . 0 0 2 \ 9 )$ 。 因此，在使用氯喹的过程中，医务人员应对 COVID-19 患者( 特别对有饮酒史) 的肾功能进行密切监护，并在联合用药中谨慎选择肾毒性较小的药物。
3. 4 肌无力等其他 ADEs
本研究分析结果中，发热( ROR =1. 80，IC-2SD =1. 84) 无力 $\left( \mathrm { \ R O R } = 1 . 9 8 , \mathrm { I C - 2 S D } = 1 . 6 5 \right)$ 肌无力$\left( \mathrm { \ R O R } = 1 . 4 9 , \mathrm { I C - 2 S D } = 2 . 1 3 \right)$ 和高铁血红蛋白血症$\left( \mathrm { \ R O R } = 4 . 3 7 , \mathrm { I C - 2 S D } = 0 . 0 3 \right)$ 尚未在氯喹药品说明书中收录。 目前已报道，氯喹偶导致头晕、头痛、失眠或精神焦虑等神经系统ADEs，通常在停药后自行缓解。 文献［30］报道，长期服用氯喹的患者可能产生神经肌肉病变，临床变现为肌无力、麻木及四肢末端感觉异常等。 此外，Rizvi 等报道一名 25 岁患者在服用600 mg 氯喹后，发烧，昏迷，嘴唇、舌头、口腔、指甲床和指尖出现深紫色，血红蛋白水平为54%，诊断为氯喹导致的高铁血红蛋白血症。 给予亚甲蓝( $1 \ \mathrm { m g \cdot k g ^ { - 1 } } )$ 后，病人明显好转［32］ 。
4 结论
本研究基于药物不良事件自发呈报系统，挖掘出了临床研究警示及氯喹药品说明书提示的心脏器官( 完全性房室传导阻滞、心室纤维性颤动、心脏毒性、心室肥大、心电图 QRS 波群延长、心电图 QT 延长、心源性休克、心跳呼吸停止和限制性心肌病) ，胃肠系统疾病( 呕吐) ，眼器官疾病( 失明、眼花) ，皮肤及皮下组织类疾病( 脱发) ，神经系统疾病( 自杀死亡、意识丧失、 躁狂、 企图自杀、 昏迷、 困倦和惊厥) 等安全问题，对此建议临床医务人员针对上述不良反应进行重点监护，预防发生和进展。 另外，本研究分析得出氯喹对全身性疾病及给药部位各种反应( 发热、无力、缺氧、苍白和多器官衰竭) ，代谢及营养类疾病( 低钾血症) ，呼吸系统、胸及纵隔疾病( 胸腔积液) ，血管与淋巴管类疾病( 低血压、高铁血红蛋白血症) ，各种肌肉骨骼及结缔组织疾病( 肌无力) ，肾脏及泌尿系统疾病( 急性肾衰竭) 等多个说明书未收录的不良反应信号，建议临床应用氯喹时重点关注，警惕类似不良反应的发生。 此外，本研究分析得出新的氯喹相关不良反应信号需要经过更多的临床研究进行系统研究和评估。
另外，本研究分析结果所得其他 ADEs: 低血压$\left( \mathrm { \ R O R } = 1 . 4 7 , \mathrm { I C - 2 S D } = 1 . 1 4 \right)$ 、胸腔积液 $\mathrm { \ : ( \ R O R = }$ $1 . 8 2 , \mathrm { I C - 2 S D } = 0 . 5 7 )$ 、 缺氧 ( $\mathrm { R O R } = 6 . 0 5 , \mathrm { I C - 2 S D } =$ 1. 65) 、 苍白( $\mathrm { R O R } = 2 . 4 6 , \mathrm { I C - 2 S D } = 0 . 3 1 )$ ) 和多器官衰竭( $\mathrm { R O R } = 1 . 8 1 , \mathrm { I C - 2 S D } = 0 . 0 2 )$ 均未收录于氯喹药品说明书。 建议医务人员在临床使用中密切监护COVID-19 患者并预防上述不良反应的发生。
3. 5 剂量累积与安全性
眼部病变是氯喹主要的不良反应。 它分为可逆( 角膜沉积、眼调节反射障碍等) 与不可逆两类。 角膜沉积最为常见且与剂量相关，主要原因是氯喹在角膜上皮沉积。 而视网膜病变是最严重的不可逆型不良反应，发生率约为 10%［30］。 美国眼科学会认为氯喹不良反应与其服用剂量和时间相关，建议氯喹日最大安全剂量为 $2 . 3 ~ \mathrm { m g } \cdot \mathrm { k g } ^ { - 1 }$ 。 其定义氯喹相关视网膜病变高危患者( 以下任一项) : ①服用时间＞5 年; ②累积剂量 $> 4 6 0 \mathrm { ~ g ~ }$ 或日剂量 $> 2 5 0 \ \mathrm { m g \cdot d ^ { - 1 } }$ 或日剂量 $> 2 . 3 \mathrm { \ m g \bullet \ k g ^ { - 1 } \bullet \ d ^ { - 1 } } ;$ ; ③老年患者或肝肾不全患者。 建议视网膜病变高危患者定时进行眼部相关疾病筛查［24，33］。 另有报道，氯喹总剂量达到 100g 或服用 $2 5 0 \ \mathrm { m g \cdot d ^ { - 1 } }$ 达 1 年以上的与视网膜病变相关［34］ 。
由于本研究信号检测基于自发呈报数据库，而自发呈报可能存在漏报和重复报告等问题。 另外，数据库缺少基础用药人口数据，难以计算实际ADEs的发生率。 尽管如此，利用自发呈报系统数据库进行氯喹安全信号的检测与分析，能够为抗击新冠肺炎的疫情阻击战中用药决策和安全性评估提供有价值的参考和建议，有望有效避免氯喹相关药害事件并保证患者安全。
3. 6 药物相互作用
《新型冠状病毒肺炎诊疗方案( 试行第七版) 》推荐试用 α-干扰素、 洛匹那韦/利托那韦、 利巴韦林、磷酸氯喹和阿比多尔用于治疗 COVID-19，且不建议同时应用3 种以上抗病毒药物。 其中，利巴韦林会引起心脏骤停和溶血性贫血，洛匹那韦/利托那韦会导致 PR 间期延长，因此不建议氯喹与上述 2种药物联合使用。 在抗菌治疗中，由于喹诺酮类抗生素和大环内酯类抗生素均会导致 QT 间期延长，万古霉素会导致耳毒性和肝肾毒性等，因此不建议氯喹与上述抗感染药物联合使用。 此外，链霉素会加重氯喹对神经肌肉接头的直接抑制作用。 因此，临床医务人员在合并用药时应结合氯喹相关不良反应，密切注意患者是否有基础疾病和配伍禁忌( 表6) ，预防不良反应的发生和加重。
