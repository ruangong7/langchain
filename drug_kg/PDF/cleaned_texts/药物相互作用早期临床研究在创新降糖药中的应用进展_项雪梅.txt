1 研究类型选择
1.1 指针药物DDI 临床研究
在 DDI 临床研究始前研究者可根据体外数据得到代谢酶或转运体在创新降糖药的吸收分布代谢排泄过程中的贡献据此确定进行指针药物 DDI 临床研究的必要性指针药物研究针对定的代谢途径考察了体内发生 DDI 最严重的情况且试验结果可外推至具有相酶或转运体途径的药物[7] FDA 官网对不同代谢酶/转运体使用何种指针药物有推 [8] 近 5 年发表的部分创新降糖药 DDI 指针药物临床研究汇总见表 1
1.2 临床合并用药的DDI 研究

1.3 DDI 模拟研究
在有试验药物药代动力学（PK）数据的情况下可以过建立基于生理的药代动力学（PBPK）模型来进行 DDI 模拟研究以到豁免部分 DDI 临床试验的目 $\hat { \mathsf { H } } \hat { \mathsf { J } } ^ { [ 3 2 ] } ($ 查阅 2021 年 FDA 批准上市的 50 个新药评报 [33] 共 15 个创新药物在 DDI 临床研究中使用了 PBPK 模拟的方法主要中于经代谢酶或转运体介的 DDI 主要解决的问题为（1）在体内进行强效指针抑制剂和诱剂的 DDI 临床研究后模拟中效和弱效指针抑制剂和诱剂的 DDI临床研究研究结果可支持剂量调整 （2）在体内进行低剂量指针药物研究使用 PBPK模拟创新药或指针药物在更高剂量下的 DDI 情况； （3） 在进行DDI 临床研究前预测体内 DDI 的大以支持是否展 DDI 临床研究决策
2 研究人群和样本量的确定
常选择在健康男性和女性受试者中进行创新降糖药 DDI 临床研究殊情况下如果出于安全性考虑或为取得些药效动力学（PD）研究指标不适于在健康人群中展时也可选择在 2 型糖尿病患者中进行如新型葡萄糖激酶激动剂 Piragliatin与辛伐他汀格列脲的 DDI 临床研究[34，35]纳入 2型糖尿病患者作为研究对象 ， 因 Piragliatin 25 mg即可使健康受试者腹血糖降低 20% 而糖尿病患者服用 $2 0 0 \mathrm { m g }$ 仍然有较好的耐受性和有效性为考察最大剂量下的 DDI 程选择健康受试者是不太合适的因此试验在患者中进行在般情况下DDI 受试者样本量的计算应考虑 DDI 程大和考虑受试者个体内和脱落率的影响若要得到双向 DDI 研究结果可加入另相互作用药物的单药阶段完成 PK/PD 采样如在恒格列净与甲双胍的 DDI 临床研究中[38] 完成了 3个周期的 PK 采分别为甲双胍单药恒格列净稳态后及恒格列净合甲双胍给药阶段才可得到恒格列净和甲双胍是否有 PK 相互作用的结论 。

4 给药方案
4.1 给药剂量
根据 FDA 颁的 DDI 指则为观察到最大程的药物相互作用促药应在安全的前提下使用推荐给药方案中的最大剂量和最短给药隔
5 DDI 临床研究实施
5.1 保障安全性
对于 GLP-1 受体激动剂很多研究采用滴定给药的策略[37，43] 即从剂量始逐步滴定至目标剂量这样的给药方是基于该类药物普遍具有胃肠道不耐受的不良反应为提高受试者依从性以及出于理考虑建议采用滴定给药设计
4.2 给药方式
4 2 1 单次/稳态给药般情况下促药和受药均推在稳态条件下进行 DDI 评估由于阶段酶抑制剂的合用致使受药半衰期增加此时需延长受药的给药时以确保到稳态可设置稳态谷采血以查受试者多服药的依从性若底物药物是长半衰期药物则促药应持给药至底物药物的 3\~5 倍半衰期在项评估格列净与华法地高辛的 DDI 临床研究中[44] 地高辛华法均采用单给药格列净多给药稳态因是地高辛和华法相比格列净具有更长的半衰期。
（4） 注胃肠道不良事件患者在服用甲双胍或 GLP-1 受体激动剂类降糖药时常伴有恶呕吐食欲减退等胃肠道不耐受现象但般会在多给药后耐受在康受试者身上也有类的效果。因此应注重对受试者的宣教降低其恐惧理。
7 结语
DDI 临床研究是创新降糖药研发和上市前的风险获益评估中很重要的部分各指则的出促使 DDI 临床研究成为种常规要求不同的需求和药物性使得创新降糖药的 DDI 临床研究有着设计多样化的故可根据身研究目的和产品性选择最合适的设计方法展 DDI 临床研究在该项研究中应在保证受试者安全性的基本要求上追求 DDI 结果的精确性同时考虑效率与经济性符合伦理要求保障受试者权益对于创新生物制剂类降糖药还应尤其注免疫性的监测及免疫系统不良事件对于注射类药物还要注注射部位的反应
5.2 加强受试者管理
在 DDI 临床研究中由于研究目的是为了得到药物单用和合用状态下的 PK 参数的化是否具有统计学差因此单用和联用阶段的受试者饮食应尽量保持致以减少对研究结果的外部干扰
6 试验结果的解读
6.1 药代动力学指标
在各指南和文献中 DDI 临床研究常推荐$\mathrm { A U C } _ { \mathrm { 0 - i n f } }$ 及 $C _ { \mathrm { m a x } }$ 等 PK 参数作为终指标在合及不合使用促药时 PK 参数的均值比 90%置信区处于 80%\~125%时可以为 DDI 无临床意义[1-3] 。
6.2 药效学指标
甲双胍依赖于有阳离子转运体 （OCT1）的肝窦摄取而肝脏是发挥甲双胍降糖作用和产生罕见的严重毒性-乳酸酸中毒的主要部位另外它主要是过转运体 OCT2/多药及毒性化合物外排转运体 （MATEs）1/2-K 被肾管主动转运清除[45]有报道表明甲双胍的疗效和毒性的改与全身暴露化不完全相 [46] 因此过进行口服葡萄糖耐量试验（OGTT）来评估甲双胍的降血糖作用用该 PD 参数对 PK 指标进行补充是比较合适的[47]在项评估依格列汀与甲双胍的 DDI 研究中以给药前进行 OGTT 试验结果作为基线在每阶段给药稳态再进行 OGTT 试验评价指标可以描为相对基线血糖-时曲线下面积的减少 ΔAUGC 以及血糖峰值差值 $\Delta G _ { \mathrm { m a x } }$ OGTT 无效应边界为 0.75\~1.33[47]另外华法常用的 PD 指标为 INR-时曲线下面积的增量 $\mathrm { i A U C } _ { \mathrm { I N R } }$ 以及 $\mathrm { I N R } _ { \mathrm { m a x } } ^ { [ 3 7 , 4 4 ] }$ 在 DPP-4i类创新降糖药的 DDI 临床研究中常常采用 DPP-4i 单独使用阶段及与其他药物合用阶段的血浆DPP-4 活性的效应-时曲线下面积作为 PD 终对于 SGLT-2i 类创新降糖药的 DDI 临床研究常常进行每个时段内尿糖排泄（UGE） 测作为PD 指标[41 ，42]
