塞来昔布潜在不良药物相互作用处方调查及对策
( 安徽省蚌埠市第三人民医院药学部，蚌埠 233000)摘要目的分析塞来昔布潜在不良药物相互作用( pADIs) ，促进合理用药。 方法通过医院合理用药软件系统抽取 2020 年 1 月 1 日—12 月 31 日安徽省蚌埠市第三人民医院塞来昔布联合用药的所有门诊处方，鉴别 pADIs，并对$\mathrm { p A D I s }$ 危险严重性进行分级。 结果共收集塞来昔布胶囊联合用药处方 705 张，存在 $\mathrm { p A D I s }$ 处方 169 张( 占 24．0%) ${ \bf \tt p A - }$ DIs 发生频次 213 次。 其中塞来昔布与非甾体抗炎药、来氟米特与血管紧张素转换酶抑制药或血管紧张素 Ⅱ 受体拮抗药$\mathrm { p A D I s }$ 发生频次居前 3 位。 塞来昔布+非甾体抗炎药危险严重性分级为“禁忌”。 结论该院塞来昔布胶囊与其他药物存在 pADIs，医院应当加强塞来昔布胶囊 pADIs 风险点培训，采取信息化平台进行 $\mathrm { p A D I s }$ 警示，以减少和防范用药风险。

Prescription Investigation of Celecoxib Potential Adverse Drug Interactions and Countermeasures
CHENG Jun( Department of Pharmacy，the Third People＇s Hospital of Bengbu，Anhui Province，Bengbu 233000， China)ABSTRACT Objective To analyze the prescription of celecoxib potential adverse drug interactions( pADIs) and to promote rational drug use． Methods Outpatient prescriptions of using celecoxib in combination with other drugs were surveyed from January 1，2020 to December 31，2020 through the third people＇s hospital of Bengbu rational drug software system．And pADIs were identified and classified into categories of potential clinical outcomes． Results A total of 705 prescriptions of celecoxib capsules in combination with other drugs were collected and enrolled．There were 169 prescriptions for pADIs，which occurred 213 times for pADIs． Potential adverse drugs interacting with celecoxib capsules were mainly nonsteroidal anti-inflammatory drugs ( NSAIDs) ，leflunomide，and angiotensin-converting enzyme inhibitors ( ACEIs) or angiotensin II receptor blockers( ARBs) ．The severity of interaction between celecoxib and NSAIDs was determined by “Contraindications ”． Conclusion There were pADIs between celecoxib capsules and other drugs in our hospital．Therefore，it is necessary to strengthen risk training of celecoxib capsules pADIs，set medication rules through rational drug use software，and give interception or warning respectively in the electronic prescription window of doctor workstation to reduce medication risk．塞来昔布为特异性选择性抑制环氧化酶-2 ( cy-clooxygenase-2，COX-2) 非甾体抗炎药物 ( nonsteroidalantiinflammatory drugs，NSAIDs) ，一般剂量下对 COX-1几乎无抑制作用，用药相对安全，临床应用非常广泛［1］ 。 目前，潜在不良药物相互作用( potential adversedrug interactions，pADIs) 已成为临床研究热点［2］ 。 有文献对 NSAIDs 的 pADIs 处方进行分析，主要以阿司匹林为主［3-4］，笔者尚未见深入研究塞来昔布 pADIs 及其危险严重性分级的报道。 笔者在本研究调查蚌埠市第三人民医院塞来昔布胶囊联合用药处方，收集处方中 pADIs，并对危险严重性进行分级，为采取应对策略提供依据。
1 资料与方法
利用医院合理用药软件系统调取 2020 年 1 月 1日—12 月31 日门诊塞来昔布胶囊所有联合用药处方( 处方用药≥2 种，其中一种为塞来昔布胶囊) 。 塞来昔布胶囊生产厂家为辉瑞制药有限公司。 利用 Excel2010 版软件，记录联合用药处方中患者就诊科室、姓名、性别、年龄、诊断结果等相关信息。 参考 Medscape药物相互作用数据库并结合药品说明书及用药助手应用程序( application，APP) ，统计 pADIs 处方数和相关药物，并对危险严重性进行分级［5］: 禁忌，相互作用可以威胁患者生命，联合使用是禁忌; 严重，相互作用可能威胁患者生命，和( 或) 需要一种替代药物，如果必须联用，需要干预去减少或预防严重不良反应; 中度，相互作用可能导致患者病情加重，需要严密监测; 轻度，相互作用临床效应有限，不需要替代药物。
2 结果
3 讨论
本调查发现，705 张塞来昔布胶囊联合用药处方中 ${ \bf \Omega } _ { \bf { \Lambda } } \mathbf { \Omega } _ { \bf { \Lambda } } \mathbf { \Omega } _ { \bf { \Lambda } } , { \bf { \Lambda } } \mathbf { \Omega } _ { \mathrm { { p A D I s } } }$ 处方 169 张，占 24．0%，患者分布在各年龄段，与多种药物存在 $\mathrm { p A D I s }$ ，虽未收集到相关不良反应报表，但需引起临床重视。
3．1 塞来昔布胶囊联合 NSAIDs 的 $\mathrm { p A D I s }$ 塞来昔布胶囊联合 $\mathrm { N S A I D s }$ 的 $\mathrm { p A D I s }$ 发生频次共 59 次，以阿司匹林与双氯芬酸钠主。 两种 NSAIDs 胃肠道毒性风险增加，其严重性分级为 “禁忌” 。 众所周知， $\mathrm { N S A I D s }$ 主要不良反应是胃肠道不良反应，两种 NSAIDs 联合使用，将产生药效学相互作用，胃肠道溃疡、出血和穿孔等发生风险显著增加［6］。 另外，实验研究证实，NSAIDs 显著干扰阿司匹林的抗血小板活性，可能与${ \mathrm { N S A I D s } }$ 与 $\mathrm { S e r } 5 3 0 \ 、 \mathrm { A r g } 1 2 0 \ 、 \mathrm { T y r } 3 8 5$ 和 COX-1 疏水通道的其他氨基酸形成氢键，干扰阿司匹林抗血小板活性有关［7］ 。
3．2 塞来昔布胶囊联合 CYP2C9 抑制药 $\mathrm { p A D I s }$ 塞来昔布胶囊联合来氟米特发生频次位居第二( 42 次，19．7%) ，主要集中在风湿免疫科，与其适应证有关。
塞来昔布与来氟米特常见不良反应之一为肝毒性，两种药物联合使用，将产生药效学相互作用，增加肝毒性潜在风险，其严重性分级为 “严重” 。 2001 年 3 月 12日，欧洲药物评审组织 ( The European Agency for theEvaluation of Medicinal Products，EMEA) 发布来氟米特致严重肝损伤公众申明［8］，129 例来氟米特引起严重肝损伤的报道中，101 例合并用药，而 NSAIDs 为主要联合药物之一; 2010 年 7 月 13 日，美国食品药品管理局( FDA) 再次发布来氟米特可导致严重肝损伤的安全通报［9］，49 例来氟米特引起严重肝损伤患者中，同时使用 NSAIDs 是其高风险因素之一。 此外，塞来昔布与来氟米特也会发生基于药动学的相互作用，来氟米特代谢物抑制肝微粒体酶 CYP2C9，而塞来昔布主要经肝微粒体酶 CYP2C9 代谢，两者联合使用也可能增加塞来昔布血药浓度，导致 $\mathrm { p A D I s }$ ［10］3．5 塞来昔布胶囊联合甲氨蝶呤 $\mathrm { p A D I s }$ 塞来昔布胶囊与甲氨蝶呤发生 $\mathrm { p A D I s } 2 0$ 次。 塞来昔布与甲氨蝶呤联合使用，能够增加甲氨蝶呤中毒的潜在风险。 体内动物实验结果表明［16］，塞来昔布通过抑制有机阴离子转运蛋白，影响甲氨蝶呤在肾小管的分泌，阻碍甲氨蝶呤的外排。 曲彩红等［17］报道 1 例类风湿关节炎患者接受来氟米特与低剂量甲氨蝶呤联合塞来昔布治疗，5周后出现肝、肾功能损害及骨髓抑制。 因此，临床医师对于类风湿关节炎等患者，在处方塞来昔布与来氟米特和( 或) 甲氨蝶呤药物联合时，要关注 $\mathrm { p A D I s }$ ，加强用药监测，以减少和避免不良反应。
3．3 塞来昔布胶囊联合血管紧张素转换酶抑制药( ACEI) 或血管紧张素受体抑制药( ARB) 或利尿药 $\mathrm { p A } -$ -DIs 塞来昔布胶囊联合 ACEI 或 ARB 发生频次位居第三( 38 次，17．8%) 。 其中，与 ACEI 或 ARB 发生 $\mathrm { p A D I s } 3 3$ 次，与利尿药发生 $\mathrm { p A D I s } 5$ 次。 两者发生 $\mathrm { p A D I s }$ 可能与肾脏前列腺素合成被塞来昔布抑制有关。 一项随机、双盲、安慰药对照的临床试验结果表明，塞来昔布对 ACEI治疗的高血压患者，与安慰药比较 24 h 内对抑制 ACEI的降压作用未见显著影响［11］，但该试验未进一步研究长期使用塞来昔布对 ACEI 的降压作用影响。 另一项随机双盲对照研究［12］，纳入了接受 ACEI 固定单药治疗的年龄≥65 岁骨关节炎患者，结果发现在联合使用塞来昔布治疗第 6 周时，6．9%患者收缩压增加，4．7%患者出现水肿;而在长期接受钙离子拮抗剂单药治疗的患者中，未发现患者收缩压变化或水肿。 另外，一项基于美国不良事件报告系统数据库的回顾性研究［13］，发现服用利尿药和( 或) ACEI 是患者肾损伤的高风险因素。 因此，对于长期使用塞来昔布与 ACEI 或利尿药的患者，应仔细监测血压及肾功能。
3．6 塞来昔布胶囊联合泼尼松或氯吡格雷 pADIs$\mathrm { p A D I s }$ 处方中，塞来昔布胶囊与皮质类固醇药物( 泼尼松) 发生 16 次。 一项纳入胃溃疡或十二指肠溃疡或上消化道出血的住院患者 1415 例的研究表明［18］，同时接受 NSAIDs 者使用皮质类固醇相对风险比为 4．4，而未接受 NSAID 者皮质类固醇相对风险比为 1．1。
另外，塞来昔布联合使用氯吡格雷 $\mathrm { p A D I s }$ 发生 9次。 氯吡格雷为抗血小板药物，而塞来昔布主要不良反应是消化道溃疡、出血、穿孔等，且会影响血小板聚集等。 塞来昔布与氯吡格雷联合使用，增加出血风险。检索国内外相关数据库，发现数例塞来昔布与干扰止血的药物( 华法林、氯吡格雷和达比加群酯) 相互作用引起脑和消化道等不同部位出血的个案报道［19-21］，需引起临床重视。
3．4 塞来昔布胶囊联合美托洛尔 pADIs 塞来昔布联合使用美托洛尔存在 pADIs，发生频次位居第四( 29次，13．6%) ，其严重性分级为 “中度” 。 塞来昔布是常见 CYP2D6 抑制药，美托洛尔是 CYP2D6 常见底物，塞来昔布会增加美托洛尔血浆浓度。 WERNER 等［14］研究了塞来昔布对美托洛尔药代学的影响，在 12 例健康男性志愿者中，使用塞来昔布( 200 mg，po，bid，连续 7d) 预处理后，给予美托洛尔( 50 mg 单剂) 后，其平均峰值血浆浓度( $C _ { \mathrm { m a x } } \vert$ 和浓度-时间曲线下面积( AUC) 与单独服用美托洛尔相比，分别增加了38%与和64%; 进一步研究发现，塞来昔布可以导致美托洛尔正常基因纯合子性快代谢者( extensive metabolizer，EM) AUC 增加 103%，而基因突变杂合子 EM 者仅增加 36%。 可见，美托洛尔基因多态性对药物相互作用的影响程度较大。 另外一项临床试验也得到了相似结果，患者应用塞来昔布剂量为 $4 0 0 \ \mathrm { m g \cdot d ^ { - 1 } }$ ，连续应用 7 d 后，正常基因纯合子 EM 者美托洛尔暴露量增加 2 倍，而突变杂合子 EM 者仅增加 1．4 倍［15］。 因此，塞来昔布联合CYP2D6 底物美托洛尔时，要加强心动过缓或低血压等监测 。
3．7 应对策略塞来昔布作为特异性选择性 NSAIDs，与传统非选择性非甾体抗炎药物比较，有较高的胃肠道安全性，但在心血管、肝脏及肾脏方面的安全性仍不可忽视［22-23］，尤其与其他药物联合使用时，因发生 $\mathrm { p A } -$ DIs 而增加其风险，更需要引起重视，必须加强用药安全性监测。 基于本研究调查结果，本院已在门诊医师工作站嵌入逸曜合理用药管理系统，在门诊医师工作站开具电子处方时，对于危险严重性进行分级为 “禁忌”，系统自动进行拦截; 对于危险严重性进行分级为“严重”或“中度”，以弹出提示框方式，实时提醒医师注意塞来昔布 pADIs 风险点。 另外，本院正在积极引进处方审核软件，协助药师加强处方审核及干预，临床药师也将有针对性地对全科医学科、免疫风湿科及血液科等相关临床科室加强塞来昔布 $\mathrm { p A D I s }$ 知识培训，以提高医师安全用药意识。
