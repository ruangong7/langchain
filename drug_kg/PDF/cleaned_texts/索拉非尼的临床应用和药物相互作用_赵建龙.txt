索拉非尼的临床应用和药物相互作用
Sorafenib on clinical application and drug interaction
摘要: 索拉非尼是一种多靶点的酪氨酸激酶抑制剂，主要治疗晚期肾癌、肝癌。药物 － 药物相互作用引起的索拉非尼的药代动力学的变化可能影响其临床效果和安全性，个体化的治疗药物监测可以控制潜在的药物相互作用的发生。 本文对索拉非尼的临床应用和药物 －药物相互作用做一综述。
赵建龙，占辉，杨月 ，李文哲，王中辉，邱相君( 河南科技大学医学院，河南洛阳 471003)ZHAO Jian － long，ZHAN Hui，YANG Yue，LI Wen － zhe，Abstract: Sorafenib is a multi － targeted tyrosinekinase inhibitor，and mainly used for the treatment of advanced renal cell carcinoma and hepatocellular carcinoma. The pharmacokinetic changes of sorafenib caused by drug － drug interactions may affect its clinical efficacy and safety，so individualized treatment drug monitoring could control the occurrence of potential drug interactions． In this paper，the clinical applications and drug － drug interaction of sorafenib was reviewed．WANG Zhong － hui，QIU Xiang － jun( Medical College of Henan University of Science and Technology， Luoyang 471003，Henan Province，China)索拉非尼( sorafenib，商品名 Nexavar，多吉美) ，是一种多靶点抗肿瘤新药，也是一种血管内皮细胞生长因子受体( VEGFR) 的酪氨酸激酶抑制剂( TKIs) ［1 － 2］。 在合用其他抗肿瘤药物的晚期实体瘤治疗中，索拉非尼表现出良好的安全性和抗肿瘤活性［3］。 索拉非尼主要用于治疗晚期肾癌、肝癌; 另外，联合其他抗肿瘤药物用于多种进展性实体瘤的治疗，如黑色素瘤、乳腺癌、非小细胞肺癌( NSCLC) 、甲状腺癌、胃癌等［3 － 5］。 索拉非尼主要通过 CYP3A4 进行氧化代谢，以及通过尿苷二磷酸葡萄糖醛酸基转移酶( UGT) 1A9 进行葡萄糖苷酸化代谢; 同时索拉非尼是 CYP3A4，CYP2C19 和 CYP2D6 的竞争性抑制剂，合并用药时会引起药物间的相互作用( DDI) ［6 － 8］ 。
1 临床应用
肝癌索拉非尼可显著抑制体内外肝癌的生长，其效应呈剂量依赖性。 索拉非尼可显著抑制细胞的增殖，在人肝癌亚历山大细胞( PLC /PRF /5) 和人肝癌细胞株( HepG2) 的半数抑制浓度( $\mathrm { I C } _ { 5 0 } \big )$ 分别为6. 3，4. 5 mol · L － 1，亦可显著抑制肝癌细胞内丝裂原活化蛋白激酶的激酶( MEK) 、胞外信号调节激酶( ERK) 的磷酸化水平［9］。 索拉非尼在抑制人肝癌细胞株 HepG2 增殖，诱导其凋亡，髓样细胞白血病 － 1 蛋白质 ( Mcl － 1 ) 及人碱性成纤维细胞生长因子 － 2( bFGF － 2) 可能在肝癌细胞的增殖分化中起着重要的作用［10］。 索拉非尼治疗肝癌的疗效与患者本身的身体状况和肝功能密切相关，患者有较好的身体状况和肝功能，其生存周期就会更长; 体力状态和肝功能状况较差的肝癌患者不建议单独用索拉非尼进行治疗。 同时，甲胎蛋白水平可作为肝癌病情的一个重要预测指标［11］。 在亚太人群的晚期肝癌患者中，索拉非尼与安慰剂相比可延长生存期，且耐受性良好; 索拉非尼可以改善肝癌患者的生存率，提高其生存质量，是肝癌靶向治疗的新途径［12］。 同时，索拉非尼治疗中国人中晚期原发性肝癌患者有较好的病情控制和生存获益，不良反应可控［13］ 。 。
2 药物相互作用
达卡巴嗪其在体内分解释放出甲基正离子$\left( \ \mathrm { C H } _ { 3 } ^ { \ + } \right)$ ，发挥烷化作用; 同时又能转化成一种与嘌呤生物合成的中间产物相似的物质，可能干扰嘌呤的生物合成，用于黑色素瘤、软组织肿瘤、恶性淋巴瘤等恶性肿瘤的治疗。 索拉非尼与达卡巴嗪合用时，达卡巴嗪的 AUC 和 $C _ { \mathrm { m a x } }$ 分别减少 23%和 16%，达卡巴嗪的代谢物 5 － 氨基咪唑 － 4 － 甲酰胺( AIC) 的 AUC 和$C _ { \mathrm { m a x } }$ 值分别增加 41% 和 45% ，达卡巴嗪和 AIC 的 $t _ { 1 / 2 }$ 无明显影响; 而索拉非尼及其 3 个代谢物的 AUC 和$C _ { \mathrm { m a x } }$ 值有很大的波动。 当索拉非尼与达卡巴嗪合用时，可以减少达卡巴嗪的暴露，增加 AIC 的暴露［24］ 。
肾癌索拉非尼治疗转移性肾癌的多中心、 随机、双盲与安慰剂对照的 Ⅲ 期临床试验的结果显示［14］，索拉非尼临床获益率高达 84% ; 与安慰剂比较，索拉非尼可显著延长转移性肾癌患者中位无进展生存期( PFS) ，并显著延长总生存期( OS) 。 索拉非尼在中国治疗晚期肾癌的开放、多中心、非对照的 Ⅱ 期临床试验结果显示［15］，临床获益率达 84. 21% ，客观缓解率达21%，PFS 长达 41 周。 索拉非尼对晚期肾癌的病情控制有较好的效果，但其多种不良反应应加强管理，治疗前应全面评估患者个体条件，并告知不良反应的种类和相应的处理和监控方法，治疗中严格控制相关的风险因素和监测临床症状［16］。 通过索拉非尼新辅助治疗可能缩小肿瘤、降低肿瘤分期，使原先无法手术的局部晚期患者能够接受手术切除，从而提高疗效或改善患者生活质量［17］卡培他滨其可在体内转变成 5 － 氟尿嘧啶( 5 － FU) 的抗代谢氟嘧啶脱氧核苷氨基甲酸酯类药物，能够抑制细胞分裂和干扰 RNA 和蛋白质合成，用于紫杉醇和蒽环类抗生素化疗方案治疗无效的晚期原发性或转移性乳腺癌的进一步治疗。 索拉非尼与卡培他滨合用时，卡培他滨不改变索拉非尼的$\mathrm { A U C } _ { 0 - 1 2 }$ h 和 $C _ { \mathrm { m a x } }$ ，而索拉非尼可以使卡培他滨和 5 －FU 的 $\mathrm { A U C } _ { 0 - 1 2 }$ h略微增加［25］。 但是，索拉非尼的 3 级手足综合征不良反应与合用卡培他滨相关，限制索拉非尼的继续使用［25］ 。
非小细胞肺癌由于索拉非尼可以抑制非小细胞肺癌患者 k － ras 基因突变引起的 Ras /Raf /MEK /ERK 信号通路的上调，显示出独特的抗肿瘤活性［18］。索拉非尼与先前治疗非小细胞肺癌的药物( 长春瑞滨、顺铂和吉非替尼) 合用治疗非小细胞肺癌，显示出可延缓肿瘤生长的作用。 索拉非尼单药治疗非小细胞肺癌显示出良好的效果，临床耐受性良好，对复发性非小细胞肺癌具有抗肿瘤活性［19］，且在治疗过程中未发现其对患者的体力状况和症状带来不良影响［20］。 局部进展或复发的非小细胞肺癌患者接受索拉非尼联合吉非替尼治疗的耐受性良好。 尽管索拉非尼单药治疗进展期非小细胞肺癌患者显示出临床获益，但是与其他酪氨酸激酶抑制剂一样，与化疗药物联用时并未显示出生存获益［19 。
多西他赛其主要治疗晚期乳腺癌、卵巢癌、非小细胞肺癌，对头颈部癌、小细胞肺癌、胃癌、胰腺癌、黑色素瘤等也有一定疗效。 索拉非尼与多西他赛合用时，索拉非尼可以使多西他赛的 $\mathrm { A U C } _ { 0 - \operatorname* { i n f } }$ 和中位$C _ { \mathrm { m a x } }$ 显著增加，中位清除率明显减少，增加多西他赛的暴露; 多西他赛可以减少索拉非尼的血浆暴露，但不明显改变索拉非尼的药代动力学参数［26］。
卡铂和紫杉醇卡铂为第 2 代铂类化合物，其生化物征与顺铂相似，但肾毒性、耳毒性、神经毒性低，尤其是胃肠道反应低。 卡铂为广谱抗肿瘤药，主要用于小细胞肺癌、卵巢癌、睾丸肿瘤、 头颈部鳞癌等治疗。 在非小细胞肺癌患者治疗中［27］，索拉非尼 400mg 合用卡铂 $5 \mathrm { ~ \ m g ~ } \bullet \mathrm { ~ \ m i n ~ } \bullet \mathrm { ~ \ m L ^ { - 1 } ~ }$ 、 紫杉醇 200$\log \cdot \mathrm { ~ m ~ } ^ { - 2 }$ ，药代动力学的相互影响无相关性，但抗肿瘤活性明显增强。
其他肿瘤索拉非尼显著抑制人卵巢癌SKOV －3细胞的增殖，且其抑制作用呈剂量和时间依赖性［21］。 索拉非尼通过阻断肿瘤细胞的 MAPK 通路和影响 VEGFR 表达干扰和阻断肿瘤血供，来抑制肿瘤细胞的增殖，为骨肉瘤的治疗提出了新的思路 ［22］在其他肿瘤治疗中，索拉非尼与化疗药物联合治疗转移性恶性黑色素瘤疗效较好; 治疗甲状腺癌、前列腺癌也显示良好的趋势［23］西妥昔单抗和伊立替康其是美国食品药品监督管理局( FDA) 批准的治疗晚期大肠癌的药物。 西妥昔单抗可与表达于正常细胞和多种癌细胞表面的上皮生长因子( EGF) 受体特异性结合，并竞争性阻断EGF 和其他配体，通过与 EGF 受体结合的酪氨酸激酶( TK) 的抑制作用，阻断细胞内信号转传途径，从而抑制癌细胞的增殖，诱导癌细胞的凋亡，减少基质金属蛋白酶和血管内皮生长因子的产生。 伊立替康是喜树碱的半合成衍生物。 伊立替康及其活性代谢物SN － 38可与拓扑异构酶I － DNA 复合物结合，从而阻止断裂单链的再连接。 在晚期大肠癌的治疗中［28］，索拉非尼合用西妥昔单抗和伊立替康，在第 1，15 天，索拉非尼血浆药物浓度－时间曲线表现为吸收缓慢和消除延长。 合用索拉非尼可以增加伊立替康的耐受性，减少西妥昔单抗和伊立替康的临床治疗剂量; 虽初始高剂量的索拉非尼可以增加皮疹发生率，但与总体药物暴露无相关性［28］。
索拉非尼在治疗晚期肾癌、肝癌中取得了明显疗效，在其他进展性实体瘤如黑色素瘤、乳腺癌、非小细胞肺癌、甲状腺癌、胃癌等的治疗中，常联合其他抗肿瘤药物。 临床上，药物 － 药物相互作用引起的索拉非尼药代动力学的变化可能影响其临床疗效和安全性。个体化的治疗药物监测可以控制潜在的药物相互作用的发生。
非洛地平非洛地平为选择性钙离子拮抗药，主要抑制小动脉平滑肌细胞外钙的内流，选择性扩张小动脉，对静脉无此作用，不引起体位性低血压，对心肌亦无明显抑制作用，主要用于高血压的治疗。 非洛地平是 CYP3A4 的底物，与索拉非尼合用时，会发生CYP3A4 相关的临床药代动力学的药物相互作用。 在不调整其他治疗方法的情况下，与非洛地平合用，可引起索拉非尼的血药浓度升高 3 倍，同时发生3 级厌食症［ 29］ 。
