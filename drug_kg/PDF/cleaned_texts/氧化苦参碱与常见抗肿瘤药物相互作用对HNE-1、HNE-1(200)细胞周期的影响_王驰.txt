参考文献：
肿瘤细胞的增殖周期大致分为以下三个阶段$( 1 ) \mathrm { G } _ { 0 } { \sim } \mathrm { G }$ 期即 DNA 合成前期主要为向 S 期过渡准备物质上的条件 (2)S 期即 DNA 合成期是进行DNA 复制的时期 ， 此期 DNA 表示为 $\mathrm { d s D N A } ; ( 3 ) \mathrm { G } _ { 2 } \sim$ M 期此期为有丝分裂阶段其中 S 期为细胞增殖的关键抗肿瘤药物常通过引起肿瘤细胞 DNA 损伤而导致细胞周期阻滞有 DNA 损伤的细胞常被阻滞在 $\mathrm { G } _ { 1 }$ 期防止受损的 DNA 进入 S 期复制或被阻滞在 $\mathrm { G } _ { 2 }$ 期以防止在 M 期进行异常分裂[3] 将细胞阻滞在 $\mathrm { G } _ { 1 }$ 期或 $\mathrm { G } _ { 2 }$ 期会使大部分含 DNA 损伤的细胞在未得到修复的情况下进入细胞分裂期导致细胞的增殖性死亡增加理论上能够提高化疗的敏感性[4,5]本研究以鼻咽癌 HNE-1 细胞株和由放射线诱导的鼻咽癌耐药细胞株 HNE-1（200）为研究对象采用流式细胞仪检测天然药物 $_ \mathrm { O x y }$ 和 $\mathrm { V R P }$ 与 4 种常用抗肿瘤药物联合应用对两种细胞株细胞周期的影响结果显示 ： $_ \mathrm { O x y }$ 与肿瘤药物相互作用可使鼻咽癌耐药细胞株和非耐药细胞株均产生细胞 $\mathrm { G } _ { 1 }$ 期阻滞抑制细胞增殖这与经典化疗增敏剂 VRP 相似其中 VCR 与药物相互作用结果同 BLM 相似而DDP 和 $5 { \mathrm { - F u } }$ 结果相似其作用较 VCR 和 BLM 显著本研究显示天然药物 $_ \mathrm { O x y }$ 和经典化疗增敏剂$\mathrm { V R P }$ 均能通过诱导鼻咽癌细胞 $\mathrm { G } _ { 1 }$ 期阻滞从而产生化疗增敏作用并且对耐药细胞株也具有相同的作用机制[6] 这为进一步将 $_ \mathrm { O x y }$ 作为化疗增敏剂和肿瘤多药耐药逆转剂提供了依据
