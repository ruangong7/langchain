等辐射法分析结肠镜麻醉中丙泊酚与依托咪酯的药物相互作用
李有武，李成龙，涂学云，戴转云，王铮，詹育成，汪燕【摘要】目的采用等辐射分析法研究结肠镜麻醉中靶控输注( TCI) 丙泊酚与依托咪酯两药之间的相互作用方法选择门诊待做无痛结肠镜检查患者158 例，随机分成丙泊酚组( P 组) 依托咪酯组( E 组) 丙泊酚－依托咪酯复合组( C 组) 3 组，采用序贯法确定各组病例数。 麻醉诱导前各组以序贯方式静脉 TCI 丙泊酚、依托咪酯及两药复合药物。 病人睫毛反射消失时即开始结肠镜检查，测定 P、E、C 组半数血浆有效浓度值( E C 5 0 ) ，采用等辐射分析法分析二者之间的相互作用。 结果 P 组 E C 5 0 值为 4.1 5 g / mL ，其95% 可信区间为 3.5～4.8 g / mL ; E 组 E C 5 0 值为400 ng/mL，其 95% 可信区间为 3 7 0～4 2 5 ng / mL ; 丙泊酚复合依托咪酯靶控输注麻醉用于结肠镜检查，其 E C 5 0 分别降为 1． 28 /220，其 E C 5 0 比值总和为0．86，位于95%CI 左侧，P＜0．05。 结论经等辐射分析法证实，丙泊酚与依托咪酯在结肠镜 TCI 麻醉时麻醉效应呈协同作用。
药物联合通过药代动力学和药效学机制产生相加、协同和拮抗作用，取长补短联合用药已成为临床麻醉的必然趋势 。 等辐射分析法( Isobolographic a-nalysis) 是一种分析药物之间相互作用的方法，对于药物联合应用后药物效应的改变，能予以简洁、精确的定量分析［1］。 丙泊酚和依托咪酯均属非巴比妥类静脉全麻药，具有起效快、苏醒迅速且并发症少的优点。 本研究应用等辐射分析法对无痛结肠镜检查术时异丙酚与依托咪酯二药的相互作用及临床效果进行探讨。

等辐射分析法是通过研究药物单独和联合应用产生同样效应时各组成药物的剂量或浓度来比较分析药物之间相互作用，通常分别测定单独药物应用时的 E D 5 0 ( 或 E C 5 0 ) 分别标绘在横坐标和纵坐标上，相连成等效相加线，然后再测定联合应用的 E D 5 0 ( 或 E C 5 0 ) ，并标绘在坐标图上。 如果药物联合应用的效应强度落在等效相加线上，表示两药作用为相加; 如果落在等效相加线的左侧，则代表协同作用;落于等效相加线的右侧，则为拮抗作用。 相关研究表明［7］，丙泊酚 TCI 用于结肠镜检查时的血浆 E C 5 0 为 4． 15 g / m I ，刘礼军［4］等人测定的 TCI 依托咪酯镇静意识消失的 C P 5 0 为 337 ng/mL，陈鸿等人测定的丙泊酚与依托咪酯催眠状态下的 E D 5 0 分别为1.1 5 mg / k g . 0.1 1 mg / k g ］。 目前，采用序贯法测定丙泊酚与依托咪酯用于无痛结肠镜检查术的 E C 5 0 并采用等辐射法分析其相互作用尚没有相关文献报道。 我们的研究显示: 单纯丙泊酚 TCI 用于结肠镜检查术时的 E C 5 0 为 4.1 5 g / mL ，其 95%可信区间为 3.5～4.8 g / mL ; 依托咪酯 TCI 用于结肠镜检查术时的 E C 5 0 为 4 0 0 ng / mL ，其 95%可信区间为 370～4 2 5 ng / mL ; 丙泊酚复合依托咪酯 TCI 麻醉用于结肠镜检查，其 E C 5 0 分别降为 1． 28 /220，其 E C 5 0 比值总和为0．86，位于 95%CI 左侧， P < 0.0 5 ，运用等辐射分析法原理判定为丙泊酚与依托咪酯具有药物协同作用。 通常作用于受体同一功能部位的两种药物相互作用通常为相加，作用于不同受体或同一受体不同部位的药物之间相互作用通常为协同，推测丙泊酚、依托咪酯两药麻醉协同作用均与 γ－氨基丁酸受体有关［9］。 由此表明，依托咪酯复合应用于丙泊酚无痛结肠镜检查，可以显著降低二者剂量或总量，避免因剂量增加而产生与呼吸、循环等相关副作用。
有关研究证实［10］丙泊酚的血液动力学变化在未达到明显镇静状态时即可产生，平均下降幅度10% ～20%，而依托咪酯则相反，BP、HR 在研究的靶浓度范围内无明显变化，具有良好的血流动力学稳定性，本研究也证实这观点，C 组、E 组血流动力学稳定性明显高于 P 组( P＜0． 05) ，表明丙泊酚与依托咪酯联合用药具有良好的循环稳定性。
综上所述，异丙酚与依托咪酯联合应用于静脉TCI 麻醉具有协同作用，可以大大降低相互剂量，可以获得良好的血流动力学稳定性，可以安全运用于无痛结肠镜检查麻醉。
