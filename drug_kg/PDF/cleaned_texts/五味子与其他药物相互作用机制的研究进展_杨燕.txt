3 药物相互作用主要机制
3． 1 对 CYP 酶系的影响
CYP 酶系是最重要的 Ⅰ 相药物代谢酶，广泛分布于肝脏、小肠等部位。 CYP3A 占肝脏、肠道中 CYP 总含量的一半以上，在药物代谢中起着重要作用。 约有 60% 以上的药物由 CYP3A 参与催化代谢。 因此通过了解五味子与 CYP3A的相互作用，对评估五味子与其他药物之间相互作用有着重要的意义。
Su 等［16］给予小鼠醋制/非醋制的单剂量/多剂量的五味子制剂后，通过 HPLC 法测定“探针”的血浓度和相关动力学参数，结果证实五味子能激活 CYP3A4 和抑制 CYP1A2，醋制五味子的抑制作用更强; 单剂量激活 CYP2E1，多剂量抑制 CYP2E1［16］。 王宝莲等［17］ 通过体外实验，证实了五味子水 /醇提取物显著抑制 CYP1A2 、 2C6 、2C11 、2D2 、 E1 和 3A1 /2 ; 在体内实验中，多剂量给药的五味子水/醇提取物增加CYP2E1 和 CYP3A1 /2 的活性，而抑制 CYP2D2 活性; 体外实验中，先给予7 d 的五味子醇提物后，五味子醇甲、五味子酯甲五味子甲素 -五味子酯甲的自身代谢加速，这说明五味子成分多次给药可通过诱导 CYP450 酶而诱导自身木脂素类成分体内代谢。 Iwata 等［18］ 研究了五味子的几种成分对大鼠肝微粒体 CYP 酶活性的影响，发现 Gomisin B、 GomisinC( 五味子酯甲) GomisinG 能抑制 CYP 酶活性，五味子酯甲强烈且不可逆地抑制 CYP3A4 活性，其作用机制为形成不可逆的络合物。 Liu 等［19］证实了 GomisinG( 五味子的提取物之一) 是 CYP3A4 的良好底物，CYP3A4 的抑制物能显著影响GomisinG 的代谢。 李维亮等［20］以大鼠肝微粒体为载体，选取咪达唑仑为药物“探针”，HPLC 检测五味子乙素对肝微粒体代谢咪达唑仑的影响，结果证实了五味子乙素在体外可抑制大鼠肝微粒体 CYP3A 活性，其作用机制为可逆性抑制，属于非竞争性抑制类型，五味子乙素与底物或酶无亲和力，而与酶原底物复合物或次生产物具有很好的亲和力。 Brandin等［21］ 证实五味子 60% 醇提取物可以诱导 CYP1A2、CYP3A4 MDR1 的表达，CYP3A4 的表达增加有可能是通过激活 PXR 引起的。 程能能等［22］ 通过实验证实五味子水提物对 CYP3A 酶活性的影响呈现抑制和诱导双重作用，给药后12 h 为酶抑制，3 d 后由抑制转为诱导趋势，6 d 后呈现诱导作用。 陈倩等［23］ 对这种双重作用作出了更为详细的阐述，认为五味子中同时含有 CYP3A 酶的抑制和诱导组分，五味子的作用具有时间浓度和靶点相关性，即短时间( 2 d 以内) 高浓度以抑制作用为主，长时间( 3 d 以上) 低浓度可诱导酶活性。 在酶蛋白水平，离体条件下一般仅观察到抑制效应，而在 mRNA 水平可见部分木脂素组分呈现明显的诱导作用同时部分木脂素组分自身也可能呈现低浓度诱导五味子除了具有保肝降酶作用外，还具有抗癌、抗艾滋病毒( HIV) 拮抗血小板活化因子( PAF) 和抑制醛糖还原酶等多种活性［7 ～ 9］ 。

3． 2 对 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 影响
药物外排蛋白在保护机体免受细胞毒药物损害方面具有重要作用。 目前，在药物吸收中具有重要作用的外排蛋白主要是与 ATP 结合的盒式膜转运蛋白家族 MRP，其中包括$\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 、MRP1 和乳腺癌耐药蛋白( BCRP) 。 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 可通过消耗ATP 而逆浓度梯度转运药物分子，该蛋白在肠道、肝脏和大脑等组织表达较高，在药物的吸收和清除过程中具有重要作用 。 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的底物结构类型多样，包括环孢素 A、紫杉醇、地塞米松利多卡因红霉素和 HⅣ-蛋白酶抑制剂等由于该蛋白的外排作用，导致上述药物在靶器官的吸收减少，生物利用度降低［25］ 。
华梓婷等［33］在人肝肿瘤细胞株 HepG2 细胞中，通过瞬时共转染报告基因实验研究几种中药提取物在不同浓度和不同处理时间下对 PXR 介导的 CYP3A4 的转录调节作用，在不同处理时间的研究中，五味子均能在 12 ～36 h 内增强CYP3A4 的转录表达，诱导能力随时间延长呈增强趋势，在相同浓度作用下，其诱导效果为: 五味子甲素 ＞ 五味子乙素＞五味子酯甲。 俞春娜等［34］采用中药提取分离技术、色谱技术、报告基因实验结合 $\mathrm { R T } \mathrm { \mathrm { 4 P C R } }$ 的方法，发现五味子甲素、五味子乙素、五味子醇甲、五味子酯甲也具有 PXR 激活效应，将五味子成分与 PXR LBD 进行分子对接，从配体-受体相互作用的角度分析五味子成分对 PXR 的激活效应，发现五味子酯甲能通过氢键和疏水作用与 PXR 配体结合腔发生广泛的相互作用。 $\mathrm { Z e n g }$ 等［35］ 通过 RT-qPCR 和蛋白质印迹法证实了使用五酯片治疗后，PXR 的目的基因 CYP3A11 和UGT1A1 表达显著升高，五味子甲素、五味子乙素、五味子丙素五味子醇甲五味子醇乙五味子酯甲能激活人 PXR，并且活性相似。 $\mathrm { M u }$ ［36］ 等证实了五味子甲素、五味子乙素、五味子醇甲五味子醇乙能激活 PXR，对 hPXR 和 mPXR 的$\mathrm { E C } _ { 5 0 }$ 分别为 $2 \ \mu \mathrm { m o l } \cdot \mathrm { L } ^ { - 1 }$ 和 $1 . 2 5 \mu \mathrm { m o l } \cdot \mathrm { L } ^ { - 1 }$ ，并且这种作用来自它们的母体植物( the parental herbs) ，而不是代谢物 。
有研究通过建立 Caco-2 细胞模型［26］，证实五酯片、维拉帕米、五味子甲素、五味子丙素及五味子醇乙能抑制 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 介导的他克莫司的外排，其中五味子甲素抑制 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的作用最强。 严子玲等［12］证实 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 抑制剂维拉帕米及五味子提取物均可促进吴茱萸碱和吴茱萸次碱的大鼠肠吸收，提示五味子可能通过抑制 $\mathrm { P \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } \mathrm { \overline { { \Omega } } } } } } } } } } } } } } }$ 的外排作用而促进吴茱萸碱和吴茱萸次碱的肠吸收。 $\mathrm { P a n }$ 等［27］以人白血病 K562 /Adr、 人乳腺癌MCF-7 /Adr 、 人表皮样癌 KBv200 和 Bcap37 /Adr 四种过度表达 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的细胞系为工具，研究五味子对 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的影响，证实五味子甲素、五味子乙素、五味子酯甲能抑制 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 介导的药物耐受。 五味子醇甲、五味子醇乙对 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的作用有限，这可能与环辛二烯上的羟基有关。 $\mathbb { W } { \mathrm { a n } }$ 等［28］证实了五味子醇甲、五味子醇乙可逆转 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 介导的多药耐药性。 $\mathrm { S u n }$ 等［29］通过研究 HL60/Adr( 多柔比星诱导的稳定表达 MPR1 基因的多药耐药细胞株) 和 HL60/MRP( 柔红霉素诱导的稳定表达MPR1 基因的多药耐药细胞株) 细胞系，证实了五味子乙素是 MPR1 和 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的双重抑制物，进一步确定了五味子乙素对肿瘤多药耐药产生的机制。 而 2014 年有研究通过构建$\operatorname { C a c o } 2$ 细胞模型，证实他克莫司能降低五味子酯甲五味子甲素、 五味子醇甲、 五味子醇乙的血药浓度，这是通过由以上研究结果可见，五味子提取物能激活 PXR 介导的 CYP3A 的转录调节作用，进而影响其他药物的体内代谢过程 。
3． 4 核因子相关因子( Nrf2)
核因子相关因子( Nrf2) 是碱性亮氨酸拉链 $\mathrm { { C a p } \ \tilde { \ n } ^ { \prime } \ C o l - }$ lar 家族成员中活力最强的转录因子，是调控机体或细胞对抗外来异物和氧化损伤的关键因子。 许多激酶途径如蛋白激 C( PKC) 、促分裂原活化蛋白激酶( MAPK) 、磷脂酰肌醇-3-激酶( PI3K) 等参与了 Nrf2 的激活。 于洋［37］ 等人证实五味子乙醇提取物可明显诱导 Nrf2 核转位，且通过 Nrf2 信号通路诱导下游靶基因 HO-1、p-糖蛋白( P-gp) 等 Ⅱ 相解毒酶及转运体的转录。 当阻断 ERK、p38MAPK 途径后，Nrf2 下游靶基因如 HO-1、 P-gp 等转录活性大大降低，因此 ERK、p38MAPK 激酶途径有可能参与调控五味子乙醇提取物对Nrf2 信号通路的激活过程。 该实验说明五味子乙醇提取物可以通过诱导 Nrf2 核转位来调控下游靶基因 P-gp 的转录活性 。
3． 5 多药耐药相关蛋白( MRP1)
MRP1 能将带负电荷的药物分子泵出细胞，而带正电荷的化疗药物须与谷胱甘肽( GSH) 结合，才能排出胞外，因此减弱P-gp、MRP1 的外排功能和降低细胞内 GSH 含量可能抑制肿瘤细胞的耐药性，秦小清等［38］在实验中选取 P-gp 高表达细胞株 K562 /ADR、 MCF-7 /ADR 和 MRP1 高表达细胞株HL60 /ADR 作为研究对象。 五味子甲素( SchA) 对各细胞无毒剂量筛选结果为 K562 /ADR: 80 μmol 獉 L － 1 ; MCF-7 /ADR:60 μmol 獉 L － 1 ; HL60 /ADR: 40 μmol 獉 L － 1 ; 在 MRP1 高表达细胞株 HL60 /ADR 中，SchA 对嗯环类( DOX、 DNR) 、长春新碱表现很好的耐药逆转效果( P ＜0．01) ，但对紫杉类与氟尿嘧啶的逆转效果较差，推测紫杉类与氟尿嘧啶可能不是 MRP1的作用底物。 实验发现随着 schA 浓度的增加可减少 K562 /ADR、HL60 /ADR 细胞内的 GSH 含量( 与对照组比较，P ＜ 0．01) 。 说明 schA 逆转 HL60 /ADR 细胞的耐药性可能是通过抑制 MRP 介导的 GSH-药物外排泵发挥作用。
4 五味子对不同代谢酶以及转运体影响大小的比较
2014 年 Qin 等［39］通过体内外实验，比较五酯片中 6 种木酯素( 五味子甲素、五味子乙素、五味子丙素、五味子醇甲、五味子醇乙五味子酯甲) 对他克莫司增效作用的大小，证实五味子醇甲作用最强( P ＜ 0． 000 5) ，使用五味子醇甲后，他克莫司的 Foral( 口服生物利用度) 显著增加408． 3% 。 肠道首关消除是影响他克莫司生物利用度的主要原因( P ＜0． 000 5) ，肠道首关消除主要由 CYP 介导的药物代谢和 P-gp 介导的药物外排引起。 然而，五味子醇甲对 CYP 酶系和P-gp 的影响哪个更大并未有相关研究。 作者经查询国内外主要数据库，未见这方面内容的相关报道
5 讨论
目前，五味子与其他药物相互作用的机制研究主要集中在 CYP 酶系、P-gp、PXR 上，其中对 CYP 酶系的研究仍存在较多问题和分歧，原因可能是五味子中某些成分对 CYP 起到何种作用受3 个条件决定: 实验周期、实验环境( 于体内或体外进行实验，于体外使用肝微粒体或肝细胞进行实验) 、给药剂量［24］。 而对 P-gp、PXR 的研究结论一致性比较高，作者推测可能是与 P-gp、PXR 调控机制所受到的干扰因素较少有关。 然而，对代谢酶和转运体影响大小的比较并未见进一步研究［39］。 除此之外，近些年还有研究证实五味子乙醇提取物可通过 Nrf2 信号通路诱导 P-gp 的转录［37］; 肿瘤细胞的耐药性减弱可能与五味子甲素减弱 P-gp、MRP1 的外排功能和降低细胞内 GSH 含量有关［38］。
综上所述，五味子可通过影响 CYP450 、 P-gp、 PXR、 Nrf2 、MRP1 等来改变其他药物的吸收和代谢等过程。 明确五味子与其他药物相互作用的机制，对寻找高效低毒的 P-gp 抑制药、多药耐药逆转药等有重要意义，是今后五味子相关研究值得深入探索的方向。
