环孢霉素与某些药物相互作用的研究进展
环孢霉素[CyA]是一种新型免疫抑制剂，广泛用于器官移植时的排斥反应和移植物抗宿主反应，也用于治疗自身免疫性疾病和其他一些疾病。某些药物能明显影响CyA的药代动力学，使其血药浓度升高或降低，从而导致CyA的毒性增加或疗效减弱。这些相互作用具有重要的临床意义，也引起了临床极大的关注。本文对近年来国外有关CyA与某些药物相互作用的研究进行简要综述。

酮康唑与 CyA 的相互作用机制可能是酮康唑抑制肝脏微粒体酶，如 N-乙酰化酶和细胞色素酶的活性。酮康唑与细胞色素有高度的亲合力，可竞争性抑制 CyA 在细胞色素 P450 的代谢位点，减弱 CyA 的代谢，使 CyA 的血药浓度升高，同时产生肾毒性。Henricsson 等 [5] 用人肝脏微粒体细胞色素 P450 在体外研究了酮康唑等药物对该酶代谢 CyA 的影响，结果是酮康唑对细胞色素 P450 的抑制作用最强。
一、升高 CyA 血药浓度的药物
3. 钙离子拮抗剂与 CyA 的相互作用
1. 红霉素与 CyA
硫氮唑酮能使肾移植病人CyA血药浓度明显升高。据Wagner等[6]报道，硫氮唑酮明显增加CyA的初始浓度(Co)，用硫氮唑酮后，Co从 318± 14ng / ml 上升到 536± 29ng / ml ，同时Cmax也明显增加，从 1638ng / ml± 200ng / ml 上升到 2035± 304ng / ml 。用硫氮唑酮6天后，CyA的清除率明显降低。Roy等[7]观察了钙离子拮抗剂对心脏移植和肾移植病人CyA药代动力学的影响，结果表明，用硫氮唑酮后，这些病人的CyA的吸收速率常数(Ka)增加，达峰时间(Tmax)缩短，峰浓度增加。Maddux等发现，每天用 240mg 硫氮唑酮后，可使肾移植病人每天用 800mgCyA 的谷值浓度从 245ng / ml 增高到 822ng / ml ，把CyA的用量降到每天 600mg ，CyA的谷值浓度仍高达 990ng / ml ，血清肌酐也继续升高，病人出现明显的肾毒性。停用硫氮唑酮后，肾毒性缓解，CyA血药浓度反而下降到治疗浓度以下(48ng/ml)。Grino等报道，肾移植病人每天用 240mg 硫氮唑酮，4天后，CyA的谷浓度从 290ng / ml 升高到 1000ng / ml ，降低CyA用量的 37\% 以后，CyA的浓度仍维持在高水平。已有人[8,9]对硫氮唑酮对肾移植病人移植器官的功能和CyA的所需剂量进行了前瞻性评价，维持治疗浓度所需的口服AyC的剂量，用硫氮唑酮者比不用者可降低 20～30\% 。用硫氮唑酮后，能改善早期移植的器官功能，很少发生排斥反应。
红霉素能使器官移植病人、自身免疫性疾病病人和健康受试者的CyA浓度升高。Harnett等对3例肾移植病人进行观察，2例静脉注射红霉素，1例既口服又静滴红霉素，结果前2例CyA谷浓度分别增加 267\% 和 233\% ，后1例增加 309\% 。Wad-haw等对肾移植和胰腺移植病人口服红霉素 250mg / 6h ，结果CyA的曲线下面积U增加1倍，峰浓度和稳态血药浓度(Cmax,Css)比用红霉素前增加近两倍，药动学参数表明，用红霉素后，CyA的吸收速率和吸收量都明显增加。有人观察了8例接受血液透析的病人，这些病人口服CyA6mg/kg，有的同时口服红霉素 33mg / kg ，有的单服CyA，服红霉素4天后，CyA的谷浓度为 240ng / ml ，单用CyA者为 96ng / ml 。CyA的生物半衰期 (T1 / 2) 也明显增加，单用CyA者为 6.84± 0.31h ，合用红霉素者为 8.80± 0.80h 。Freeman等对10名健康受试者口服 250mg 红霉素，每天4次，共7天，同时口服 10mg / kgCyA ，结果用红霉素后CyA的Cmax和AUC分别增加2.4倍和2.2倍， T1 / 2 没有改变。Gupta等探讨了红霉素与CyA相互作用的机制，发现红霉素对口服和静注CyA能产生明显影响，口服红霉素后静注CyA，血浆CyA清除率降低 13\% ,T1 / 2 没有改变，而口服CyA，其Cmax增加近3倍，AUC增加2倍，该作者认为，用红霉素时可使口服CyA的吸收量从 36\% 增加到 60\% 。交沙霉素也能增加CyA浓度。
维拉帕米(异搏停)治疗有心律失常和高血压的肾移植和心脏移植病人时,能使CyA的血药浓度明显升高。Robson等 [10] 报道,肾移植病人用维拉帕米40mg,每天2次,治疗1周后,CyA的血药浓度从30ng/ml升高到704ng/ml,当维拉帕米用量增加到80mg,每天2次,治疗3周后,CyA的浓度升高到1054ng/ml。停用维拉帕米1周后,CyA的血药浓度降到504ng/ml,两周后,CyA的浓度降低到409ng/ml。Dy等 [11] 观察了9例器官移植病人,用维拉帕米后,CyA的血药浓度从194.7±28ng/ml升高到494.9±71ng/ml。其他钙离子拮抗剂尼卡地平也能增加CyA的浓度。硝苯啶在体外试验中能升高CyA的浓度,但是用于病人体内后不能使CyA的浓度升高 [11～13] 。
红霉素与 CyA 相互作用的机制尚不清楚，有人认为，红霉素能明显抑制细胞色素 P450 的活性，由于细胞色素 P450 在 CyA 代谢中起重要作用，红霉素可能通过此途径而抑制 CyA 的代射，使其血药浓度升高。另外，红霉素还能抑制小肠蠕动，使口服的 CyA 浓度增加。
2. 酮康唑与 CyA 的相互作用
酮康唑与CyA同时应用能明显增加器官移植和骨髓移植病人的CyA浓度。有人[2,3]对用酮康唑作为一种降低肾移植和心脏移植病人CyA治疗费用的方法作了评价，用酮康唑后，每天CyA达到治疗谷浓度的用量可减少 75～80\% 。在用酮康唑的期间里，血尿素氮和血清肌酐升高。酮康唑使CyA浓度增加后，即使减少CyA用量或停用酮康唑，CyA的浓度和血清肌酐需要几个星期后才能恢复到原来的水平。Shepard等报道，肾移植患者每天服酮康唑600mg同时口服CyA320mg，两天后，CyA血药浓度从 52ng / ml 升高到 110ng / ml ，血清肌酐由 1.3mg / dl 上升到 1.9mg / dl ，4天后，CyA浓度升高到 220ng / ml ，血清肌肝升高到 2.3mg / dl ，停用酮康唑7天后，CyA浓度降到 47ng / ml ，血清肌酐降到 1.5mg / dl 。另外，抗真菌药硝康唑和氟康唑也能钙离子拮抗剂使 CyA 浓度升高的机制可能是由于这类药物抑制了肝脏微粒体氧化酶，主要是抑制了代谢 CyA 的细胞色素 P450 的同功酶 P450PCN I[14] ，即同功酶细胞色素 P450II A[15] 。该酶被抑制后，CyA 的代谢减慢，其血药浓度也随之升高，同时，CyA 的毒性也因而增加。有人 [16] 提出用钙离子拮抗剂来增加 CyA 的浓度，减少 CyA 的用量，以节省器官移植病人用 CyA 治疗有关的费用，减轻病人的经济负担。
能使 CyA 浓度增加的药物还有类固醇激素类, 如甲基泼尼松、强的松、口服避孕药、甲基睾丸酮、达那唑等。此外，秋水仙素、西咪替丁、氟喹诺酮类等药物，也能使CyA的血药浓度升高。
3. 磺胺二甲嘧啶和甲氧苄氨嘧啶与 CyA 的相互作用
Jones 等报道,磺胺二甲嘧啶和甲氧苄氨嘧啶与 CyA 合用时,能明显降低 CyA 谷值浓度,由于 CyA 浓度降低,在 5 例病人中有 2 例出现了排斥反应。磺胺类药物也是通过微粒体酶诱导作用而降低 CyA 的浓度。
二、降低 CyA 血药浓度的药物
1. 抗惊厥和抗癫痫药物与 CyA 的相互作用
另外，有些药物与 CyA 合用能加重 CyA 的肾毒性，这些药物也可直接作用于肾脏产生肾毒性，如硫酸庆大霉素、两性霉素 B、速尿、头孢菌素类、苯丙酸氮芥等。
苯妥因、苯巴比妥、卡马西平能明显降低 CyA 的血药浓度。Keown 等研究了肾脏、肝脏和心脏移植病人，接受苯妥因治疗后，CyA 的 AUC 降低约 50%，要维持 CyA 的有效治疗浓度必须增加 CyA 的剂量。Carstensen 等观察了儿童骨髓移植后苯巴比妥对 CyA 的影响，结果是，每天用 100mg 苯巴比妥时，CyA 谷浓度用放免法测不到。当苯巴比妥剂量降低到 25mg/天时，测得 CyA 的浓度为 190ng/ml。卡马西平也能明显降低 CyA 的血药浓度。
苯巴比妥、苯妥因和卡马西平降低 CyA 浓度的机制是因这类药物诱导细胞色素 P450 酶的活性，使 CyA 的代谢增强，从而导致 CyA 的血药浓度降低 [15] 。
2. 利福平与 CyA 的相互作用
利福平能显著降低 CyA 的血药浓度。Van Buren 等报道，用利福平治疗患结核的器官移植病人时，这些病人都出现了急性排斥反应，CyA 的谷值浓度明显降低，AUC 与用利福平前相比，降低了 25%。利福平与 CyA 相互作用的药动学表明，用利福平后，CyA 的 Cmax 降低， T1/2 缩短，AUC 减少。要维持 CyA 的治疗浓度，需要增加 CyA 的剂量。
利福平降低 CyA 的血药浓度的机制是因利福平有很强的微粒体细胞色素 P450 同功酶的诱导作用。用人肝细胞原代培养研究表明，利福平是 CyA 氧化酶细胞色素 P450 A 的诱导剂，它能使该酶的活性增强，从而导致 CyA 代谢加快而浓度降低 [16] 。
干扰素(Interferon, IFN)是具有抗肿瘤、抗病毒和免疫调节作用的一类高活性、多功能诱生蛋白。自1957年Isaacs和Lindenmann发现以来，已逐步形成涉及病毒学、细胞学、分子生物学、肿瘤学和免疫学等多学科的一门新兴边缘科学——干扰素学。随着基因工程干扰素的问世，大量的高纯度IFN在临床得到应用。由于IFN用药剂量较大( 106 u以上)，疗程较长(3～6个月或更长)，用药过程中的不良反应时有发生。本文就近几年国内外有关报道作一概述，以引起医药人员的注意。
2. 血液系统的不良反应 [3,5]
使用临床级剂量的 IFN(10 6 u/d)时，可产生轻度骨髓抑制。在临床治疗中发现，当以 8.5×10 4 u/kg/d（或更高）的 IFN-α 治疗慢性肝炎病人时，可造成受试者白细胞、血小板和网状细胞水平下降，而当以 5.1×10 5 u/kg/dIFN-α 治疗水痘-带状疱疹病人和用 IFN-γ 治疗系统性硬化病时，也观察到类似现象。在所有 IFN 治疗中，随着 IFN 剂量加大对骨髓影响会进行性增加。其血象反应特点，首先是多核细胞下降，再过 1～2 天后，血小板水平下降，接着网状细胞数也开始减少。所有这些作用并不影响治疗，但为安全起见，多数学者主张在大剂量应用 IFN 治疗中，受试者多形核白细胞应 >1×10 9 /L，血小板应 >50×10 9 /L 比较适宜。除此以外，IFN 对凝血系统也有影响。有人发现使用 α-2b 的少数病人有凝血素和部分凝血活酶作用时间延长，造成凝血功能紊乱，原因不详。
目前临床应用的 IFN 主要有三类，包括人白细胞干扰素 (IFN-α)，人成纤维细胞干扰素 (IFN-β) 和人类淋巴细胞干扰素 (IFN-γ)。它们具有类似的不良反应，其发生率似乎以 IFN-α 较小，以 IFN-γ 较大 [1] 。临床表现主要有以下几个方面。
1. 神经系统的不良反应 2-6
最常见的不良反应是发烧和倦怠。当给病人胃肠道以外注射大剂量 (2.4x104u/kg/d 或更大）部分纯化的IFN- 时，曾观察到相当一部分病人在注射2～4h后出现发热反应，也有部分病人出现类似流感症状，这种反应可随IFN剂量加大而增高。在治疗过程中发现，初次肌注或皮下注射大剂量IFN时，可引起体温升高，但这种作用在停药或调整剂量后可减轻。Kahan在用重组IFN- 治疗系统性硬化病时，有3例用药后2h内出现中度发热，持续2～4h，需扑热息痛治疗；3例用药后，2h出现疲乏，持续8h。随着IFN剂量加大( >106u/d )，对中枢神经系统也产生其它毒性作用。主要表现为：头痛、肌肉痛、关节痛、意识损伤、惶惑、眩晕、运动失调、感觉异常、忧虑不安、抑郁症、神经紧张、梦幻等。也有出现高烧不退、虚脱、焦虑、视觉异常的报道，但这在临床上比较罕见。
