华法林与唑类抗真菌药物相互作用及其机制研究进展
Research of the interaction and their mechanisms between warfarin and azole antifungal agents

School of Pharmacy，Fujian Medical University， Fuzhou 350001， Fujian Province，China)华法林是目前临床上应用最广泛的维生素 K 依赖性凝血因子抑制剂［1］。 国外的华法林说明书中指出，华法林和部分唑类抗真菌药联用会增强华法林的抗凝作用［2］。 但是，国内的华法林说明书并未指出华法林与唑类抗真菌药物存在相互作用。 本文从华法林和唑类抗真菌药物的药代动力学( PK) 特征出发，对唑类抗真菌药物与华法林的相互作用机制的相关文献报道进行综述。
1 华法林与唑类抗真菌药物的药物相互作用的机制
药效动力学( pharmacodynamics，PD) 相互作用指一种药物引起另一种药物疗效或药物不良反应( ADR) 的增加性或拮抗性药理效应的现象，比如华法林和非甾体抗炎药联合使用会增加出血风险。 唑类药物对肝药物代谢酶的抑制作用是华法林与唑类药物产生相互作用的机制，如氟康唑、伏立康唑和伊曲康唑等［3］定稿日期: 2019 － 04 － 18

2 唑类抗真菌药物对华法林影响的案例报道
1. 2 唑类抗真菌药物的代谢途径
2. 1 咪康唑对华法林的影响
唑类抗真菌药物主要有咪唑类( 酮康唑、克霉唑、咪康唑) 和三唑类( 氟康唑、伊曲康唑、伏立康唑)［5］。还有首个外用的三唑类抗真菌药物———艾氟康唑［6］和新型三唑类药物———泊沙康唑［7］。
截至2016 年4 月13 日，英国药品和医疗产品管理局( MHRA) 已收到 146 份报告咪康唑与华法林之间可能存在药物相互作用的 ADR 报告。 大多数报告( 128 份，88%) 与咪康唑口腔凝胶剂型有关; 最常报告的事件包括: 国际标准比率增加( INR，111 份报告) 、 挫伤 ( 21 份) 、 血尿 ( 17 份 ) 和鼻衄 ( 8 份 ) 。 在146 例病例中，约 50% 报告了 INR 值增加超过 10，其中 3 例病例因出血性事件导致死亡［14］。 国外相关研究报道［15 － 17］，不乏有华法林与咪康唑口腔凝胶联用导致华法林抗凝活性明显增强的病例。 研究者均认为，咪康唑通过抑制参与华法林代谢的 CYP2C9 酶的活性，导致华法林清除减少，从而使其抗凝作用增强;但是理论上，口服凝胶形式的药物不能吸收到全身循环中，因此不能抑制 CYP2C9 。 直到 TAJIMAOKUBO等［18］在合并使用华法林和咪康唑口腔凝胶的患者血浆中，检测到了相当数量的咪康唑，才证明咪康唑凝胶实际上可被吸收到全身循环中，可见咪康唑对华法林具有显著的影响。
唑类抗真菌药物是细胞色素 P450 同工酶的底物和抑制剂。 咪康唑是一种合成的咪唑类广谱抗真菌药和抗革兰氏阳性菌的药物，能够抑制多种微粒体 P－ 450 同工酶，对 CYP2C9 的抑制具有临床意义［8］。酮康唑是一种咪唑衍生物抗真菌药，能有效地抑制剂细胞色素 P450 同工酶，是细胞色素 P450 1A2 和 3A4的强效抑制剂，对同功酶 2A6、2C9、2C19 和 2D6 具有中等抑制作用［8 － 9］。 氟康唑 80% 以原药形式经肾排泄，是 CYP 酶系的抑制剂，可抑制 CYP3A4/5 和CYP2C9 ［8］。 氟康唑对 CYP2C9 的 $\mathrm { I C } _ { 5 0 }$ 值为 9. 3$\mathbf { m } \mathbf { g } \cdot \mathbf { L } ^ { - 1 }$ ，而其血药浓度为 2. 8 ～ 6. 9 mg · L － 1 ，是CYP2C9 的中度抑制剂［10］。 伏立康唑是在氟康唑化学结构基础上修饰而成的，是 CYP2C9、 CYP3A4 和CYP2C19 的底物，也是其抑制剂。 JEONG 等［11］研究显示，伏立康唑对 CYP2B6 、 CYP2C9 、 CYP2C19 和CYP3A 的 $\mathrm { I C } _ { 5 0 }$ 均小于 $< 6 \mathrm { \ m o l } \cdot \mathrm { L } ^ { - 1 }$ ，按照抑制常数记，伏立康唑对以上 4 种酶的抑制强弱为 CYP2C19 ＞$C Y P 3 A > C Y P 2 C 9 > C Y P 2 B 6$ 。 伊曲康唑主要由 CYP3A4代谢，是CYP3A4 的强抑制剂和底物［8］。 泊沙康唑主要抑制 CYP3A4 和 P 糖蛋白，也可能影响 CYP2C9 和CYP2C19［12］。 艾氟康唑( 商品名 Jublia) 为是首个外用三唑类抗真菌药物，由加拿大 Valeant 制药公司研发，2014 年6 月6 日获FDA 批准上市。 相比传统的口服三唑类药物，艾氟康唑能有效地避免系统性ADR［6］。
2. 2 酮康唑对华法林的影响
SMITH［19］报道了 1 例长期服用华法林的患者( INR 值维持在1. 6 ～3. 5) ，因慢性阴道鹅口疮感染服用酮康唑 200 mg bid，治疗 2 d 后，INR 值是 1. 9; 治疗14 d 后，身上出现自发性的瘀斑，INR 值上升到 5. 4。JACKEVICIUS 等［20］报道了 1 例主动脉瓣置换术服用华法林，随后因前列腺癌服用高剂量酮康唑( 400 mgtid) 的患者，华法林的剂量降低了 35%( 由 7 mg 降至4. 88 mg) ，但在随后的 9 d 内，INR 从 2. 62 升高到3. 82。 可见，酮康唑作为华法林主要代谢酶 CYP2C9 的中度抑制剂，在一定程度上可增加华法林的抗凝活性。
1. 3 唑类抗真菌药物与华法林的相互作用机制
2. 3 氟康唑对华法林的影响
华法林的代谢酶包括 CYP2C9( 主要代谢酶) 、CYP3A4 、 CYP1A2 、 CYP2C19 、 CYP2C18 、 CYP2C8 和CYP1A1。 影响 CYP2C9 代谢的药物对华法林的影响最大。 唑类抗真菌药物对 CYP2C9 的抑制活性: 咪康唑＞酮康唑≈氟康唑≈伏立康唑 ＞泊沙康唑，伊曲康唑和艾氟康唑对 CYP2C9 未见抑制活性。 由此推测，咪康唑对华法林的影响最大，而伊曲康唑和艾氟康唑影响较小。
ZHAO 等［10］等回顾性分析了21 例合并使用华法林和氟康唑的患者，发现与单用华法林相比，联用氟康唑 INR 值平均升高 2. 18 倍( P ＜ 0. 0001) 华法林敏感指数 ( INR /华法林日剂量，WSI) 升高 2. 07 倍( $P < 0 . 0 0 0 1 \}$ ，联用2 d 即可出现 INR 值明显升高，联用7 d 时相互作用达到峰值。 且作用强度与氟康唑使用剂量有关，50 ～ 100 mg 未出现明显的增强作用，200 ～400 mg 即出现明显的增强作用。 能引起华法林作用增效的氟康唑剂量在 200 mg 以上，且多数在合并用药后的第 2 天即出现 INR 值升高［21 － 22］。YAMAMOTO 等［3］回顾性分析了 18 例合并使用华法林和氟康唑的患者，患者的 INR 从1. 40 增加到2. 94，华法林相关代谢酶基因多态性( 主要为 CYP2C9、CYP2C19 和CYP3A4) 对华法林的抗凝作用具有重要影响，这也可能是引起药物相互作用不同效应的原因之一。根据药代动力学的理论，推测代谢酶为慢代谢型的患者，两者的相互作用将减弱;中间代谢型的患者两者相互作用一般; 快代谢型的患者，两者的相互作用最为明显［13］。
WSI 也从1. 06 上升至1. 89。 并得出了合并使用氟康唑时华法林的剂量的计算公式: $Y = 4 . 9 4 X - 3 . 9 6$ ，$r ^ { 2 } = 0 . 8 0 ;$ 其中，Y 为合并氟康唑的华法林剂量，X 为未合并氟康唑的华法林剂量。 SCHELLEMAN［23］通过对美国医疗补助数据中使用华法林并出现胃肠道出血的病例进行了病例对照和病例交叉研究，确定胃肠道出血和使用抗菌药物( 包括氟康唑) 之间的关系，结果显示氟康唑具有明显的增加华法林使用患者出现胃肠道出血的风险 ( OR = 2. 09 ［95% CI:1. 34 ～ 3. 26］) 。 氟康唑对华法林抗凝作用的影响在较短时间内( 合用后 1 d) 即可出现，且在 7 d 内达到峰值，INR 可升高 2 ～ 3 倍，因此，氟康唑与华法林开始联用时就应密切监测凝血功能。
2. 4 伏立康唑对华法林的影响
ZHAO 等［10］研究显示，以华法林联用伏立康唑治疗的 6 例患者，其平均 INR 值从联用前的 2. 03 升高至联用后的 5. 26( 升高 2. 59 倍， ${ \cal P } { < } 0 . 0 1 )$ ，高于氟康唑的 2. 18 倍。 YAMAMOTO 等［3］研究显示，5 例联合使用伏立康唑的患者，其 INR 由 1. 95 增加至 2. 89( P ＜0.05) ，INR 升高的比率低于氟康唑。 另有个案［24］报道了伏立康唑与华法林联用致 INR 升高的病例。 PURKINS 等［25］则采用双盲安慰剂对照、双向交叉研究方法，把17 例健康男性受试者分为 2 组: ( 1)给予伏立康唑 +华法林，随后是安慰剂 +华法林; ( 2)给予安慰剂 + 华法林，随后是伏立康唑 + 华法林，结果显示伏立康唑 + 华法林的凝血酶原时间大于安慰剂 + 华法林。 可见伏立康唑可明显增强华法林的抗凝效果，因此两者联用时应注意监测凝血功能。

2.5 伊曲康唑对华法林的影响
国内外均鲜见伊曲康唑对华法林作用影响的报道，伊曲康唑在人肝微粒体中抑制 CYP3A4 和CYP2C9 的 $\mathrm { I C } _ { 5 0 }$ 值分别为 $2 0 \mathrm { { , } 7 1 0 0 \ \mu g \cdot L ^ { - 1 } }$ ; 而伊曲康唑的血药浓度一般为 $> 1 \ \mathrm { ~ m g ~ } \cdot \mathrm { ~ L ~ } ^ { - 1 }$ ，伊曲康唑是CYP3A4 的强抑制剂，对 CYP2C9 的抑制作用有限，伊曲康唑对华法林的作用甚微。 YAMAMOTO 等［3］研究显示，伊曲康唑对华法林的抗凝活性影响，差异无统计学意义。 YEH 等［26］报道 1 例肺栓塞反复出现需要长期服用华法林的患者，因肺部念珠菌感染合用伊曲康唑 200 mg bid，4 d 后患者出现广泛的瘀斑和鼻出血，查INR 值大于8。 因此，伊曲康唑对华法林的影响还需要更多的病例佐证。
3 讨论
华法林联用唑类抗真菌药物时，需要密切监测凝血酶原时间( PT / INR) ，并根据结果调整剂量或更换抗真菌药物。 对于不同唑类对华法林抗凝作用的影响大小，咪康唑引起的华法林 INR 值的升高最多; 氟康唑引起的华法林 INR 值升高的时间最短; 伊曲康唑显示了不同的作用效果，可能与选取的病例不同有关。 根据肺真菌病诊断和治疗专家共识［27］和本文结论，对服用华法林合并真菌感染患者治疗给出如下推荐: 对于肺念珠病，推荐使用伊曲康唑、棘白菌素类或两性霉素 B，严重患者可联合 5 － 氟胞嘧啶。 对于肺曲霉病侵袭型，推荐伊曲康唑、卡泊芬净/米卡芬净、含脂质两性霉素 B。 对于肺隐球菌病，免疫功能正常的患者，轻、中症时用伊曲康唑、两性霉素 B; 重症时用两性霉素 + 5 － 氟胞嘧啶; 合并脑膜炎时用两性霉素 + 5 － 氟胞嘧啶。 对于肺隐球菌病，免疫功能缺陷的患者，轻、中症时用伊曲康唑; 重症时用两性霉素 +5 －氟胞嘧啶; 合并脑膜炎时用两性霉素 + 5 －氟胞嘧啶。 对于肺毛霉病，推荐两性霉素 B + 5 － 氟胞嘧啶。对于肺孢子菌病，推荐氨苯砜和氨苯砜 － 伯氨喹啉。未来不同唑类抗真菌药物对华法林的影响需要进行前瞻性的多中心、随机、双盲对照试验。

“抗菌药物循证用药论坛”在京举办
2019 年5 月22 日，由中国药学会中国临床药理学杂志、北京大学第三医院和北京大学医学部药物评价中心联合主办，深圳华润九新药业协办的“抗菌药物循证用药”论坛在北京顺利召开! 本次论坛邀请中国药学会中国临床药理学杂志常务副主编单爱莲教授、北京大学第三医院药剂科主任赵荣生教授担任大会主席。 北京市各药学领域专家学者 60 人出席会议，对抗菌药物热点问题进行深入地交流和学习。
会上，大会主席单爱莲教授和赵荣生教授对与会专家表示热烈欢迎。 赵荣生教授致大会开幕词。 华润九新药业市场部总监郎罡代表公司对参会专家的到来表示热烈欢迎，同时表达了公司履行企业社会责任，秉承“关爱大众健康”宗旨，致力于研发、制造优质药品服务社会的决心大会精选了5 个专题报告冯婉玉教授和赵荣生教授主持了学术报告环节杨帆教授作“规范 β 内酰胺类抗生素皮试”学术报告，明确指出，头孢菌素皮试筛查并无实质预测价值，滥做皮试滥解释不仅延误患者治疗时机，增加经济负担，还大幅缩窄患者治疗选择，造成抗菌药物滥用。 胡昌勤教授作“头孢菌素类药物质量一致性评价关键要素”学术报告，头孢菌素一致性评价关键要素之一是降低临床应用的药物不良反应发生率; 关键要素之二是通过工艺优化提高产品稳定性。 五水头孢唑林钠独立的螯合晶体结构，使药物不良反应发生率明显较同类产品更低，有效解决澄清度问题，降低杂质含量。 华张菁教授作了“阿奇霉素研究前沿及循证药学依据”主题报告，报告中引用了目前全球范围内针对阿奇霉素的最新科研成果，用详实的数据阐述了阿奇霉素在国内外的地位及循证用药依据，强调了阿奇霉素抑制细菌生长和炎症反应“内外兼修”双重作用，有力地论证了体外阿奇霉素耐药并不等同于临床无效。 翟所迪教授作“严重过敏反应救治指南的制定和解读”学术报告，分享了指南制定的历程，并对严重过敏反应的机制，救治措施进行详细讲解杨丽教授作“药师在抗菌药物管理和治疗中的作用”学术报告，分享了北京大学第三医院在抗菌药物管理相关制度方面的建设，对与会单位具有重要借鉴意义。
