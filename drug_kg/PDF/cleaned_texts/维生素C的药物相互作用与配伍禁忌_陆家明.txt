如何看待维生素C片剂的酸性维生素C片剂压制过程中，无中和措施，应为酸性药物，但在体内能否产生酸性效应呢？维生素C主要在体内代谢分解成草酸、二酮古乐糖酸或与硫酸结合形成抗坏血酸2一硫酸酯由尿排出，也有部分直接以原形排出体外[5]。过去认为维生素C能酸化尿液，使在酸性尿液中溶解度较小的药物(磺胺类药物如常用的SMZ Co等)析出结晶，损害肾脏，现已被大量的实验所否定，如李义和等[6]报道口服维生素C 600～900 mg / d ，服药前后尿液无显著性差异。郑明新等[7]用超常剂量维生素C(0.5g, tid, 1.0g tid, 1.5g tid)给健康受试者口服，结果对尿液值无显著影响，与国外报道口服大剂量维生素C(4～6g)并不酸化尿液相符。刘士俊[8]用常用剂量SMZ Co(0.96g, bid)和维生素C(0.2g, tid)及常用量± 50\% 剂量口服，结果也证明对不同类型病人尿液值无影响。阮计章[9]、徐丙桢[10]等也有类似研究报道。故在临床常规使用SMZ Co和维生素C时，不必视为禁忌，如确需长期服用时，可嘱病人多饮水，以促进药物排泄。其可能的解释是，机体是一个大的缓冲体系，对外界影响有一定的调节能力，维生素C在体内吸收快，代谢快，与无机盐尿液酸化药氯化铵作用不同。
从 1996 年《新药与临床》抗菌药物征文及最近有关文献 [1] 中看到，仍有作者简单根据维生素 C 的酸性，提出维生素 C 与某些药物的相互作用或配伍禁忌，鉴于维生素 C 临床应用甚为广泛，从合理用药考虑，就有关问题阐述如下。
维生素 C 又名抗坏血酸(ascorbic acid)，分子中含有酮一烯醇式结构，因此抗坏血酸的水溶液是强酸性，其 50 mg/mL 溶液的 pH=2,5 mg/mL 溶液的 pH=3。
维生素 C 注射液不能算酸性注射液为了避免注射液酸性的刺激, 中国药典规定维生素 C 注射液 pH 值为 5.0 7.0, 故配制注射液时已加入计算量的碳酸氢钠, 中和了部分维生素 C 分子中的羧基, 使抗坏血酸部分变成了抗坏血酸钠。我们不应把维生素 C 注射液作为酸性药来对待, (如注射用水 pH 为 5.0 7.0, 氯化钠注射液 pH 为 4.5 7.0 一般也不作为酸性溶媒), 在临床应用时把它加入输液后, 反而可使 5% 或 10% 葡萄糖注射液 pH 值提高 (从 pH4.55 4.85 升高至 6.3 6.7)。
维生素 C 注射液与其他药物配伍禁忌问题
1 与氨苄西林、青霉素可否配伍维生素 C 注射液在配制过程中要加入焦亚硫酸钠作抗氧剂，焦亚硫酸钠在水溶液中即生成亚硫酸氢钠 (Na2S2O5+H2O 2NaHSO3 ) ，青霉素、氨苄西林等内酰胺类抗生素能被亚硫酸氢钠催化分解，在 pH 6.5, 60℃ 下催化系数比较，青霉素 G 为 4.9，氨苄西林为 32，后者受到更显著的催化作用 [2] ，因此维生素 C 与氨苄西林之间的配伍禁忌，并不是一些资料中提出的是维生素 C 注射液的“酸性”所致 [3] ；而青霉素与维生素 C 注射液则是可以混合注射的 [4] 。
2 与氨茶碱、碳酸氢钠、谷氨酸钠和钾注射液配伍问题氨茶碱注射液 pH 值在 9.6 以下即使稀释于输液也不应与维生素 C 混合；碳酸氢钠注射液应用时一般均是分瓶输注；谷氨酸钠和钾注射液 pH 值为 7.5～8.5，应用时一般以 3:1, 2:1 或 2:2 配合，然后加入葡萄糖注射液 500～1000 mL 中静脉滴注，作者通过试验及检索有关资料，结果认为是可配伍的(海普医药交流 1993;9:28)。

新药与临床 New Drugs and Clinical Remedies 1997 年 3 月;16(2):124李延鸿, 陈嘉榆(广州市职业病防治院, 广东广州 510420)氧氟沙星(ofloxacin)具有第3代喹诺酮类抗菌活性，对多种革兰阳性和阴性菌有良好的抗菌活性，对肺炎支原体、结核杆菌、沙眼衣原体也有一定的抗菌效果。临床上少见有该药引起心律失常的报道，现将我院发现的1例报告如下。
病人, 男性, 84 a, 因患慢性支气管炎伴肺气肿、肺心病、冠心病住入我院。查体: 血压 18/10 kPa, 心率 100 次/min, 心电图检查提示窦性心动过速, P 波高尖 (0.22 0.24 mV), 左前分支传导阻滞, T 波改变。1995 年 7 月 21 日因肺部感染而给予静脉滴注 (静滴) 氧氟沙星 200 mL (含氧氟沙星 400 mg, 浙江温州制药厂生产, 批号: 950316), 滴速为 40 滴/min, 约 15 min 后, 病人感胸闷、头晕、上半身大汗淋漓、心慌、气短、呼吸困难等症状, 血压: 19/10 kPa, 心率: 120 次/min，心律不齐。即作心电图检查，提示：窦性心动过速，偶发房性早搏。左前分支阻滞，双侧心房肥大。停药后好转。同年8月1日又因肺部感染而给予氧氟沙星200 mL（批号：950504，厂家同上），静滴，qd，为避免上次情况的出现，滴速控制在30滴/min，约10 min后再次出现心慌、大汗淋漓等同上所述情况，血压18/10 kPa，心率125次/min，心律不齐，即停药，给予吸氧处理后症状逐渐好转，此后改用其他抗生素静滴未见同样症状，肺部感染得到控制。
讨论本例先后 2 次使用氧氟沙星时均出现胸闷症状，心电图检查提示：窦性心动过速，偶发房性早搏，且用其他抗生素治疗时未出现同样症状，故认为其心律紊乱为静滴氧氟沙星所致，临床应用于老年病人时应注意观察。
