2 讨论
他克莫司是一种具有大环内酯类结构的免疫抑制药，属钙调神经磷酸酶抑制药［1］，在肾移植术后的应用越来越广泛其治疗窗窄药动学个体差异较大血药浓度影响因素较多［2］ 尤其是当移植术后抗排斥治疗时感染等合并症联合用药可能引发药物相互作用导致其药动学改变本文主要讨论肾移植术后患者他克莫司血药浓度的影响因素其中重点探讨临床较少见的他克莫司与替加环素的药物相互作用，为移植术后个体化用药提供参考。
他克莫司与药物相互作用影响
目前已知可升高他克莫司浓度的药物常见唑类抗真菌药物大环类酯类抗菌药物五味子提取物部分质子泵抑制药等［11］ 排查该患者他克莫司合并用药未发现上述常报道药物结合他克莫司血药浓度升高时间段治疗药物变更仅月日患者加用了替加环素。
患者人口生物学因素及病生理指标的影响
替加环素为新一代甘氨酰环素类广谱抗菌药物目前关于替加环素与他克莫司发生药物相互作用的案例报道极少。 2011 年文献报道了 1 例 51 岁肾移植后感染性休克女性患者使用替加环素治疗过程中他克莫司血药浓度显著升高该患者未服用其他可能与他克莫司相互作用的药物且停止使用替加环素治疗后，他克莫司血药浓度明显下降［12］。年另例岁肾移植后尿路感染的男性患者，使用替加环素后他克莫司 $C _ { \mathrm { o } }$ 急剧上升，联合用药 6 d 后由初始 $1 1 . 5 \mathrm { n g } \cdot \mathrm { m l } ^ { - 1 }$ 升高至 $2 8 . 2 \ \mathrm { ~ n g ~ } \cdot$ $\mathrm { m l } ^ { - 1 } , 1 0 \ \mathrm { d }$ 后进一步升高达到 $4 3 . 6 ~ \mathrm { n g } \cdot \mathrm { m l } ^ { - 1 }$ ，停用替加环素第 1 周恢复［13］。 除此外未发现相关病例报道但年美国食品药品管理局关于注射用替加环素的药品信息增加了药物相互作用内容替加环素与钙调磷酸酶抑制药合用会增加后者暴露量建议在替加环素治疗期间监测钙调神经磷酸酶抑制药的血药浓度以避免过高药物浓度所致药物毒性替加环素与他克莫司药物相互作用机制尚不明确他克莫司由细胞色素酶代谢与他克莫司相互作用的药物是同功酶诱导药或抑制药而替加环素主要通过胆道消除次要途径包括肾脏排泄以及葡萄糖醛酸化，无 CYP450 酶系统关联的描述。 根据替加环素与环孢素、华法林药物相互作用结果［14，15］ 推测尽管体外研究表明替加环素不影响但不能排除其在体内的影响；另一方面，替加环素蛋白结合率中等水平，其潜在影响其他药物蛋白结合水平或改变结合位点进而发生相互作用的可能。
他克莫司血药浓度与患者年龄等因素相关，有研究提出儿童肝脏相对成人较大，导致较高的肝脏清除率而超重和肥胖患者他克莫司血药浓度较高，肥胖患者他克莫司剂量明显小于 $\mathrm { B M I } < 2 5 ~ \mathrm { k g }$ $\cdot \mathrm { m } ^ { - 2 }$ 的患者影响他克莫司生化指标方面研究表明对他克莫司血药浓度有显著影响他克莫司进入体内与红细胞特异性结合当较高时他克莫司结合率升高导致游离型药物减少清除率降低且他克莫司主要经肝脏代谢因此肝功能异常亦能影响药物在体内的清除。 综合该患者年龄、以及可能影响他克莫司血药浓度的病生理指标，他克莫司血药浓度升高前后相关检查数据基本正常且无较大波动考虑血药浓度变化与上述因素关联性不强。

3 小结
器官移植术后存在较高的感染风险，在使用免疫抑制药基础上常联合抗感染药物治疗他克莫司是实体器官移植术后主流的免疫抑制药之一也是肝脏酶系的底物临床上与许多药物存在相互作用本文介绍例他克莫司与替加环素发生药物相互作用进而导致他克莫司血药浓度显著升高的案例尽管目前他克莫司与替加环素药物相互作用机制不明，但已有极少数的案例报道，并且药品信息也增加了相关药物相互作用警示信息建议在替加环素治疗期间监测钙调神经磷酸酶抑制药的药物浓度临床药师需要提高警惕不可忽视少见的药物相互作用同时也期待更多的研究探讨两者药物相互作用机制
