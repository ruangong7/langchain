利福平与其他药物相互作用研究进展
何婷,张民作者单位新疆维吾尔自治区阿克苏地区阿克苏地区中医医院何婷
730050 兰州市,甘肃省中医院临床药学科(何婷、张民)
【摘要】 利福平是一线抗结核药物,是一种强效的细胞色素 P450(CYP)酶系统及 P 糖蛋白(P-gp)转移系统的诱导剂临床可与多种药物发生相互作用这些相互作用主要体现在药动学和药效学两个方面文章就近年来国内外关于利福平的相互作用研究进行综述,为临床合理使用利福平提供参考。
利福平常与其他抗结核药物联用于各种结核病的初治与复治如结核性脑膜炎的治疗[1] 利福平适用于无症状脑膜炎奈瑟菌带菌者以消除鼻咽部脑膜炎奈瑟菌,也可用于治疗肺炎链球菌脑膜炎,但不适用于脑膜炎奈瑟菌感染的治疗。 利福平可与其他药物联合治疗麻风非结核分枝杆菌感染利福平对结核分枝杆菌和部分非结核分枝杆菌麻风分枝杆菌等在宿主细胞内外均有明显的杀菌作用利福平对需氧革兰阳性菌(葡萄球菌产酶株、甲氧西林耐药株、肺炎链球菌肠球菌属炭疽杆菌产气荚膜杆菌白喉杆菌厌氧球菌等具良好抗菌作用对需氧革兰阴性菌如脑膜炎奈瑟球菌流感嗜血杆菌脑膜炎奈瑟菌等亦具有高度抗菌活性对嗜肺军团菌具有强大抗菌作用对沙眼衣原体伯氏考克斯体等病原体均有良好的抗微生物活性利福平作为一线抗结核药物与其他药物联合对多种药物代谢酶及药物转运体存在诱导及抑制作用,引起的药物相互作用复杂多变笔者综述近年来利福平与合并使用药物的相互作用为临床合理用药提供参考
2 与利福平发生相互作用的药物
2.1 镇静催眠药利福平可诱导三唑仑、唑吡坦、佐匹克隆经的代谢降低其疗效临床禁止联用等[4]考察口服利福平对单剂量三唑仑药动学和药效学的影响结果发现利福平使三唑仑曲线下面积(AUC)减少,使 $\mathrm { { C } _ { \mathrm { { m a x } } } }$ 由 $( 2 . 9 { \pm } 0 . 2 ) \mathrm { n g / m l }$ 降至 $( 0 . 3 6 { \pm } 0 . 0 6 ) \mathrm { n g / m l }$ 使 $\mathrm { t } _ { 1 / 2 }$ 从 $( 2 . 8 { \pm } 0 . 1 ) \mathrm { h }$ 缩短至$( 1 . 3 { \pm } 0 . 1 ) $ 三唑仑的药效显著下降利福平会使佐匹克隆减少 $\mathrm { C } _ { \mathrm { m a x } }$ 降低催眠作用显著减低[5]。 利福平会使扎来普隆的 $\mathrm { C } _ { \mathrm { m a x } }$ 和 AUC 降低。 苯二氮艹卓类口服药(如阿普唑仑、艾司唑仑、氟西泮、奥沙西泮氯硝西泮地西泮等与利福平联用会发生类似相互作用,利福平诱导肝微粒体酶如 CYP3A4、CYP2C19 增加苯二氮艹卓类药的代谢消除,致血药浓度降低故利福平与这些苯二氮艹卓类联用需谨慎
1 利福平与其他药物相互作用的机制
肝药酶是肝细胞内用于转化药物的酶系统细胞色素是肝脏的主要药物代谢酶参与临床常用药物的代谢其主要包括CYP1A2、 CYP2A6、 CYP2B6、 CYP2C8、 CYP2C9、CYP2C19、CYP2D6、CYP2E1、CYP3A4、CYP3A5 等,其中以酶系作用最强[2] 酶主要参与药物体内代谢相反应,负责药物的生物转化[3]。利福平对CYP3A4、CYP2C9、CYP2C19 和CYP2B6存在诱导效果, 对 CYP3A4 的诱导作用最强, 对的诱导作用最弱发生药物相互作用的原因是,利福平可诱导 CYP450(特别是 CYP3A)代谢,并轻微诱导 CYP2C 和葡萄糖醛酸化,从而加速药物排泄,还可增加肠道 $\mathrm { P - g p }$ 介导的药物外排,从而减少作为 $\mathrm { P - g p }$ 底物的药物在胃肠道被吸收降压药利福平可诱导介导的肠壁内二氢吡啶类钙通道阻断剂的代谢导致钙通道阻断剂的血浓度降低降低抗高血压药的降压疗效如硝苯地平、马尼地平、尼卡地平、拉西地平、巴尼地平、非洛地平、尼莫地平、尼索地平等避免联用。 苯磺酸氨氯地平为弱抑制剂与利福平联用时氨氯地平的血药浓度变化较大,密切监测血压,必要时调整剂量酒石酸美托洛尔是一种的作用底物利福平可诱导美托洛尔的代谢导致美托洛尔的血药浓度降低, 进而使其疗效下降。 Tapaninen 等[6] 考察CYP3A4 和 $\mathrm { P - g p }$ 诱导剂利福平对肾素抑制剂阿利吉仑药动学和药效学的影响,发现联用利福平使阿利吉仑 $\mathrm { { C } _ { \mathrm { { m a x } } } }$ 降低 39% , $\mathrm { A U C } _ { 0 \to \infty }$ 减小 56%,但没有影响阿利吉仑的 $\mathbf { t } _ { 1 / 2 }$ 和肾脏清除率,临床应该避免联用。
谢等[13]通过健康受试者考察利福平对厄洛替尼药动学的影响发现厄洛替尼剂量越大利福平对其诱导代谢越显著,临床应避免联用。 索拉非尼和吉非替尼是经肝脏代谢与 CYP3A4 酶活性有关,与利福平同时给药分别平均减少和 [1]等[14]考察诱导剂利福平对阿法替尼药动学的影响,发现联用利福平,使阿法替尼 $\mathrm { { C } _ { \mathrm { { m a x } } } }$ 降低21. 6% ,使 AUC 减少 33. 8% ,对 $\mathbf { t } _ { 1 / 2 }$ 无影响。 利福平可诱导肝微粒体酶,增加抗肿瘤药达卡巴嗪、环磷酰胺的代谢烷化代谢物的形成促使白细胞减少因此需调整剂量。
2. 6 抗感染药物
黄色葡萄球菌有协同抗菌作用利福平与喹诺酮类联用可改变喹诺酮类的药物消除动力学降低其血浆浓度从而使其药效降低研究显示培氟沙星与利福平联用,药理作用相互拮抗。 莫西沙星体内的代谢主要是经催化形成葡糖苷酸代谢物经催化形成硫酸结合物酶几乎不参与莫西沙星代谢。 利福平与克拉霉素联用,可加速克拉霉素的代谢降低克拉霉素的血浆浓度使疗效减弱。 甲氧苄啶与利福平联用时可明显增加清除,血清半衰期缩短替硝唑与利福平联合给药可能加速替硝唑的消除降低血浆中替硝唑浓度酮衍生物口服或其他系统性激素类避孕药等联用时可加速药物代谢使药物的药效减弱上述药物与利福平联用需适当调整剂量与香豆素或茚满二酮类、抗凝药物联用时,建议每日监测凝血酶时间,据以调整剂量维持抗凝剂的有效剂量丙磺舒可与利福平竞争被肝细胞的摄入使利福平血药浓度增高并产生毒性反应氯苯酚嗪可减少利福平的吸收达峰时间延迟半衰期延长抗酸药和利福平联合应用可降低利福平的吸收,建议在服用抗酸剂前至少 1 h 服用利福平依托考昔是一种非甾体抗炎药与利福平联用可使其血浆 AUC 减少 65%,联用时需考虑其相互作用。 孟鲁司特通过 CYP3A4、2C8 和 2C9 代谢,谨慎与酶诱导剂利福平同时服用,特别是儿童。
3 小结
利福平是利福霉素类的半合成广谱抗菌药,作为一线抗结核药物需与其他药物联用利福平是强诱导剂,对其他药物的药动学和药效学产生一定的影响,降低联用药物的血药浓度,疗效减弱,甚至失效但存在使联用药物吸收增加血药浓度增加的现象。 临床既要看到利福平相互作用的有利方面,充分利用其效益根据相互作用的结果合理地调整用药又要避免利福平与其他药物的相互作用引起的不良反应,提高利福平用药的安全性,降低用药风险。
