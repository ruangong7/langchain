南北五味子及其制剂与其他药物相互作用的研究进展
冯格 ， ，翟健秀 ， ，陈万生 ，熊筱娟 ，高守红 ，杨阳 ，夏天一 ，张凤 ( 1． 第二军医大学长征医院药材科，上海200003;2． 宜春学院化学与生物工程学院，江西宜春 3360003; 沈阳药科大学中药学院，辽宁沈阳 110015)［摘要］ 五味子为木兰科植物五味子( 北五味子) 及华中五味子( 南五味子) 的干燥成熟果实，其制剂已被广泛应用于临床。本文综合了近些年国内外相关文献，对南北五味子作用机制进行归纳总结，对南北五味子与其他药物的相互作用以及其相关制剂的联合用药进行了概述，从而为临床安全用药提供参考。
五味子为中医药常用及名贵药材，始载于神农本草经，列为上品，有 “北五味子 ” ( Schisandraechinensis fructus ) 和 “ 南五味子 ” ( Schisandraesphenantherae) 之分，然而，由于南五味子价格低廉且与北五味子具有相似的特性，民间常将二者有意或无意的混用作为滋补强壮药，但南北五味子两种生药的主要活性成分含量、药理作用以及药材质量等方面存在较大差异性，自 2000 年版 《中国药典》起，将五味子分别收载为五味子和南五味子两个品种［1-2］。 五味子习称 “北五味子”［3］，为木兰科( mag-noliaceae) 五味子属 ( Schisandra ) 植物五味子［Schisandra chinensis ( Turcz． ) Baill． ，简称 SC］的干燥成熟果实，而南五味子为同属植物华中五味子( S． sphenanthera Rehd ，简称 ) 的干燥成熟果实。 南北五味子具有代表性的成分主要是木脂素、三萜酸及内酯等［］，其制剂如五酯胶囊( 来源为南五味子， ) 五酯片( ) 五酯软胶囊( ) 等为临床常用处方药; 含有五味子的非处方类药物如五味子颗粒( 来源为五味子， ) 、五味子糖浆( ) 等作为养心安神药，多数患者会自行购买服用。
药物相互作用是指两种或两种以上的药物合用时引起的药效变化，即产生相加( 增加) 、协同( 增效) 、拮抗( 减效) 作用，合理的联合用药可增强疗效或降低不良反应，反之则疗效降低或毒性增加，还可能引发异常反应，干扰治疗使病情加重。 因此，在进行联合用药时了解药物的作用机制，熟悉药物之间的相互作用是很有必要的。 中药作为一种辅助性治疗药物及食用材料逐渐被广泛使用，但其存在的潜在的药物相互作用也越来越引起警觉，且由其引起的药物相互作用亦是临床上用药安全性和临床实践中存在的关键性问题［5-6］。 上述中药五味子制剂为临床常用药物，尤其是五酯( 软) 胶囊和五酯片，具有良好的护肝保肝作用，但在临床联合用药时发现其可与其他药物产生相互作用，从而对联用药物的疗效产生影响。 含五味子的非处方类药物如五味子糖浆有较好的镇静安神作用，但若患者就医不加陈述，也有可能存在潜在药物相互作用的情况。 除此以外，作为一种常用名贵中药材，五味子还可用于保健品、化妆品、食品等。 因此，本文对南北五味子及其制剂与其他药物的相互作用机制及其相互作用进行了综述，为临床安全合理的联合用药提供参考依据，同时为五味子在其他领域的安全使用提供重要信息 。
1 五味子( SC 或 SS) 与其他药物发生相互作用的机制
五味子( 或 ) 引发的药物相互作用中，细胞色素酶系( ， ) 和药物转运体 P-糖蛋白( P-glycoprotein，P-gp) 起着重要作用，大部分药物例如抗肿瘤药物均是通过 CYP3A4 代谢，同时也是 P s p 的底物，而五味子( 或 ) 对P 及 CYP3A4 活性均有明显的抑制作用［7-8］。 因此，研究五味子及其制剂与其他药物发生相互作用的机制是非常有意义的，临床在联合用药时需引起警惕 。
1 ． 1 五味子( SC 或 SS) 对 CYP450 酶系的影响CYP450 酶系是药物一相代谢的主要酶，在药物代谢中占有重要地位，与约的药物代谢相关，其中 CYP3A4 在其异构体中表达量最多，且有 50% 以上的药物通过此酶代谢［］。 有研究表明，CYP3A4对 CYP3A4 mRNA 的表达具有诱导作用，此作用同利福平相当［10-11］。 临床用药时发现五味子制剂( SC或 SS) 可影响联用药物的生物利用度，对联用药物的药动学产生影响。 近年来，研究者对南北五味子提取物单体对 CYP 酶影响开展的研究已成为热点，主要是通过建立人或大鼠肝细胞体系以及肝微粒体酶体系进行实验，并发现其对 CYP 酶可产生不同的作用，表现为诱导或抑制作用。 陈倩等［8，12］通过研究五味子( ) 提取物对大鼠肝细胞体系或肝微粒体 CYP3A 酶活性的影响，发现五味子提取物对CYP3A 酶具有短时间抑制、 长时间诱导的双重作用，单体化合物五味子甲素、五味子乙素可以显著抑制大鼠原代肝细胞的 CYP3A 酶活性。 唐霞等［ ］通过动物体内实验对五味子( SC) 水溶性提取物以及南五味子( ) 对小鼠双重作用进行研究，发现小鼠在灌胃给药12 h 后可对 CYP3A 具有抑制作用，第3 天则抑制转为诱导作用，第6 天则仅为诱导作用，同时通过体外小鼠肝微粒体酶孵育实验发现南五味子对 CYP3A 呈剂量依赖性抑制作用由提取物引发研究者对单体成分的研究，李丹等［ ］通过体外人肝微粒体孵育实验研究五味子酯甲( 或) 对酶活性的抑制作用，结果表明五味子酯甲对的抑制能力大于 ，结果相似于陆兔林等［9］的研究 。 Iwata 等［15-16］通过建立大鼠以及人肝微粒体酶体系对五味子( ) 对酶的影响进行研究，发现多数单体成分如五味子醇乙、五味子酯甲、五味子酯乙、戈米辛 ，，， 等可对酶的活性产生影响，其对具有不同程度的抑制作用，其中五味子酯甲的抑制作用比酮康唑还要强，且对大鼠肝微粒体和人肝微粒体抑制作用最强，表现为浓度和剂量依赖性。李维亮等［ ］通过对五味子乙素( SS) 影响大鼠肝微粒体 CYP3A 的探讨，发现其对大鼠肝微粒体CYP3A 具有非竞争性可逆性的抑制作用。 五子衍宗丸具有保肝护肾之功效，Chen 等［18］通过细胞实验发现该制剂提取物对酒精引起的肝损伤具有保护作用，并推测这可能与五味子通过影响的活性增强机体抗氧化能力有关。 另外，查阅国内外文献并总结发现不同木脂素单体成分对 CYP450 同工酶的影响不同，如五味子酯甲主要影响 、CYP2C6 /11 、 CYP2E1 、 CYP3A; 五味子醇甲主要影响CYP2C6 /11 、 CYP2E1 、 CYP3A /2; 五味子甲素主要影响 、 、 、 ; 五味子乙素主要影响 CYP1A2 、 CYP2D2 、 CYP2E1 。 由此可见，在临床用药时五味子( SC 或 SS) 制剂可能会对多种联用药物产生相互作用。
1 ． 2 五味子( SC 或 SS) 对 pg p 的影响 P-gp 是一种能量依赖性的跨膜糖蛋白，具有 “药泵”功能，既可结合药物，又能与ATP 结合，由ATP 供能使胞内药物泵出胞外，降低了细胞内的药物浓度，使细胞产生耐药性。 本课题组前期通过细胞转运实验，发现五酯胶囊及其活性成分五味子醇乙、甲素、酯甲的作用与阳性药物 pg p 的抑制剂维拉帕米相似，均可降低他克莫司的转运率，表明五酯胶囊及其主要活性成分具有逆转 P · g p 外排他克莫司的作用，同时也是五味子( SS) 使他克莫司血药浓度升高的原因之一［19］。 F o ng 等［20］ 通过建立细胞转运模型实验研究五味子醇甲对 P · g p 的影响，结果表明五味子醇甲可通过影响 P - g p 底物复合物逆转 P - g p 介导的多药耐药性，从而使 P · g p 底物在细胞内的浓度增加。
2 五味子( SC 或 SS) 及其制剂与其他药物的相互作用
2． 1 五味子( SC 或 SS) 与其他药物的相互作用南北五味子( SC 或 SS) 功效多，研究其提取物或活
性成分与其他药物的相互作用已成为热点。 如五味子( ) 与西药氯吡格雷相互作用的研究: 氯吡格雷为血小板聚集抑制药，临床上可用于治疗心脑血管等疾病。 作为前药，需经体内和代谢生成有活性的产物发挥作用，但仅有的药物代谢成活性产物， 的药物代谢为无活性的 SR26334［21］ 。 戴歌心等［22］研究表明五味子提取物( ) 单次给药对氯吡格雷在大鼠体内的药动学影响不明显，长期给药会使其羧酸代谢产物SR26334的AUC和 C m a x 明显减少; 另外，由于实验中氯吡格雷原型物代谢迅速，灵敏度低，后就无法检测其含量，因此用无活性物的减少来反映活性产物的增多。 考虑到氯吡格雷在体内主要经酶同工酶CYP2C19 和 CYP3A4 生成活性产物，由此推测五味子长期用药能够诱导和的活性，促进原型代谢，可能增强氯吡格雷抗血小板的作用，具体机制尚待进一步研究。
由于五味子( 或 ) 具有抗癌、 抗氧化、 保肝、调节中枢神经系统等作用，研究发现与其他中药联用的机会很多，因此发生药物相互作用的可能性较大。 吴茱萸具有抗肿瘤、抗菌、抗病毒、治疗心血管系统、消化系统等疾病，五味子与吴茱萸联用可产生协同作用的效果，严子玲［23］通过建立体循环灌流模型来考察五味子( ) 配伍对吴茱萸肠吸收的影响，结果表明前者可促进后者的吸收，并推测这很可能与 P s p 被抑制有关。 且不同浓度的五味子对 P糖蛋白的作用也不同，表现为低浓度诱导、中高浓度抑制的作用。 黄芩具有保肝护肝的作用，与五味子配伍可有增效作用，韩敏等［ ］通过对大鼠给药黄芩及五味子( ) 提取物，结果表明两药联用后，除了防治肝损伤、肝纤维化方面具有显著的协同作用外，五味子酯甲、黄芩苷的 t 1 / 2 均显著延长， A U C , C m a x 也明显升高，二者血药浓度长期维持在较高水平，从而使两药疗效增强。
由于五味子 ( SC 或 SS) 及其制剂主要对CYP3A4 酶活性影响较大，因此多数研究采用探针药物法考察其对咪哒唑仑的代谢影响来评价肝药酶CYP3A 活性的改变。 吴笑春等［ ］发现健康受试者服用五酯胶囊后，咪哒唑仑的 C m a x 和 A U C 0 - 2 4 明显增加， t m a x 延迟倍， ( ) 有所降低，表明五酯胶囊对CYP3A4 酶抑制作用较强; 亦有相似研究［36-37］表明五味子甲素、五味子乙素对具有显著的抑制作用，通过体内实验研究发现甲素、乙素对咪达唑仑代谢的抑制呈剂量依赖性2． 2 五味子( SC 或 SS) 制剂与其他药物的相互作用由于药物代谢是导致药动学个体差异的关键因素，因此考察五味子制剂( 或 ) 与其他药物联用时是否影响药物代谢酶的活性，能够为临床的合理用药提供科学依据。 免疫抑制剂主要用于器官移植抗排斥反应和自身免疫病，五味子制剂与之联合用药时可影响其药动学。 他克莫司在临床上常用于治疗肝脏或肾脏移植术后其他免疫抑制药物无法控制的移植排斥反应，但其价格相对昂贵。 多个研究发现中药五酯胶囊( ) 在与他克莫司联合用药用于器官移植患者术后治疗的时候，不仅发挥保肝作用，同时提高了他克莫司的血药浓度和生物利用度，减少其使用剂量，已经成为器官移植科常用的他克莫司“节约剂”，大大减轻患者的经济负担［25-26］。 课题组前期［19］通过人肝微粒体孵育实验发现五酯胶囊及其活性成分对 、 、 、和均有抑制作用，并证实了他克莫司为 P 和的共同作用底物，该研究不仅阐明了上述两药联用的作用机制，同时为临床安全用药提供参考。 相关研究表明，五味子酯甲、醇甲［20］、 甲素［27］、 醇乙［28］具有逆转 P 外排的机制且不影响 P b p 自身的表达，这与课题组前期研究相似。 与上述研究类似，隋忠国等［29］通过大鼠体内研究发现五味子酯甲可以剂量依赖性提高大鼠体内他克莫司的 C m a x 和 A U C 0 - 。 刘龙山等［ ］通过探索五酯片用于肾移植患者对他克莫司药动学及其长期疗效影响，发现与五酯片联用后患者体内他克莫司的C 0 · C m a x · A U C 0 + 1 2 h均显著提高， t m a x 明显推迟，对患者进行随访发现患者服用他克莫司的量明显减少，表明五酯片可显著提高他克莫司的生物利用度。 西罗莫司是比他克莫司更新的免疫抑制剂［31-32］，二者代谢相似主要经 CYP3A 酶代谢［33］，徐文等［34］探索五酯软胶囊与西罗莫司联用后对后者在大鼠体内的药动学产生的影响，结果显示五酯软胶囊在极低、低、中、高剂量联合给药西罗莫司后在大鼠体内的 C m a x 、A U C 0 - 逐渐升高，但 t 1 / 2 变化不明显，从而表明五酯软胶囊可以通过抑制 CYP3A4 酶的活性促进西罗莫司的吸收。
五味子( 或 ) 及其制剂主要是通过影响CYP450酶及 P b p 的活性与其他药物产生相互作用，从而影响联合药物的血药浓度及生物利用度。伴随着不同新药出现，五味子( SC 或 SS) 与其他药物的联合用药也与日俱增，通过药物相互作用可能会使联用药物的血药浓度增加带来毒副作用; 也可能会降低其血药浓度甚至使其失效。 因此，对于产生药物相互作用的药物，需对临床患者进行跟踪观察，对药物浓度进行适时合理的监测，从而为临床安全用药提供保障。
五味子和华中五味子均属木兰科五味子属植物，由于主要成分含量差异较大， 年版 《中国药典》虽将五味子和华中五味子的干燥成熟果实分别收载为五味子和南五味子，但功能主治方面仍一致，且 2015 年版 《中国药典》［38］仍未将其功效分开，因此，还需进一步研究。 有研究表明［1，39-42］南北五味子化学成分的差别主要体现在: 北五味子( ) 所含五味子醇甲和五味子乙素的含量较高，五味子酯甲和五味子甲素的含量低于南五味子，且北五味子中木脂素总量高于南五味子; 南五味子( ) 中不含五味子乙素，但其所含五味子酯甲和五味子甲素含量均高于北五味子，五味子醇甲含量较低。 由此可见，两者成分含量差异较大，不能混为一谈，所以两者以及两者各自制成的制剂对于酶和 P 的影响也不一样，从而与联用药物相互作用产生的疗效也不同 。
总之，由于南北五味子与其他药物存在相互作用，所以在作为食品、保健品甚至化妆品等使用时应引起警惕，同时由于二者主要成分含量不同在药物相互作用方面也会有差异性，使其制剂与其他药物联用产生的药效也会不同。 因此解决南北五味子制剂在临床上混用的问题已引起临床医生及广大研究者的共鸣。
