环泊酚注射液与利福平胶囊的药物相互作用研究
马媛媛 1，陆玲庆 1，凌云 1，刘筱 2（1 上海市公共卫生临床中心，上海 201508；2 四川海思科制药有限公司，成都 611130）目的通过研究环泊酚注射液与 CYP2B6 酶强诱导剂利福平的药物相互作用（DDI），评估环泊酚在代谢过程中可能受到【摘要】的潜在 CYP 酶的影响。方法该研究是一项在健康受试者中进行的单中心、开放、随机、两阶段、两交叉临床研究。通过比较利福平胶囊对环泊酚注射液的药动学（PK）、药效学（PD）及安全性的影响，对环泊酚与利福平的 DDI 进行分析。结果与单用环泊酚注射液相比，稳态利福平对环泊酚 $\mathsf { A U C } _ { _ { 0 - \infty } , \mathrm { ~ \tiny ~ A U C } _ { 0 - \mathrm { i n f } } } \mathbb { Z } C _ { \mathrm { m a x } }$ 均无显著性影响；2 组双频指数（BIS） $\mathrm { \ A U C _ { 0 - t } }$ 和 $\mathrm { B I S } _ { \mathrm { p e a k } }$ 几何均数比值的90% 置信区间均在 80.00%\~125.00%。稳态利福平对环泊酚的药效（BIS 值）及安全性和耐受性均无显著性的影响。结论环泊酚的 PK 参数、PD 参数、安全性及耐受性指标均不受 CYP2B6 诱导剂利福平的影响。

3 讨论
本研究的目的是评价代谢酶 CYP2B6 诱导剂利福平对环泊酚注射液的 PK、PD 和安全性的影响，代谢酶 CYP2B6 主要在肝脏和脑中表达，是细胞色素 CYP450 家族的一员，约占肝脏 CYP450 总含量的 2% \~ 10%［6］。作为重要的代谢酶，CYP2B6 参与了市场近 25% 的药物代谢［7］。代谢酶 CYP2B6可以被利福平高度诱导［6，8］，试验药物环泊酚注射液的主要Ⅰ相代谢酶为 CYP2B6。故本研究以利福平作为诱导剂，观察环泊酚注射液的代谢是否受潜在 CYP2B6 诱导剂的影响。根据 FDA 2017 年 DDI指南［3］，尚未推荐 CYP2B6 的抑制剂，故未同步进行 CYP2B6 抑制剂对环泊酚 PK 的影响。
CYP2B6 诱导剂利福平对环泊酚 PK 影响的研究结果表明，单用环泊酚和环泊酚联合利福平$\mathrm { A U C } _ { 0 - \infty } \setminus \mathrm { A U C } _ { 0 - \mathrm { i n f } }$ 的几何均数比值的 90%CI 均处于 80.00% \~ 125.00% 的范围内； $C _ { \mathrm { m a x } }$ 的几何均数比值的 90%CI 略超出 80.00% \~ 125.00% 范围（79.48%\~102.87%），提示稳态利福平对环泊酚的吸收速度和程度没有明显影响；联合利福平未改变环泊酚的半衰期和清除率，说明稳态利福平对单用环泊酚的清除没有明显影响。因此，利福平对环泊酚的 PK 无明显的影响。同样的，稳态利福平对环泊酚的 PD 效果也无显著影响。另外，环泊酚注射液给药后安全可耐受，单独给药以及联合利福平给药的不良事件与环泊酚注射液前期研究基本保持一致，未见非预期不良事件发生。环泊酚是最近开发的全新的静脉麻醉镇静药物，具有起效快速、苏醒迅速平稳的 PD 特征。本试验结果提示，环泊酚联合使用利福平表现出了良好的安全性和耐受性。在环泊酚临床使用中，联合使用 CYP2B6 诱导剂不会出现显著的 DDI，无临床意义的 PK 方面的不良相互作用。临床可以根据需要选择环泊酚和CYP2B6 诱导剂联合使用，而无需调整药物剂量。
代谢酶 CYP2B6 诱导剂利福平对环泊酚注射液的 PK、PD 均无明显的影响。环泊酚注射液单独给药组和联合利福平组耐受性和安全性良好，稳态利福平对环泊酚注射液的安全性和耐受性也无明显的影响。
