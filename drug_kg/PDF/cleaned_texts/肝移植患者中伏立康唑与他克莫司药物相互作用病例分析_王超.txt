肝移植患者中伏立康唑与他克莫司药物相互作用病例分析Δ
摘要目的：对伏立康唑（VOZ）在两种不同的给药方式下（口服和静脉滴注）对他克莫司（TAC）药物浓度的影响程度进行比较，探讨两种药物相互作用机制。方法：观察分析1例服用TAC的肝移植术后随访患者，在应用VOZ治疗肺炎前后，TAC体内药物浓度的变化。结果：静脉滴注 VOZ 时 TAC 的平均谷浓度 ( c 0 ) 为 18.6 ng/ml（13.1～24 ng/ml），c0/D 为 12.6 ng/（ml·mg）[12～13.1 ng/（ml·mg）]，口服 VOZ 与 TAC 联合用药时 TAC 的 c0为 7.2 ng/ml（5.8～9.4 ng/ml），c0/每日剂量（D）为 18.5 ng/（ml·mg）[15.6～24.8ng/（ml·mg）]。与联合用药前相比，静脉滴注VOZ使TAC的 c 0 / D 增加了641.2％，口服VOZ则使得TAC的 c 0 / D 增高了 994.1％；口服VOZ联合应用时TAC 的c/D比静脉滴注VOZ联合应用时增加了47.6％。结论：肝移植术后患者在应用VOZ治疗肺炎后，TAC减少原剂量的1/3给药的方法并不适用，个体化给药很重要；二者相互作用的机制为：VOZ抑制肝脏和肠道中的CYP3A4/CYP3A5，使TAC的药物浓度显著升高；与VOZ静脉给药方式相比，口服VOZ联合用药时TAC具有较高的生物利用度。
移植后真菌感染是常见的并发症，死亡率高。近年来耐药真菌菌株和新出现真菌日益普遍，临床上迫切需要新的抗真菌药物来对抗移植术后的真菌感染。伏立康唑（VOZ）抗菌谱广、活性强，因此在移植术后真菌感染的治疗与预防上应用日益广泛。VOZ 通过肝脏 C Y P 4 5 0 酶（CYP）系 CYP2C19、CYP2C9和CYP3A4代谢，与多种药物之间存在着相互作用（特非那定、阿司咪唑、西沙必利、匹莫齐特、奎尼、西罗莫司、环孢素、他克莫司等），尤其是移植后患者更应严格监测VOZ与免疫抑制剂（如西罗莫司、环孢素A、他克莫司等）合用时免疫抑制剂的血药浓度，以便调整剂量，保障安全、有效、合理用药。由于VOZ上市时间短，有必要对该药的不良反应进行跟踪；另外，由于与多种药物间存在相互作用，有必要对该药进行血药浓度监测[1]。本文就天津市第一中心医院（以下简称“我院”）器官移植中心收治的1例肝移植术后服用他克莫司（TAC）的随访患者，在应用VOZ治疗肺炎后，TAC体内药物浓度与未联合用药时进行了比较，并且就VOZ在两种不同的给药方式下对TAC的影响程度进行了比较，同时探讨了两种药物相互作用的机制。现病例分析如下。
2.2 TAC的药物浓度监测
根据临床经验结合该患者的实际情况，该患者体内的TAC的目标谷浓度c0范围为3～8 ng/ml。该患者未应用VOZ之前TAC（2 mg、q12h）平均谷浓度 c 0 为 6.8 ng/ml（6.6～9.1 ng/ml），平均 c 0 / D 为 1.7 ng/（ml·mg）[1.6～2.3 ng/（ml·mg）]。考虑到药物的相互作用，根据 V O Z 与TAC联合用药时TAC用药量减少原来剂量的1/3的既定原则[9]，遂减少TAC的剂量（1 mg、q12h）；2 d后静脉滴注VOZ（100 mg、q12h），静脉滴注8 d后改为口服（100 mg、q12h）直至出院，序贯疗法。应用VOZ第5天时测得的 TAC c0为 24.0 ng/ml，此时的 c0/D 为 12.0 ng/（ml·mg），比未用药之前 c 0 / D 升高了605.9％。考虑到药物浓度过高可能带来不良反应，遂停用TAC，直到停药第8天TAC的药物浓度降至7.3 ng/ml[c0/D 为 7.3 ng/（ml mg）] 开始给予小剂量 T A C 。根据药物浓度监测，不断调整剂量，使得该患者体内的TAC药物浓度在其目标浓度范围内。第85天出院时TAC（0.25 mg、12 h）药物浓度为6.2 ng/ml， c 0 / D 为24.8 ng/（ml mg），比未联合用药前TAC的 c 0 / D 增加了1 358.8％。静脉滴注VOZ时TAC平均谷浓度 c 0 为 18.6 ng/ml（13.1～24 ng/ml），c0/D 为 12.6 ng/（ml·mg ) [ 1 2～1 3.1 ng / ( m l · mg ) ] ，与口服VOZ联合用药时TAC的平均谷浓度 c 0 为 7.2 ng/ml（5.8～9.4 ng/ml），平均 c 0 / D 为 18.5n g / ( m l · mg ) [ 1 5.6～2 4.8 ng / ( m l · mg ) ] 。与未联合用药前比，静脉滴注VOZ使TAC的 c 0 / D 增加了641.2％，口服VOZ则使得TAC的 c 0 / D 增加了994.1％了。VOZ在两种不同的给药方式下对TAC的影响比较，TAC与口服VOZ联合应用时的 c 0 / D 比与静脉滴注时增加了47.6％（见表1）。TAC的 c 0 / D 变化趋势见图1。
患者，男性，40岁，体质量68 kg，此次由于发现肝功能异常2月余，于2012年12月25日入我院进行治疗。既往史：2007年2月6日由于“乙肝后肝硬化失代偿期、慢性重症肝炎”接受原位肝移植术，术后按照TAC+吗替麦考酚酯（MMF）+甲泼尼龙（Pred）的三联免疫抑制方案。 本次入院时查体：体温（T）36.6 ℃ ，血压（BP）130/70 mm Hg（1 mm Hg＝133.322Pa），呼吸21次/min。肝病容貌，全身皮肤重度黄染，无明显出血点，双侧未见肝掌、蜘蛛痣。全身淋巴结未见肿大。双肺呼吸音清，未闻及干、湿啰音。心前区无膨隆及异常搏动，无抬举性冲动及震颤，心界叩诊不大，心律齐，无心包擦音，未闻及病理性杂音。全腹平软，腹部可见手术瘢痕，无腹壁静脉曲张。双肾区无压痛及叩击痛，双下肢无水肿。入院时肝功能提示：丙氨酸氨基转移酶（ALT）621.9 U/L、天冬氨酸氨基转移酶（AST）386.1 U/L、总胆红素（TBIL）139.97 μmol/L、碱性磷酸酶（ALP）238.9 U/L、γ-谷氨酰转肽酶（γ-GT）238.9 U/L、乙肝免疫球蛋白滴度＞1 000mg/L。入院治疗时肾功能正常。
2.1 诊断治疗
入院后给予保肝利胆、抗排斥、抗乙肝病毒、抑酸、防治骨质疏松等治疗。肝脏穿刺活检病理回报：移植肝交界性急性排斥反应、移植肝慢性排斥反应、药物性肝损害。根据病理结果，在TAC+MMF+Pred的基础上，调整TAC、MMF、Pred用量，行抗排斥治疗。由于患者持续性的肝功能指标升高，入院后第3天开始间断进行血浆置换治疗，血浆置换后肝功能得到好转。入院后第27天患者开始咳嗽并伴少量白痰，第30天患者咳嗽且间断低热，胸部CT检查提示：双肺炎症，痰细菌培养显示甲型链球菌、黄色奈瑟菌感染，巨细胞病毒（CMV）-脱氧核糖核酸（DNA）复制阳性结果。给予青霉素、更昔洛韦抗感染治疗，并且给予米卡芬净钠预防肺部真菌感染，继续间断血浆置换。入院后第35天患者出现间断寒战高热，咳嗽、咳痰伴轻度憋气，胸CT显示：肺炎较前进展，双肺弥散毛玻璃影较前增多，右肺中叶及双肺下叶后基底段可见片状高密度影，且伴随氧分压和二氧化碳分压降低，确诊为侵袭性肺真菌感染[2]。遂给予伏立康唑+阿奇霉素+更昔洛韦抗感染治疗。患者治疗过程中，肝功能指标下降，肝功能好转，病情得到控制（患者整个治疗过程中肝功能变化情况见图1，图中 c 0 为谷浓度，D为每日剂量）。第85天出院时患者情况：ALT 28.9 U/L、AST 60.0 U/L、TBIL 76.2 μ mol/L、ALP 165.8 U/L、γ-GT 378.2 U/L、乙肝DNA＜100 IU/ml，胸部CT显示：肺炎较前吸收，医嘱出院后继续服用VOZ抗感染治疗。整个治疗过程中患者的肾功能正常。
3.1 引起TAC药物浓度升高的药物分析
该患者入院后连续服用TAC（2 mg、q12h），与TAC联合应用能够影响TAC药物浓度的药物为泮托拉唑（40 mg、qd）连续服用33 d。静脉滴注VOZ前测得TAC的药物浓度c0为6.8 ng/ml（6.6～9.1 ng/ml），c /D 为 1.7 ng/（ml mg）[1.6～2.3 ng/（mlmg）]。考虑到药物的相互作用遂调整TAC剂量（1 mg、q12h），2 d后开始应用VOZ，静脉滴注VOZ第5天时测得TAC谷浓度c0为 24.0 ng/ml，c0/D 为 12.0 ng/（ml·mg），升高了 605.9％。目前，已经有文献报道，兰索拉唑与雷贝拉唑可以升高TAC的药物浓度[3]，却鲜有泮托拉唑与TAC的药物相互作用的报道。已知泮托拉唑在体内主要经过CYP2C19、CYP3A4酶代谢，由CYP2C19代谢为4′-O-去甲基泮托拉唑硫醚和6-羟基泮托拉唑，被CYP3A4代谢为泮托拉唑砜[4]。由于应用VOZ时，泮托拉唑与TAC联合应用已经33 d，TAC的药物浓度已经达到稳态，阿奇霉素对CYP酶系无明显影响[5-6]，更昔洛韦主要以原型从尿中排除对他克莫司也无影响[7]。通过分析后认为TAC药物浓度的升高是由于应用VOZ所致。
目前，国内外对于VOZ与TAC在肝移植术后患者体内相互作用的研究较少，由于肝移植患者存在肝脏与肠道中药物代谢酶可能不相同的特殊性，国外的研究多数集中在肺移植、骨髓移植、肾移植等，国内对于二者相互作用的研究也仅仅限于肾移植患者。本病例观察并分析了本院1例服用TAC的肝移植术后随访患者，指出在应用VOZ治疗肺炎后，按照固定原则，TAC减少原剂量的1/3给药的方法并不适用，突出了个体化给药的重要性，可为以后临床合理用药提供依据。另外比较了静脉滴注VOZ与口服VOZ两种不同的给药方式下对于TAC生物利用度的影响，指出TAC与口服VOZ联合应用时具有较高的生物利用度，这在国内属于首例。同时，由于本研究中只涉及到 1 例患者，未能大样本评估肝移植患者体内CYP2C19/CYP3A4/CYP3A5 不同基因型对于 TAC 与 VOZ 相互作用的影响，有待后续进一步研究。
本例患者肝移植术后5年，静脉滴注VOZ后TAC的c/D增幅为641.2％，这与已经报道的肾移植患者中630％基本一致[8] 。口服 VOZ 使得 TAC 的 c0/D 增长 994.1％，这与 Venkatara-manan R等[9]研究的在肝移植患者中，给予VOZ（200 mg、q12h）TAC的c/D增长10倍基本一致。曾经有研究[10]指出，当TAC与VOZ联合应用时，TAC按照固定的原则给药，即减少原用药量的1/3给药，此原则在本患者中并不适用。这说明，当VOZ与TAC联合应用时个体化给药原则的重要性。另外本病例中还指出TAC与口服VOZ联合用药的c/D比与静脉滴注VOZ联合用药后的c/D增长了47.6％，表明与口服VOZ联合用药时TAC具有较高的生物利用度。但是有报道指出，在大样本的研究中VOZ不同的给药方式对TAC的 c 0 / D 无显著影响[11]。由于本病例中未能详细地评估VOZ在两种不同的给药方式下对TAC的c/D的影响是否具有统计学意义，这是本研究的不足之处。
3.2 TAC与VOZ相互作用的机制
VOZ在体内呈非线性代谢特点，主要通过肝脏的药物代谢酶 CYP2C19、CYP3A4、CYP2C9 代谢[12]。TAC 与 VOZ 具有相同的药物代谢酶，VOZ主要通过抑制CYP3A4酶使TAC药物浓度显著升高。但是，体外研究指出，VOZ对于CYP3A4/5都有抑制作用，且对于CYP3A4的抑制作用大于对CYP3A5的抑制作用，对CYP3A4的抑制作用属于竞争性和非竞争性抑制两种抑制机制，VOZ对于CYP3A5基因的抑制作用CYP3A5\*3/\*3＞CYP3A5\*1/\*3＞CYP3A5\*1/\*1[13] 。综合近年来的研究，静脉滴注VOZ时，由于VOZ抑制了肝脏中的CYP3A4/5酶，影响了TAC的代谢，导致TAC的c0/D升高。TAC首关效应明显，60％的药物被肠道内的CYP3A4、CYP3A5酶代谢，另外小肠内的肠道内CYP3A4与P-gp 的协同作用在TAC的首关效应中也起到了重要的作用。口服VOZ在肠道内通过对CYP3A4、CYP3A5酶的抑制作用，减少了TAC在小肠内的代谢，增加了TAC生物利用度[14-15]。另外有研究指出VOZ并不是 P-gp 的底物[8]，因此口服VOZ与TAC联合用药时具有较高的生物利用度，与VOZ抑制患者小肠内的CYP3A4、CYP3A5酶有关。目前国外有文献报道，TAC与质子泵抑制剂（PPIs）联合用药时肠道内的CYP2C19也可以影响TAC与PPIs 药物的相互作用，且肠道内的non-CYP2C19\*1基因型携带者对于二者药物相互作用大于CYP2C19\*1基因携带者。由于PPIs与VOZ具有相同的药物代谢酶[16]，因此推测，肠道内的CYP2C19基因型也影响TAC与VOZ的相互作用。本研究中患者肠道内的基因型为CYP2C19\*1/\*1、CYP3A4\*1/\*3、CYP3A5\*1/\*1，推测该患者肠道内CYP2C19对于VOZ与TAC药物相互作用的影响较小。但由于本研究中只有1例患者，未能详尽评估肠道内不同的CYP2C19基因型对于二者相互作用的影响，这是本研究的不足之处。
摘要目的：探究静脉给药不良事件常见原因及防治方法，为临床合理用药提供依据。方法：检索数据库查找静脉给药不良事件的相关文献，并对文献分析整理。结果与结论：静脉炎的原因为药物的毒性、pH、渗透压、不溶性微粒、温度、溶剂；可以通过一般方法、冷热敷、中西药防治。药物渗漏的原因有药物因素、血管因素、临床护理操作因素；防治手段除热敷、冷敷、湿敷、中西药防治、封闭外，还可利用拮抗药或解毒剂。血管栓塞与肉芽肿的原因为不溶性微粒进入血管，可以通过建立医院静脉药物配置中心防治。
静脉给药是临床上最重要的治疗措施之一，与其他给药方式相比具有作用迅速、利用度高等特点，广泛地应用于临床。但是，在静脉给药的过程中，越来越多不良事件被发现，引起了人们的高度关注。目前常见的静脉给药不良事件有静脉炎、药物渗漏、血管栓塞与肉芽肿等，本文就此介绍如下。
临床上引起静脉炎的原因主要包括非药物因素和药物因素。非药物因素往往包括静脉输液的部位、场所、输注的速度、留置针情况、局部消毒措施等。这些因素常常可以通过提高护理水平而得到控制[1]。而药物因素往往通过药物本身的毒性、渗透压、温度及酸碱度等引起静脉炎。故药物因素对静脉炎的发生显得尤为重要。
1.1.1 药物的毒性。化疗药物引起的静脉炎最为多见，因大多数化疗药物都属细胞毒类药物，在杀伤肿瘤细胞的同时，对正常细胞也具有一定作用[2]。其致静脉炎的作用往往贯穿于静脉炎是静脉给药过程中最常见的不良事件，严重影响了疾病的治疗及患者的顺应性。
1.1 静脉炎的原因
