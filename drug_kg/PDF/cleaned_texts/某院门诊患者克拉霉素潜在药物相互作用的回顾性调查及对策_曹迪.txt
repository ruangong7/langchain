某院门诊患者克拉霉素潜在药物相互作用的回顾性调查及对策
曹迪，程军（蚌埠市第三人民医院药学部，安徽蚌埠　233000）摘要：目的了解我院门诊患者中的克拉霉素药物相互作用情况，为临床合理用药提供参考。方法采用回顾性研究方法，以克拉霉素药品说明书为基础，参考相关文献及专业数据库，对我院2022年8月—2023 年7月使用克拉霉素的门诊患者处方的潜在药物相互作用情况进行分析。结果共纳入7470份使用克拉霉素的患者处方，发生 1171 例（1347例次）潜在药物相互作用，发生率为 15.68%。涉及 45 种药物，主要包括黄嘌呤类平喘药、糖皮质激素类、致QT间期延长药物、羟甲基戊二酰辅酶 A（HMG-CoA）还原酶抑制剂、二氢吡啶类钙通道阻滞剂等，其中高风险药物相互作用共 902 例次，占 66.96%。结论克拉霉素在门诊患者中发生潜在药物相互作用现象较普遍，临床医师应权衡利弊，优化药物治疗方案，药师应通过专项培训、前置处方审核等进行干预，保障患者用药安全。
Retrospective investigation and countermeasures for potential drug-drug interactions involving clarithromycin in outpatients of a hospital
CAO Di, CHENG Jun (Department of Pharmacy, the Third People’s Hospital of Bengbu, Bengbu Anhui 233000)Abstract: Objective To determine the drug interactions involving clarithromycin in outpatients in a hospital and provide reference for rational drug use. Methods We retrospectively analyzed the potential drug interactions in outpatient prescriptions of clarithromycin from August 2022 to July 2023 in our hospital, based on the clarithromycin package insert and with reference to relevant literature and professional databases. Results Totally 7470 prescriptions of clarithromycin were included, covering 1171 cases (1347 interactions) of potential drug interactions, with an incidence of 15.68%. The interactions involved 45 drugs, primarily xanthine bronchodilators, glucocorticoids, QTprolonging drugs, HMG-CoA reductase inhibitors, and dihydropyridine calcium channel blockers. Among them, 902 interactions were classified as high-risk, accounting for 66.96% of the total. Conclusion Potential drug interactions involving clarithromycin are relatively common among outpatients. Clinicians should weigh the benefits and drawbacks and optimize treatment regimens. Pharmacists should intervene through specialized training and pre-prescription review to ensure patient medication safety.据调查，临床上超过30%的药品不良反应（adverse reaction，ADR）是由药物相互作用（drug-drug interaction，DDI）引起的，严重威胁患者的安全，导致患者住院时间延长、医疗成本增加，而DDI往往可以预防和避免，药师通过发挥自身专业优势对临床中出现的DDI进行鉴别和评估，有利于帮助医师对诊疗中出现的DDI进行管理[1-2]。克拉霉素（clarithromycin，CAM）是一种常见的半合成十四元环大环内酯类抗菌药物，通过抑制细菌蛋白质的合成来发挥抗菌作用，其主要由肝细胞色素 P450 同工酶 3A4（CYP3A4）代谢，是 CY-P3A4、P糖蛋白（P-gp）强抑制剂，同时CAM也是已知高风险的致QT间期延长药物[3]，有研究表明，CAM同其他药物联用时可能会产生潜在药物相互作用（potential drug-drug interaction，pDDI），从而影响药物临床疗效，甚至产生严重的ADR。本研究通过调查分析蚌埠市第三人民医院（简称我院）门诊患者CAM联合用药处方，梳理CAM相关的pDDI严重程度及风险点，并提出干预措施，以期为临床安全用药和后期管理提供参考。

1　资料与方法
1.1　资料来源
本调查采用回顾性研究方法，利用医院合理用药软件，通过门诊患者查询功能，获取我院2022 年 8 月—2023 年 7 月门诊使用 CAM患者的同日门诊处方。其中同一患者同日多张处方合并为一张处方，排除合并后单药处方及处方信息不完整处方。
1.2　研究方法
由 2 名药师共同对处方资料中的 pDDI 和高风险DDI进行分析判断，当2名药师对相互作用的分类出现异议时，由第3名高级职称药师综合分析并作出最后判断。
1.2.1 pDDI和高风险DDI评判标准本研究的pDDI和高风险DDI评判标准基于克拉霉素缓释片（江苏恒瑞医药股份有限公司）药品说明书（最后更新时间：2023年3月27日），并参考专业数据库进行制订，如果满足以下3个分级中的任何一个，则被定义为pDDI；如果同时满足3个分级，则被定义为高风险DDI：
① Micromedex 数据库分级为 Contraindicated（禁止同时使用）、Major（可能危及生命和 / 或需要医疗干预以尽量减少或避免严重的不良影响）、Moderate（可能导致患者病情加重和/或需要在治疗中发生改变）；② Lexicomp数据库分级为X级（避免使用）、D级（考虑调整治疗方案）、C级（监测治疗）；③ 用药助手App分为禁用（禁止同时使用）、严重（可能会危及生命，必须同时使用时需要医疗干预来减少或避免严重ADR）、中度（可能加重患者病情和/或需要更改治疗）。

3　讨论
3.1　药品说明书、循证数据库中pDDI数量警示信息存在差异
说明书是医师获取必要药品信息的主要途径，由研究结果可知，仅有19种pDDI在说明书中提及，并且说明书中无统一的pDDI警示分级，与徐哲等[5] 的研究结果一致。因此，需要药师为医师提供专业的DDI知识和注意事项，帮助医师规避临床用药风险。Micromedex、Lexicomp、用药助手是3个比较常用的循证药学数据库，pDDI模块收载的DDI均参考国内外药品说明书、权威文献、指南等循证证据，由医学专家进行评审编写[6-7]。Micromedex、Lexicomp、 用药助手中 CAM 相关pDDI检出数分别为39对、40对、30对，部分药物对风险等级略有差异，判定为高风险DDI共26对，建议在药学人员配备充足的医疗机构，可考虑综合纳入 Micromedex、Lexicomp、用药助手数据库信息，重点关注高风险DDI，若数据库pDDI警示程度存在差异，建议以最高警示程度为准，以最大程度避免用药风险[8]。
3.2 CAM与黄嘌呤类平喘药
调查中发现CAM联合黄嘌呤类平喘药氨茶碱、茶碱pDDI较多。目前，在全球范围内，茶碱仍是呼吸系统疾病治疗中应用最广泛的处方药物之一[9]。氨茶碱是无水茶碱和乙二胺的复盐，经代谢后成为有活性的茶碱，成人中茶碱约90%经肝脏CYP3A4代谢，同时茶碱的治疗剂量与中毒剂量较接近，血药浓度超过20 mg·L－ 1 时ADR发生概率会明显增大。CAM为强CYP3A4抑制剂，能够减少茶碱清除，使茶碱血药浓度增加25% ～ 30%[10]。CAM 说明书明确指出，在 CAM合用茶碱的病例中，茶碱剂量应适当减少。针对老年、肝肾功能不全、茶碱剂量大的联合用药患者，可以监测茶碱血药浓度，并重视心律失常（包括心动过速）、低血压、电解质紊乱、惊厥等严重ADR监测与预防工作 [10]，确保患者用药安全。
3.5 CAM 与 HMG-CoA 还原酶抑制剂
他汀类药物作为治疗高胆固醇血症的首选药物，能稳定动脉粥样硬化斑块，在临床广泛用于防治冠心病、中风等心血管疾病。辛伐他汀和阿托伐他汀主要通过 CYP3A4 代谢，易发生 DDI[17-18]。研究表明，CAM与辛伐他汀和阿托伐他汀药物相互作用的曲线下面积比值 $( \mathit { A U C R } = \mathit { A U C } _ { \mathit { \overleftrightarrow { A } } \mathit { j } \mathit { i } \mathit { j } \mathit { i } \mathit { j } \mathit { i } \mathit { j } } ) $ $A U C _ { \mathcal { F } \notin \mathbb { N } \notin \mathbb { N } \notin \mathbb { N } } )$ 分别为9.85及2.54[4]，合用会导致横纹肌溶解风险增加。曾有因CAM和阿托伐他汀合用，导致横纹肌溶解，肾衰竭死亡的病例报道[19]。他汀类药物诱导横纹肌溶解呈剂量依赖性，《2016 AHA科学声明：他汀类和选择性应用心血管疾病19药物之间相互作用的管理建议》[20] 中建议CAM与辛伐他汀联合使用时日剂量不超过10 mg，与阿托伐他汀合用日剂量不超过 20 mg，医师在开具处方时应重点关注pDDI中辛伐他汀、阿托伐他汀的剂量，或者换用几乎不经过P450酶代谢的普伐他汀和匹伐他汀，及主要经过CYP2A9 酶代谢的瑞舒伐他汀[21]，最大限度避免横纹肌溶解等ADR的发生。
3.3 CAM与糖皮质激素类药物
调查中发现CAM联合糖皮质激素pDDI也较多，绝大多数糖皮质激素经过CYP3A4代谢，CYP3A4强抑制剂伊曲康唑与甲泼尼龙同时使用可使甲泼尼龙AUC升高2.53倍，并使其半衰期延长[11]。在一项针对健康志愿者的药代动力学研究中，酮康唑与布地奈德同时给药时，布地奈德AUC增加了6.5倍，若两药给药时间间隔12 h，则布地奈德AUC增加3.8倍[12]。同样的相互作用机制，强CYP3A4抑制剂CAM也可以使甲泼尼龙、布地奈德的 AUC 升高。De Wachter 等 [13] 曾报道了1例囊性纤维化患者吸入布地奈德 $4 0 0 ~ \mu \mathrm { g } \cdot \mathrm { d } ^ { - 1 }$ ，同时服用CAM，在用药后的6周出现了库欣综合征，包括向心性肥胖、满月脸、高血压、肾上腺轴抑制等临床症状，停用药物后临床症状逐渐好转。提示CAM通过抑制CYP3A4显著减慢了布地奈德的代谢，从而导致库欣综合征的出现。因此，提示临床应该谨慎合用CAM与经CYP3A4代谢的糖皮质激素，如必须合用需及时调整糖皮质激素剂量，并加强相关ADR监测，或选用不受CYP3A4抑制剂影响的糖皮质激素（如泼尼松龙）[11]。
3.6 CAM 与 CCB
调查中发现4对CAM联合CCB的pDDI，均为高风险DDI，联用可能会导致严重低血压、心动过缓或急性肾损伤。Wright等[22] 进行了一项回顾性调查研究，涉及7100例因使用CCB后出现低血压并住院的患者案例，在这些患者中，有100例同时使用了CAM，结果显示，CAM与CCB的联合使用显著提高了患者因低血压或休克而住院的风险$( O R = 3 . 7 0 , 9 5 \% C I \colon 2 . 2 6 \sim 6 . 0 6 , P < 0 . 0 0 1 ) _ { \circ }$ 另一项由Gandhi等[23] 进行的研究进一步证实了这一发现，他们比较了阿奇霉素联用CCB（n＝96226）及 CAM 联用 CCB（n ＝ 94 083）的情况。结果显示，CAM联用CCB的患者因急性肾损伤住院的风险显著高于前者（0.44% vs 0.22%，OR ＝ 1.98，95%CI：1.68～2.34）；同样，这些患者因低血压住院的风险也显著增加（0.12% vs 0.07%，OR ＝1.60，95%CI：1.18 ～ 2.16）；全因死亡率也更高（1.02% vs 0.59%，OR ＝ 1.74，95%CI：1.57 ～ 1.93）。这些研究均提示，作为CYP3A4强抑制剂的CAM与CCB联合使用时，会显著增加患者发生严重低血压、心动过缓或急性肾损伤的风险，需引起医务人员重视，尤其对长期使用CCB的患者，临床药师应进行用药指导及监护，以便及时发现和干预此类pDDI，减少患者用药的风险。
3.4 CAM与致 QT间期延长药物
联合应用致QT间期延长药物会使尖端扭转型室性心动过速（TdP）发生风险明显增加[14]。体内研究显示，大环内酯类抗菌药物（如红霉素、CAM）能够通过阻滞IKr通道延长QT间期导致复极异常，并促进早期后除极及TdP的产生[15]。项针对健康志愿者的研究中，联合使用CAM和经CYP3A4代谢的致QT间期延长药物西沙必利，导致西沙必利血药浓度增加了3倍，QT间期比预处理值增加了 $2 5 ~ \mathrm { m s ^ { [ 1 6 ] } }$ 。这项研究说明CAM可通过DDI增加其他经CYP3A4代谢的致QT间期延长药物暴露量，并且通过协同作用共同增加QT间期延长及诱发TdP风险。本次调查中发现12对此类pDDI，但说明书仅提及其中4对，包括1对禁止使用DDI（CAM-多潘立酮），说明此类pDDI并未在临床实践中引起重视，因此需要药师加强对致QT间期延长DDI处方的审核，并进行细致的风险效益评估，在药物使用过程中医师应密切观察患者的生命体征，加强心电监测。
4　对策
调查中发现CAM在各临床科室应用广泛，CAM是 CYP3A4 与 P-gp的强抑制剂，同时也是已知高风险的致QT间期延长药物，会与其他药物发生pDDI，甚至导致有致死风险的横纹肌溶解、急性肾损伤等，需要引起药师和医师的重视。通过本次调查，笔者总结了CAM相关 $\mathrm { \ p D D I { \sigma I } }$ 严重程度分级、高风险DDI、风险及建议等信息，并将采取下列干预措施提高医师对CAM相关pDDI的认识，促进合理用药：
① 药师将收集到的CAM相关pDDI使用情况进行分析汇总，对高风险DDI，通过我院OA系统药事管理专栏进行发布，为全院相关医务人员提供警示信息。② 在全院开展CAM合理用药专项培训，对于CAM不良pDDI问题较突出的临床科室开展有针对性的合理用药培训，并对临床典型不合理处方实例进行分析。③ 后续将利用逸耀药师临床辅助决策管理系统（前置审方软件），设置对应的审方规则，并在药事管理与药物治疗学委员会进行备案，对于pDDI级别为“禁止合用”的药物对，利用处方前置审核系统自动拦截禁止使用；对于“避免合用”的药物对，系统自动审查出的风险点，并将处方交由审方药师进行人工审查和干预，及时纠正不合理用药，规范临床用药行为；对于“谨慎合用”的药对，以弹框方式实时提醒临床医师CAM相关pDDI风险点，辅助临床医师进行用药决策，避免不合理用药。
