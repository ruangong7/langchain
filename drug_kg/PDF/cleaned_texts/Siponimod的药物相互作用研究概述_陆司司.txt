Summary of Siponimod's Drug Interaction Study
LU Si-si( Zhuhai Rundu Pharmaceutical Co. ，Ltd. ，Zhuhai 519000，China)ABSTRACT: Siponimod is the first drug to delay the progress of disability in patients with active secondary progressive but lack of the combined using study a f drugs interaction with Siponimod，including CYP2C9 /CYP3A4 inducersand inhibitors，vaccines，contraceptives，immunomodulatory or inhibitory treatments，antiarrhythmic drugs，β-blockers，to provide a reference for combined use and avoid adverse factors in clinical use.多发性硬化症是一种中枢神经系统的慢性免疫介导的炎症性疾病，伴有轴突损伤、神经病变和脱髓鞘〔1〕 。 多数患者被诊断为复发缓解型多发性硬化症( RRMS) ，其中又有 50%的患者最终在发病的 10 ～15 年内发展为继发进展型多发性硬化症( SPMS) 〔2〕 。 SPMS 病例受神经功能障碍的持续恶化，通常会影响行走、 括约肌控制、 手部功能、 言语、 吞咽和认知 〔3〕 。 FDA 于 2019 年 3 月批准由 Novartis 推出的 Siponimod( 商品名: MAYZENT) 。 该药物适用于治疗复发形式的多发性硬化症( MS) ，包括成人中的临床孤立综合征( CIS) ，复发缓解型多发性硬化症( RRMS) 和活动性继发进展型多发性硬化症( Active SPMS) 〔4 〕 。 Siponimod 是首个可以延缓 SPMS 患者残疾进展的药物，成功打破了当前活动性 SPMS 无药治疗的僵局，为该症群患者( 包括许多已经达到非复发期和高度残疾的) 带来福音。
充分的药物相互作用研究是为临床安全用药提供科学合理数据支持的前提。 笔者拟在此综述各类药物与 Siponimod的药物相互作用相关研究，旨在为 Siponimod 的联合用药方面提供参考，避免临床用药中产生不利的相互作用因素。
1 药物相互作用研究
1. 1 CYP2Y9 /CYP3A4 诱导剂及抑制剂 Felix Huth 〔9〕 等人通过 PBPK 建模，评估不同 CYP2C9 基因型在细胞色素 P450( CYP) 2C9 /CYP3A4 抑制剂/诱导剂的情况下对 Siponimod 全身暴露的 DDI 效应。 研究表明: CYP2C9 基因多态性显示对Siponimod 的代谢具有显著影响，CYP2C9\* 3 /\* 3 基因型人群的 DDI 风险显著高于其他基因型，CYP2C9\* 3 患者避免应使用本品; ( 2) CYP3A4 /CYP2C9 抑制剂使 Siponimod 的暴露增加，CYP3A4 /CYP2C9 诱导剂使 Siponimod 的暴露减少 。
Siponimod 是一种有效的选择性 1-磷酸鞘氨醇( S1P) 受体调节剂，与第一代 S1P 受体调节剂相比，Siponimod 不需要在体内进行磷酸化 〔5〕 。 Siponimod 对 S1P1 /S1P5 受体表现出纳摩尔亲和力，可诱导 S1P1 受体发生深刻而持久的内在化作用〔6〕 。 S1P1 受体的内在化使淋巴细胞对 S1P 无反应，使它们失去了从淋巴结流出并再循环进入中枢神经系统( CNS) 的强制性信号，从而减轻了神经炎症〔7〕 。 S1P 为活性磷脂，其调节涉及免疫心率平滑肌张力和内皮屏障功能的各种细胞反应 。 Siponimod 以高亲和力结合 S1P1 、 S1P5，阻断淋巴细胞从淋巴结中的排出，减少外周血中淋巴细胞数量。 在 MS 中发挥治疗作用的机制可能涉及减少淋巴细胞向中枢神经系统的迁移 。 口服 Siponimod 约 4 h( 3 ～ 8 h) 达到 $\mathrm { { C _ { \mathrm { { m a x } } } } }$ ，血浆蛋白结合率 ＞ 99. 9% ，易透过血脑屏障 。 主要通过 CYP2C9( 79. 3% ) 和 CYP3A4( 18. 5% ) 代谢，其主要代谢物 M3 和 M17药理活性预计不影响疗效、药物相互作用及安全性，消除半衰期约为 30 h〔8〕 。 Siponimod 具有非时间依赖性的药代动力学，服用单剂量( 0. 1 ～ 75 mg) 和多剂量( 0. 3 ～ 20 mg) 后全身暴露的速率和程度呈剂量比例增加〔9〕 。 此外，在临床前 MS 模型研究中报道 Siponimod 可逆转慢性神经系统麻痹并减少炎症和脱髓鞘 〔 10-13 〕 。
Anne Gardin 〔14〕 等人在一项健康受试者联合服用 600 mg利福平( 强 CYP3A4 /中度 CYP2C9 双诱导剂) 和 2 mg 的 Si-ponimod 研究中，以 PK、 $\mathrm { C _ { \mathrm { m a x } } , \mathrm { s s , T _ { \mathrm { m a x } } , \mathrm { s s , A U C t a u } , \mathrm { s s } } }$ 为主要评价指标，以代谢物 M3 和 M5 的 PK 安全性/耐受性( 包括ALC) 为次要评价指标，结果显示: 合用利福平使 Siponimod 的$\mathrm { C } _ { \mathrm { m a x } } , \mathrm { s s }$ 和 $\mathrm { A U C t a u } , \mathrm { s s }$ 分别降低 45% 和 57% ; 代谢物 M3 的$\mathrm { \Delta C _ { \mathrm { m a x } } } 9 ^ { \mathrm { s s } }$ 增加 53% ， ${ \mathrm { , A U C t a u , s s } }$ 降低 10% ; 代谢物 M5 的 AUC-tau，ss 降低 37% 。
1. 5 抗心律失常药物据报道 Siponimod 可能通过与 S1PR1的相互作用激活人心肌细胞中的 GIRK 通道，引起心动过缓〔12〕 。 由于在治疗开始时引起心率和房室传导延迟的短暂下降( 在给药后的前6 h 内观察到心率降至最低) ，基于对心率潜在累加效应的考虑，一般不会对同时接受钙通道阻滞剂( 如维拉帕米，地尔硫卓) 或其他可能会降低心率的药物( 如伊伐布雷定，地高辛) 、 Ⅰ a 类( 如奎尼丁，普鲁卡因酰胺) 和Ⅲ类( 如胺碘酮，索他洛尔) 抗心律失常药物的患者同时接受 Si-ponimod 治疗。 Siponimod 诱导的心率降低可以通过阿托品或异丙肾上腺素逆转〔8〕 。

1.6 β-受体阻滞剂在药效学( PD) /安全性研究中评估了Siponimod 和普萘洛尔的共同给药的负性变时效应，在稳态下在 Siponimod 中加用普萘洛尔( 小于累加效应) 与稳态下在普萘洛尔中加用 Siponimod 相比，负性变时效应更不明显( HR累加效应) 故建议接受 β 受体阻滞剂治疗的患者在启动 Si-ponimod 之前可能需要暂时中断 β 受体阻滞剂治疗。 而接受稳定剂量 Siponimod 的患者则可以开始接受 β 受体阻滞剂治疗 〔 8 〕 。 。
综上研究可知，由于 CYP3A4 /CYP2C9 诱导剂使 Siponi-mod 的暴露减少，CYP3A4 /CYP2C9 抑制剂使 Siponimod 的暴露增加。 因此不建议同时使用中度 CYP2C9/强 CYP3A4 诱导剂( 如利福平、依法韦伦) ，中度 CYP2C9 或中强度 CYP3A4 抑制剂( 如氟康唑) 。
2 结论和展望
当前 Siponimod 的药物相互作用研究显示 Siponimod 与避孕药联用无影响且具有良好的耐受性与安全性，但由于其主要通过 CYP2C9 和 CYP3A4 代谢的特点显示受 CYP2C9 /CYP3A4 诱导剂或抑制剂强度的影响。 另外 Siponimod 作为选择性1-磷酸鞘氨醇( S1P) 受体调节剂，其作用机制可调节涉及免疫、心率、平滑肌张力和内皮屏障功能，药物相互作用研究亦显示其具有影响免疫调节、改变疫苗的耐受性和功效、降低心率等。 Siponimod 作为继发进展型多发性硬化症的热门药物其临床应用前景良好，而目前国内对于 Siponimod 的药物相互作用研究尚少，可基于目前的研究方向进行深入研究，以期为临床安全用药提供更科学合理的指导依据。
1. 2 疫苗 Siponimod 的免疫调节特性可能影响免疫反应，可能会改变疫苗的耐受性和功效。 Mike Ufer 〔16〕 等人开展一项随机、双盲安慰剂对照的研究中，将136 名健康受试者随机分为4 组( 中断治疗、治疗前、伴随治疗、安慰剂治疗) ，于试验第20 天肌内静注含有 4 种抗原的流感疫苗以及流感疫苗开展研究，在基线( 即抗原攻击前) 以及疫苗接种后7、14、21、28 和42 天测定抗体浓度或效价。 结果显示: 4 组的 IgG 和IgM 浓度增加程度相似; 治疗前组与安慰剂组非劣效性相似，而中断治疗及伴随治疗组的响应率与安慰剂组相比，约低于15% ～30% 。 因此在流感情况下伴随 Sipinimod 治疗不能排除降低疫苗接种效率，可在疫苗接种前后暂停 Siponimod 治疗以减轻疫苗效价降低的风险。
在使用 Siponimod 治疗期间和使用4 周后，接种疫苗的效果可能较差，使用减毒活疫苗可能会带来感染风险，因此应在此阶段避免使用减毒活疫苗。 此外应在治疗前检测 VZV 抗体，建议对水痘疫苗的抗体阴性患者进行全程疫苗接种，再将治疗开始时间推迟4 周〔8〕 。
1. 3 避孕药 Shibadas Biswal 等人 〔17〕 在一项评估对 Siponi-mod 对单相口服避孕药( OC) 的影响研究中，对 24 名健康女性受试者( 18 ～40 岁) 分别评估两个治疗期( 第1 期为单独服用 OC，第 2 期为 OC + Siponimod) 的 PK 参数 FSH LH 雌二醇和孕酮浓度等。 结果显示 Siponimod 对 OC 的 PK 或 PD 没有临床相关影响，且具有良好的安全性和耐受性1.4 免疫调节或免疫抑制治疗当从具有延长免疫效应的药物转换为 Siponimod 治疗时，必须考虑这些药物的半衰期和作用方式，以避免免疫抑制作用，使疾病再激活的风险降至最低。 由于阿仑单抗免疫抑制作用的特点和持续时间，不建议在阿仑单抗治疗后开始使用 Siponimod 治疗。 通常可以在停用 β 干扰素或醋酸格拉替雷后立即开始使用〔8〕 。
临床药师对干粉吸入剂用药患者实施全程药学监护的效果研究
梁雪珍，刘恒，曾韵萍，冯应聪，陈康桂，黄晓新，林春梅( 湛江市第二中医医院，广东湛江 524013)摘要: 目的通过吸入步骤评分表对干粉( DPI) 吸入剂用药依从性的调查，评价临床药师对患者实施全程药学监护的效果。 方法本研究选取我院2019 年1 月 ～ 2020 年1 月收治的60 例吸入用药患者，由临床药师实施全程药学监护。 采用吸入步骤评分表和吸入剂用药依从性调查问卷表分别对用药监护前后患者的吸入步骤用药依从性进行评分，评价患者对吸入方法的掌握程度和对患者用药依从性的影响。 结果吸入步骤评分药学监护前后分别为( 8. 25 ± 0. 93) 、 ( 9. 90 ± 0. 09) 分，P ＜ 0. 05; 吸入剂用药依从性调查问卷得分药学监护前后分别为( 3. 32 ± 0. 25) 、(6.74 ±0. 39) 分，P ＜0. 05。 结论实施全程药学监护可提高哮喘及慢性阻塞性肺疾病( COPD) 患者对吸入技术的掌握程度，有效改善患者吸入用药的依从性，增强药物疗效。
临床上呼吸道疾病的给药途径目前首选吸入治疗方式，干粉吸入剂( DPI) 又是一种主要的吸入剂剂型且相对容易掌握〔1〕 。 DPI 的释药原理是借助流体动力学将药物传递至肺部，患者的用药技巧直接关系到药物的疗效，对患者病情的控制起着重要的作用〔2〕 临床上发现临床药师若不对患者进行指导教育，患者操作方法掌握情况差，直接影响了药物治疗效果而且临床上吸入剂用药依从性明显偏低，间接影响了对患者症状的控制效果。 故对首次用药的患者实施全程药学监护十分必要。 因此，科室针对以上问题展开了课题研究，现报道如下。
