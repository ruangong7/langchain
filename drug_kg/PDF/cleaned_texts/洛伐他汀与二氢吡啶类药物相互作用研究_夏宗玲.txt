由方程式可见，二氢吡啶类药物中硝苯地平，非洛地平，拉西地平，乐卡地平，尼莫地平对洛伐他汀的抑制作用 $\mathrm { I C } _ { 5 0 }$ 值与其分子结构参数成一次方关系，其中 $\mathrm { L o g P }$ 、折射性、极性与抑制作用成正相关，而分子量、表面积、分子体积与抑制作用成负相关。

4 讨论
由研究结果可见二氢吡啶类药物中硝苯地平、非洛地平、拉西地平、乐卡地平、尼莫地平对洛伐他汀的抑制作用强弱不同，其 $\mathrm { I C } _ { 5 0 } { } ^ { \prime }$ 值与其分子结构参数成一次方关系，其中LogP、折射性、极性与抑制作用成正相关，而分子量、表面积、分子体积与抑制作用成负相关。故在临床应用中为了避免此类药物对洛伐他汀的强抑制作用，宜选用LogP值大，而分子量，分子表面积交小的该类药物如硝苯地平、非洛地平等。
本实验采用的研究方法也可以用于其他药物间相互作用研究，该方法简便易行，对实验室设备要求不高，同时为临床药师及医生提供了药物相互作用机制，为临床合理用药提供了理论基础。
