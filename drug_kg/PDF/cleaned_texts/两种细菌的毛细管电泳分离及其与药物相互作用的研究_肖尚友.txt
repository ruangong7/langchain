摘要通过对大肠杆菌与金黄色葡萄球菌的毛细管电泳行为的研究包括对细菌样品预处理缓冲液检测波长以及聚合物添加剂对分离度的改进等的考察在优化的实验条件下实现了大肠杆菌与金黄色葡萄球菌的快速分离从而建立一种新的细菌辅助识别与定性的补充方法将抗菌药物阿奇霉素与金黄色葡萄球菌混合培育发现由于阿奇霉素抑制细菌表面蛋白合成造成与金黄色葡萄球菌作用后细菌表面电荷密度降低表现为阿奇霉素对金黄色葡萄球菌的电泳淌度的影响而且培育时间与金黄色葡萄球菌的淌度线性相关
1 引言
细菌是单细胞原核微生物了解与控制细菌的各种活动对各种细菌进行识别和性质研究是微生物科学的研究基础然而往往多种细菌共存于同一环境体系之中所以发展快速高效的细菌分离识别分析方法十分重要目前仍缺乏对各种细菌进行快速高效分离分析的方法基于细菌形态识别的技术仍占据着主要地位。近年来,根据其物理化学特性研究细菌的方法有质谱法[1]、电化学法[2]、色谱法[3,4] 离子淌度谱法[5]及光谱法[6,7]等这些方法具有快速和定量准确的特点电泳作为一种分离手段早已用于细菌的分离与性质研究[8]细菌的细胞壁含有蛋白质唾液酸等在一定 pH的水溶液中离解而带一定的电荷细菌表面的荷电情况与溶液的组成、pH、离子强度、温度等因素相关。细菌的类型、生长阶段及生长条件不同,其表面的聚合物组成也不同因此表现为其电泳淌度和等电点存在差异这是利用电泳淌度或等电点的不同对细菌进行分离和表征的基础[9,10]。毛细管电泳用于分离粪肠球菌、化脓链球菌、无乳链球菌、肺炎双球菌和金黄色葡萄球菌的混合体系[11] 是研究细菌混合体系的组成和分离分析的有效手段无胶筛分毛细管电泳被用来对啤酒酵母菌藤黄微球菌产气肠杆菌荧光假单胞菌的分离与淌度测定[9] 对药品和果汁中嗜酸乳杆菌、婴儿双歧杆菌的定性与定量分析[12],以及对尿液中细菌病原体的分析[13]。毛细管凝胶电泳还被用于进行细菌混合物的分离[14] 毛细管电泳不仅可以分离不同种属的细菌也能够分离不同亚型细菌[15]。
Armstrong等[16]采用毛细管电泳-激光诱导荧光微流体系对细菌的生存状态进行过考察。不同的荧光探针可分别与活细菌和死细菌发生特异性的结合利用荧光强度可对样品中细菌的生存状态进行分析。Torimura等[17]采用电泳介导微分析 (electrophoretic-mediatedmicroanalysis,EMMA)对细菌的活性进行了研究发现某些抗菌药物与细菌培育后一些细菌的电泳淌度发生了变化而有些细菌虽然电泳淌度没有发生变化但活性降低将 EMMA用于细菌活性分析对于抗菌药物的筛选及药物作用机理研究无疑具有积极的意义。Armstrong等[18]首创用亲和毛细管电泳峰漂移法研究化合物与细菌的结合行为将细菌加入到电泳缓冲液中通过测定分子有效淌度的变化来考察化合物与细菌的结合并通过 Scatchard方程分析求得了万古霉素与婴儿双歧杆菌的结合常数大肠杆菌金黄色葡萄球菌为环境中常见的菌种也是食品制药等工业中微生物检测的常规菌种对人类健康有重要的影响大肠杆菌为有代表性的革兰氏阴性菌而金黄色葡萄球菌为有代表性的革兰氏阳性菌本实验以大肠杆菌与金黄色葡萄球菌为对象采用毛细管区带电泳模式实现了大肠杆菌与金黄色葡萄球菌的快速分离并对抗菌药物阿奇霉素与金黄色葡萄球菌相互作用进行了考察

3 结果与讨论
31 电泳缓冲液的选择
细菌的电泳行为受缓冲液的组成 pH 离子强度等影响选择合适的电泳缓冲液对于维持细菌的稳定性保证分析重现性和提高分离效能十分重要参照文献对 $\mathrm { { N a } _ { 2 } \mathrm { { C O } _ { 3 } } }$ 缓冲液组成为 molL$\mathrm { N a H C O _ { 3 } \Phi \Phi \Phi \Phi \Phi ^ { \mathrm { T } 1 5 } }$ 与 $\mathrm { T B E } ^ { [ 1 2 ] }$ 缓冲液进行了比较。结果表明,采用 $\mathrm { N a _ { 2 } C O _ { 3 } }$ 缓冲液细菌峰形较宽且响应较小而 TBE缓冲液效果较好进一步研究了 TBE缓冲液中 EDTA的作用发现 EDTA的加入可以使细菌之间的聚集作用降低且使细菌在 nm处的响应增强但其机理尚等研究因金黄色葡萄球菌能够在 pH 的范围内生长在 pH 的 TBE[12]缓冲液甚至 $\mathrm { p H } ~ 9 . ~ 5$ 的缓冲液中也能保持细菌的活性[11],故选择 pH8.4TBE作为运行缓冲液。
3.2 检测波长的选择
细菌为大颗粒物质呈半透明状通常认为对其检测是基于细菌对光的散射作用细菌表面物质对紫外光的吸收也有一定贡献细菌的直径在微米级范围大于入射光线波长因而对入射光的减少主要以米氏散射为主比较 nm三个检测波长下组分的透过光成分响应虽然相差不大但在nm处光度下降较大故实验选择 nm为检测波长
3.3 对离心前后样品的电泳考察
将等渗液培育的细菌直接进样进行电泳分析发现两种细菌的电泳谱图相似：在宽峰之前均存在一峰形尖锐的电泳峰由于细菌为大颗粒物质扩散比小分子物质小电泳峰尖锐所以此较尖锐的电泳峰可能即为细菌的电泳峰而电泳谱图中的宽峰则为样品中存在的细菌代谢产物将细菌样品离心取其上清液进行电泳两种细菌样品上清液得到的谱图相似宽峰之前的尖峰消失也证实此尖峰即为细菌的电泳峰将两种上清液混合后进行电泳仅得到单一电泳峰说明二者为同一物质这是由于保存细菌的培养液中含有葡萄糖而两种细菌对葡萄糖的代谢产物均为丙酮酸因此该电泳峰对应的物质可能为丙酮酸
34 样品的超声处理
细菌虽属单细胞微生物,但在自然界中,通常不是以单个个体的形式存在,而是众多细菌彼此结合在一起形成聚集体 (aggregation)。不同聚集数的聚集体电泳淌度存在差异,电泳谱图较为复杂,不利于对细菌的识别与分析对细菌样品施加小功率的超声波可使细菌个体彼此分开又不至于破坏细菌细胞壁的完整性实验将细菌样品进行超声处理利用超声波的空化作用使细菌聚集体解离也使细菌在样品溶液中能够更加均一化本实验研究了超声对金黄色葡萄球菌大肠杆菌的电泳行为的影响研究表明随着超声时间的延长电泳峰的个数减少并伴随着各峰的相对强度的变化大肠杆菌超声处理 90min,金黄色葡萄球菌超声处理 130min后,两者均得到单一的峰。结果如图 1所示。
3.5 金黄色葡萄球菌与大肠杆菌的分离
将金黄色葡萄球菌和大肠杆菌样品分别超声处理 min后二者混合均匀进样得到的电泳谱图如图所示图 $2 \mathrm { a }$ 表明毛细管电泳可在 $6 \mathrm { ~ m ~ i n ~ }$ 内实现金黄色葡萄球菌和大肠杆菌的分离但金黄色葡萄球菌与大肠杆菌的电泳峰都存在分叉现象这可能是由于细菌在电泳过程中重新聚集的缘故[19] 在缓冲液中加入 PEG W/V浓度得到电泳谱图如图 $\mathrm { 2 b _ { \circ } }$ 二者的分离度增加,但是两峰的信噪比大大降低原因可能是 PEG包覆在细菌表面影响了细菌的淌度；同时PEG在此电泳中具有筛分的性质对细菌具有大小与形状选择区分使分离度增大但缓冲液的粘度变大电渗流变小在相同的进样电压与时间条件下进样量减小导致细菌出峰变小另外 PEG造成背景信号增大影响了细菌的检测可以认为在对待细菌分离不佳的情况下,加入 PEG有利于分离度的提高。但是在实际分离中更应兼顾分离度与信噪比以得到最佳的分离分析效果
3.6 阿奇霉素对金黄色葡萄球菌电泳淌度的影响
阿奇霉素为氮杂内酯类抗生素对金黄色葡萄球菌有较强的抑菌作用将阿奇霉素与金黄色葡萄球菌混合培育考察不同培育时间阿奇霉素对金黄色葡萄球菌电泳淌度的影响为了扣除电泳中电渗流的波动对测定的干扰采用中性物质二甲亚砜作为电渗流标记物同时为了避免二甲亚砜标记物对金黄色葡萄球菌的作用实验采用了标记物分区带进样技术如图所示方法为：将标记物 $( 2 4 { \mathrm { ~ \mathbf { k } ~ } } { \mathrm { V } } \times 2 { \mathrm { ~ \mathbf { s } ~ } } )$ 电泳缓冲液 $( \ 2 4 \ \mathrm { \ k V } \times 2 0 \ \mathrm { \ s } )$ 细菌样品 $( 2 4 \mathrm { ~ k V } \times 1 0 \mathrm { ~ s } )$ 依次进样然后进行电泳由于二甲亚砜电泳速度比金黄色葡萄球菌快所以电泳过程中二者不接触这就避免了标记物对细菌的影响由此得到的细菌有效淌度并非其真实淌度而是与其真实淌度相差一定值但由于考察对象为细菌淌度的相对变化,所以这不会对药物与细菌的相互作用研究带来不利影响。研究发现,随药物与细菌混合时间的延长细菌的净电泳速度减慢其电泳淌度与培育时间之间存在一线性关系如图所示阿奇霉素可抑制细菌蛋白质的合成,属快速抑制剂。由于阿奇霉素与细菌作用后,细菌表面荷负电蛋白减少引起细菌表面电荷密度降低从而改变了细菌的淌度。
4 结论与展望
实现了大肠杆菌与金黄色葡萄球菌的毛细管电泳快速分离将阿奇霉素与金黄色葡萄球菌混合培育发现培育时间与金黄色葡萄球菌的淌度存在线性关系由于细菌对环境极其敏感易发生破碎因此电泳介质的选择受到很大限制此外细菌溶液也会随时间发生变化如细菌的繁殖与聚集导致实验重现性差许多细菌释放酶蛋白质等生物分子这些生物分子对其它细菌存在影响也会对细菌的分析造成干扰毛细管电泳的紫外可见检测主要是基于细菌在紫外和可见区域对光的散射对于检测低浓度的微生物不够灵敏因此发展更为灵敏的检测方法以实现低浓度细菌的检测应引起重视毛细管电泳用于细菌的分离分析具有高效快速的特点并易于实现自动化与微型化结合高灵敏度的检测方法可进一步应用于临床与环境中细菌的分离与定量分析。它能作为流式细胞术的补充,表征细菌表面的荷电性质。此外,采用毛细管电泳研究分子与细菌的相互作用具有广阔的发展前景,将这一方法与毛细管阵列技术相结合,有可能成为测定抗菌药物效价的一种快速的方法并用于抗菌药物的高通量筛选
