药物代谢酶和转运体介导的辣椒素-药物相互作用研究进展
秦琰杰，汪难喜，张新林，翟学佳，吕永宁\* ( 华中科技大学同济医学院附属协和医院药剂科，武汉 430022)摘要:随着辣椒素的临床研究不断深入，辣椒素-药物相互作用问题日益凸显近年来的研究结果显示，辣椒素对多种药物代谢酶和转运体有显著的诱导或抑制作用，通过多种因素影响合用药物的体内过程，进而导致复杂的药物相互作用的发生。 笔者查阅了近几年国内外相关研究，从辣椒素对药物代谢酶及转运体的调控作用等方面进行综述，预测可能与辣椒素发生显著相互作用的药物，以期为临床合理用药提供理论指导，同时为复杂的药物相互作用提供新的研究思路。
Advances in Metabolizing Enzymes and Transporters Mediated Capsaicin-Drug Interaction QIN Yan-jie，WANG Nan-xi，ZHANG Xin-lin，ZHAI Xue-jia，L Yong-ning\* ( Department of Pharmacy，Union Hospital，Tongji Medical College，Huazhong University of Science and Technology，Wuhan 430022，China)ABSTRACT: With the continuously clinical study of capsaicin，capsaicin-drug interaction has become increasingly prominent. In recent years，the studies indicate that capsaicin shows a significant inducing or inhibitory effect on a variety of drug metabolism enzymes and transporters，thereby leading to the occurrence of complex drug interactions and affecting the other drugs in vivo process. In this paper，the modulation effect of capsaicin on drug metabolizing enzymes and transporters by reviewing the relevant research at home and abroad in recent years were summarized，and the drug-drug interactions associated with capsaicin in order to provide theoretical guidance for clinical rational drug use were explored . Furthermore，complex drug-drug interaction studies can be provided with prior examples．辣椒素主要存在于辣椒属植物果实中，在日常生活中常被用作香料、食品添加剂和药物。 辣椒素具有止痛、抗癌、抗氧化、抗炎、预防心脑血管疾病、促进能量代谢等多种药理活性［1-2］。 目前，辣椒素已被用于治疗慢性疼痛，术后恶心、呕吐等多种临床疾病。
1 辣椒素对 Ι 相药物代谢酶的调控作用
1.1 辣椒素在体外对药物代谢酶 CYPs 的调控作用
细胞色素 P450 酶( CYP，又名单加氧酶) 作为 Ⅰ 相代谢酶，其活性是影响药物生物转化的关键因素［3］。 人体内共发现了57 种 CYP 酶，含量最多的为 CYP3A4，其重要性按代谢药物的百分比排列有 CYP3A4 ( 50% ) 、 CYP2D6 ( 30% ) 、CYP2C9 ( 10% ) 、 CYP2C19 ( 2% ) 等 。 辣椒素不仅由多种CYPs 进行代谢［4］，而且能够调控多种 CYP 酶 ( 例如CYP1A1，1A2，2B6，2C8，2C9，2C19，2D6，2E1 和 3A4) 。 因此，当用体外系统评价辣椒素对药物的影响时，细胞色素 P450的活性调节是非常重要的参数［5］药物代谢酶和转运体活性的改变是导致临床上药物相互作用的主要机制。 近年来针对单一因素介导的药物相互作用的研究很多，但是综合代谢酶、转运体及生理等多种因素来研究多机制的药物相互作用的报道相对较少。 研究发现，辣椒素能够对多种药物代谢酶和转运体的活性产生诱导或抑制效应，从而引起自身或其他合用药物的代谢发生改变，导致复杂的药物相互作用的发生。 为了促进辣椒素的研发利用并且指导临床合理用药，同时为复杂的药物-药物相互作用的研究提供新的思路，笔者综述了近些年多种药物代谢酶和转运体介导的辣椒素与药物之间的相互作用。

1. 2 辣椒素在体内对药物代谢的影响
药物代谢反应有多种类型，通常称氧化、还原和水解为Ⅰ 相代谢反应。 辣椒素抑制或诱导 CYP 酶能够影响药物在体内的代谢过程，使同服药物的药动学参数发生不同程度的改变。 CYP3A 是人体内参与药物代谢最重要的 CYP450 酶系，主要分布在肝脏和小肠中，参与许多重要化学药物的代谢，是口服药物首过消除的重要因素。

综上所述，辣椒素对 CYP450 酶不同亚型的诱导或抑制作用能够改变底物药物的血药浓度等药动学参数( 表 2) ，影响药物在体内的药动学过程，可能会使药效降低或不良反应增加。 当临床联合用药时，应该注意与相关代谢酶的底物药物合用，但是目前尚缺乏对辣椒素药物相互作用的临床研究资料 。
1. 3 辣椒素体内和体外研究的差异
对比辣椒素的体内和体外数据，其对 CYP450 酶的作用存在很大差异。 辣椒素在体外试验中总体呈现出对CYP 酶的抑制作用，而在体内实验中大多表现为诱导作用( 表 2) 。 造成体内外试验结果不一致的原因如下: 体外实验主要针对单一独立的对象进行考察，而体内环境是一个复杂的整体系统，药物会经过吸收、 分布、 代谢等过程最终到达靶向部位发挥作用。 当药物的给药方式和作用时间以及药物代谢酶的表达环境存在差异时，药物到达靶部位的浓度和存在形式均会发生改变而且体内药物代谢酶的活性和数量也会发生变化，造成药物在体内外不同途径下产生诱导或抑制的不同作用。 再者，体外实验的酶促反应体系一般只有一种或几种 CYP450 酶组成，而药物体内过程往往是多种代谢酶和转运体等多因素协同作用的结果。 此外，大鼠和人类 CYP450 酶基因的核苷酸序列不尽相同，所表达的各亚型酶有可能不完全一致，因此辣椒素对体内 CYP1A2 、 CYP2B6 、 CYP2C9 、CYP3A4 等 CYP450 酶的影响存在差异 。 体内外试验结果不一致是药物相互作用研究中比较常见的现象，但目前尚未报道辣椒素体内外不一致的具体原因。
综上所述，目前已有的研究表明辣椒素在体内诱导UGT1A，降低 UGT1A 代谢药物的生物利用度，但相关研究较少，还有待进一步证实。
综上所述，辣椒素对转运体( 如 $\mathrm { P \mathrm { - g p } , B C R P }$ 等) 具有一定的调控作用，尤其是对 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 的抑制作用已得到广泛证实。因此，辣椒素可能通过抑制肠道内 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ ，影响某些同服的经$\mathrm { P \mathrm { \# ~ } g p }$ 转运的药物在肠道内的透过吸收和外排，尤其是治疗窗较窄易受 $\mathrm { P \mathrm { \# ~ } f ^ { \mathrm { p } } }$ 外排影响的药物，辣椒素可能通过抑制药物外排使体内药物浓度增加，从而产生毒副作用。
3 辣椒素对转运体的调控作用
药物转运体负责将药物吸收并分布到各个组织器官，分为泵入和泵出两个系统，泵入系统包括有机阴离子转运体、有机阳离子转运体、寡肽转运体、核苷转运体; 泵出系统主要为 ABC 转运蛋白，主要成员有多药耐药蛋白( $ { \mathrm { ( P - g p ) } }$ 和多药耐药相关蛋白( MRP) 以及乳腺癌耐药蛋白( BCRP) ［29-30］
4 结语和展望
随着临床疾病日趋多样化、复杂化，治疗难度不断增加，目前联合用药成为治疗复杂疾病的常用方法。 但是联合用药的安全问题不容忽视，不恰当的联合用药会因为药物间相互作用而使疗效降低或出现毒性反应。 近年来，辣椒素的临床应用越来越广泛，但是由于辣椒素对多种药物代谢酶和转运体具有调控作用，会导致同服药物的药动学或药效学发生改变，因此辣椒素与这些药物代谢酶和转运体的底物药物联用时，应该注意调整药物的剂量，避免出现有害的药物相互作用 。
